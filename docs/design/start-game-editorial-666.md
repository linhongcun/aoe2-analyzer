## 展示与来源

文明步先按现有准确条件判断机制覆盖：组队、4v4、阿拉伯、已选路位。该条件成立时始终使用机制；预算为零、无兵、blocked/unavailable 或模块/Core/Trees 失败都不能降为编辑参考。保留 #667 的折叠证据、两份独立输入、恢复、真实流程及错误重试。

覆盖外，只有已明确模式（组队还须人数）和地图且存在真实地图 guide 时，显示“地图编辑参考”。直接说明“当前条件暂无机制建议；模式、地图或路位的机制场景尚未覆盖。以下为地图通用编辑参考，不按本局模式或路位计算，也不是胜率”。不使用分数、排序号、百分比、机制优先徽标或计算结果。

复用现有四图资料，顺序、文明、理由和来源不变，不借邻图补名单：

| 地图    | 两家参考文明       | 既有来源                                  |
| ------- | ------------------ | ----------------------------------------- |
| Arabia  | Franks、Britons    | AOE2 Guide · Arabia                       |
| Arena   | Teutons、Bohemians | AOE2 Guide · Arena                        |
| Nomad   | Spanish、Koreans   | Sitaux · Nomad                            |
| Islands | Japanese、Italians | Sitaux · Water Maps、AoE Buddy 单码头流程 |

每卡有中英文名、一句原有理由、选择按钮和查看资料入口。就近展示原开局方向和可查来源。Nomad 保留先落城镇中心/码头、直城不能照搬出生与时间的限制；Islands 保留安全近岸渔场、水陆混合图流程示意、纯岛图按敌距调整造船的限制。Home 不展示具体流程，原“下面的流程”投影为“地图页的流程”；裸 `/maps` 入口明确需在页内选图。不声称重新访问外站或以地图目录核对日期证明攻略。

缺少模式、人数或地图时不补默认条件。没有 guide 的地图（如 Black Forest）明确“暂无这张地图的文明编辑参考”，仍能自主搜索、跳过与继续，不借用 Arabia。

## 选择、状态与代码边界

参考卡只调用原 `pickCiv(current,id)`，不传路位、不改其它条件，不自动选择第一家。已选且不在参考两家内的文明保持原值，保留“保留此文明继续”；搜索仍可选择其它文明。可以向既有 CivSearch.shown 传两家去重；完整目录容量与文明查看返回属于后续 #676。

将现有纯 `MapGuide/mapGuides` 原样移到轻量 domain 模块，Maps 原入口 re-export；两页使用同一资料。Home 不 import Maps feature，不新增重模型或 buildOrders 入口。原地图页四图资源/开局/文明/真实流程/来源及岛屿码头区保持。
