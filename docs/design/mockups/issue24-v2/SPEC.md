# #24 PK 等资源 · 文明折扣 · 交互规格（Jony）

范围：只影响 `等资源` 模式（URL `m=r`）；1v1 / N vs M 不显示折后价，也不改数量。

## 每侧费用块（单位卡内，`CostView` 下方）
- 每种资源一行：原价 muted + 删除线，后面是折后价（琥珀 #a65a14，700）；没有折扣时只显示原价，不用删除线也不用琥珀。
- `单价合计` 显示原价 → 折后价；`派出数量` = floor(预算 / 折后合计)，原价能买的数量 muted 删除线放在前面。
- `实际投入` x / 预算 · 结余 y（muted）。
- 折后价保留 1 位小数（例 24.5），合计按小数相加；派出数量向下取整。

## 「已计入」行
- 有折扣：绿底一行，check 图标 +「已计入：{文明} {加成简称} −{p}%（{时代}时代）」+「来源」链接（info 图标）。
- 没有折扣：一行 muted「该文明没有可计入的训练费用加成，按原价计算。」（沿用 #22/#27 的说明行写法）。
- 「来源」浮层：文明加成原文（取自 civs.json `bon`）+ 当前时代取哪一档 +「数值来自本站解析的 .dat 与加成表」+「查看{文明}全部加成 →」（#/civ/:en）。桌面悬停或点击打开，移动端点击打开；Esc 或点外部关闭。

## 团队加成
- 每侧一个开关「计入队友团队加成」，默认关；打开后出现「队友：」下拉。
- 队友的团队加成不影响该单位训练费用时：muted 说明「{队友}的团队加成「…」不影响单位训练费用，未计入。」
- 影响时：合并进「已计入」行，一条加成一行。
- URL：`ta=<civ>`、`tb=<civ>`（为空即关）。
- 按 civs.json，目前没有团队加成会降低单位训练费用，此开关先保留给以后的数据（见待确认问题）。

## 页脚
- 删掉「等资源按造价总和计算，未计文明折扣」，改为：「等资源已计入常驻文明与团队的训练费用加成；需研究的科技折扣不计入。」

## 移动端（≤600）
- 两侧单位卡纵向排列；费用块和「已计入」行宽度占满；浮层宽 300，从「来源」下方弹出。
