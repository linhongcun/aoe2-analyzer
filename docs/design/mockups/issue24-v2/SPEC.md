## 每侧费用块（单位卡内，`CostView` 下方）
- 每种资源一行：原价 muted + 删除线，后面是折后价（琥珀 #a65a14，700）；没有折扣时只显示原价，不用删除线也不用琥珀。
- `单价合计` 显示原价 → 折后价；`派出数量` = floor(预算 / 折后合计)，原价能买的数量 muted 删除线放在前面。
- `实际投入` x / 预算 · 结余 y（muted）。
- 折后价按游戏规则取整，显示整数；**取整规则待 Linus 按 .dat 确认**（样稿里 24.5→24 只是占位）。派出数量向下取整。

## 「已计入」行
- 有折扣：绿底一行，check 图标 +「已计入：{文明} {加成简称} −{p}%（{时代}时代）」+「来源」链接（info 图标）。
- 没有折扣：一行 muted「该文明没有可计入的训练费用加成，按原价计算。」（沿用 #22/#27 的说明行写法）。
- 「来源」浮层：文明加成原文（取自 civs.json `bon`）+ 当前时代取哪一档 +「价格按游戏规则取整（规则待 Linus 按 .dat 确认）」+ 底部链接「查看文明加成 →」（#/bonuses）。桌面悬停或点击打开，移动端点击打开；Esc 或点外部关闭。
