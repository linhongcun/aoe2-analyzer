# 帝国时代2 分析器 (AoE2 DE Analyzer)

在线访问：https://linhongcun.github.io/aoe2-analyzer/

帝国时代 II 决定版分析工具（中文界面）。当前模块：文明分析、单位（248 个单位详情）、科技（199 项科技详情），均可从文明页点击跳转（56 个文明的列表/筛选、详情、雷达图、对比、对局助手）。评分为主观近似值。
