# #100 定稿 · PK 对决卡标题时代（v0.6.0，#109）

`mockup.html` 复刻 `.duel-head`；截图 `duel-title-{360,375,390,1280}.png`（移动端 2x）。

## 文案
副标题格式不变：`{文明} · {时代} · {费用}`。**时代取该侧 URL 参数**（`.1.` 黑暗时代 / `.2.` 封建时代 / `.3.` 城堡时代 / `.4.` 帝王时代），与价格栏、盈亏平衡用同一个时代值。缺省参数（`a=38.Franks..f.`）显示「帝王时代」。

## 令牌与数值
- 标题 h3：18px `--fs-h3` 700，`--color-text` #1d1d1f
- 副标题：13px `--fs-sm`，`--color-muted` #636366（5.99:1）
- 时代文字：13px 600，`--color-text-2` #3a3a3c（加重以便扫读，不用颜色区分）
- 费用组 `.res` 整体 `white-space: nowrap`，副标题允许整段折行（`overflow-wrap:anywhere`），不出现横向滚动
