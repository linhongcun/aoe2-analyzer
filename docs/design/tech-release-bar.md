# 科技首发版本快捷筛选

科技页使用与现有目录页一致的 `.dbar` 和 DLC 游戏图标。图标栏位于筛选面板之外，手机收起面板时仍常驻显示；不使用吸顶或覆盖内容的定位。

- 以现有 `DLCS` 顺序显示全部资料片图标，两侧保留「全部」「免费更新」「未标注」文字按钮。移除重复的首发版本下拉框。
- 复用已有 `dlc/setDlc`、`techReleaseMatches`、筛选计数和清空行为；按钮唯一选中并提供 `aria-pressed`。免费更新按现有更新号筛选，不冒用 DLC 图标。
- 搜索、类别、时代、建筑和卡片/详情继续沿用现状；不新增存储或 URL 语义，不修改共享控件和其他页面。
- 复用现有间距、字体、颜色令牌和至少 44×44 的按钮；360/375/390/1280、明暗主题自然换行，无横向溢出或页面错误。加载与无匹配状态保留。
- 迁移现有科技四宽用例及目录布局中「科技无图标栏」旧断言；保留实际结果、免费更新、未标注、路由记忆、清空和详情断言。只执行相关验证一次，main 复用可信证据并做短上线核验。
