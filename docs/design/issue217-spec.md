# #217 术语与缩写

范围：九个经过原帖核对的条目；宏观术语不假装是单位别名。内容存放 `src/content/glossary.json`，与由游戏数据生成的 `src/data/*.json` 分开。数学例子明确为假设，不读旧帖的游戏百分比。

## 入口与信息层级

- 首页百科卡片和全局搜索进入 `/glossary`；开局列表提供文字入口，加成详情链接到措辞条目。
- 列表为单列阅读卡，先显示中文/缩写、英文原表达，再给一段释义。搜索支持缩写、英文、中文关键词及生成的中文拼音；查询参数 `q` 可还原。
- `/glossary/:id` 稳定直达。详情顺序为常见写法、含义、语境例子、注意事项、相关站内链接、折叠来源及复制链接。
- 全局搜索新增“术语”标识，同分实体结果优先；保留既有实体名、别名与拼音的排序语义。

## 状态与操作

- 空查询展示九个首批词条；无匹配保留查询与清空按钮。
- 无效条目 ID 显示“没有这个术语”和返回入口，不退回首页冒充有效结果。
- 复制成功/失败均有 `role=status` 文案。页面路由切换后重置复制反馈。
- 键盘使用正常 Tab/Enter；不新增全局快捷键。输入框有可见标签，链接/按钮高度至少 44px。
- 率与耗时示例限定固定工作量、无额外行走/等待，科技增强示例先界定增量；实际效果链接回固定数据。

## 四宽与主题

360 / 375 / 390 宽使用 `--space-4` 卡片内距、`--fs-h2` 大标题，1280 宽阅读区最大 900px、卡片内距 `--space-6`。英文与来源可断行，不把长词作为不换行的数值。正文至少 `--fs-body`，说明使用 `--fs-sm`。纯数学例子完整成句，保留上下文，不做挤压的横向对照表。

颜色均来自现有语义令牌：背景 `--color-surface`、例子 `--color-surface-2`、正文 `--color-text`、辅助 `--color-muted`、链接 `--color-link`、边框 `--color-border`。浅深主题沿用同一层级；仅使用已登记 Lucide 图标。

## 验证

单测核对词条完整性、稳定 ID、同义检索、速率条目约束和实体精确搜索仍优先。Playwright 验证全局搜索、无结果、失效 ID、复制/静态直达、实体链接及四宽浅深主题，无页面报错/横向溢出。截图为测试产物，不提交 PNG。来源均于 2026-10-19 打开，记录在各词条；仅说明词义与语境，未采纳帖子中的平衡数值。
