## 展示合同

在单位概览的“造价与生产”分区内，现有造价/生产时间/生产建筑 `dl` 之后、采集时间之前，显示一段 **“训练不消耗食物。”**。短句直接可见，不放进详情折叠、说明长文或洞察槽，不增加图标、卡片与操作。

仅实际单位 ID 为 1759/1761，且当前显示的 `(u.cost.Food ?? 0) === 0` 时显示。相同名字、文明、骑兵分类或其它无粮单位均不触发。未来同一 ID 若有正 Food，提示消失；实际成本照常显示。

“训练”限定必须保留，不能将精锐升级的 800 食物费用抹去或误写为全部费用无粮。资源 chips、生产时间/建筑、采集时间、升级研究、普通/精锐切换、页内 tab 与基本属性保持既有行为。提示属于造价分区内部，不改变 cost → 固定空洞察槽 → 基础属性的顺序。

复用现有正文排版，四宽基础可读、无横向滚动；不用颜色传递唯一信息。没有数据时沿既有加载/历史实体状态，不生成猜测。
