玩家打开 `#/civ/Armenians` 这一类页，先读本页，再决定要不要带着这一个文明离开。页内 Tab 是内容分区。情境条是离开本页的工具。两套不再对齐、不再各放一遍。

线框用亚美尼亚，因为 issue 的反馈就是这一页。名字、定位、评分、开局句、独特单位和职业选手原视频标题都来自现有数据（`civs.json` 的 `s` / `op`，独特单位中文名，`proSources.ts`）。正文分区不在本刀。

## 2. 视觉层级

方向 C，浅色编辑风。Inter。强调色只用 `#a65a14`。图标只用已登记的 Lucide。线框上方块里的字是 Lucide 名，实现换成图标，不把名字留在界面上。

**Tab 在上，是主。** 紧贴页头下面，沿用现有 `.dtabs`：浅灰轨、选中项白底、字重 600、无图标、无琥珀填充。`aria-label` 仍是「{文明中文名}内容」。五项顺序固定。选中仍写 `?tab=`（`ov` / `data` / `tech` / `history` / `pro`）。「职业选手视角」只出现在这里。

**情境条在 Tab 下面、两栏正文上面，是次。** 不放在 Tab 旁边（旁边会变成第二列导航）。不放回现在的 `tabsTop`（那一槽画在 Tab 上面，两排会看起来同级）。换 Tab 时这一条留在原地，不写进某个 Tab 的正文里。

它不是第二套 Tab：

| | 页内 Tab | 情境条 |
| --- | --- | --- |
| 角色 | 本页内容 | 离开本页 |
| 控件 | `role="tablist"` 里的 tab | 普通链接，可新标签打开 |
| 外观 | 灰轨 + 白底选中 | 一行字。可见标签「相关工具」，`aria-label="相关工具"` |
| 选中态 | 有，对应当前 `tab` | 无。没有按下、没有白底胶囊、没有第二条灰轨 |
| 图标 | 无 | 有，见下表 |

和 Tab 拉开靠这三件事：Tab 在上且有轨；中间一条 1px 分割线；情境条只有 muted 12px 的「相关工具」加链接蓝文字。不要再套一圈和 Tab 一样高的边框按钮组。现在的 `.community-tool-entry` 自带描边和底，用在这里会把这一行做成第二排导航，本刀不要沿用那层描边。琥珀色只出现在图标占位的浅底（`#f0e6da`）上，不拿来做第二套「当前项」。

可点区域不小于 44×44。链接可以换行。1280 上这五个通常在一行；换行也不做成横滑。

| 文案 | 地址 | Lucide | 建议 test id |
| --- | --- | --- | --- |
| 开局流程 | `#/builds?civ={en}` | `book-open` | `civ-tool-builds` |
| 生产对照 | `#/production?civ={en}` | `factory` | `civ-tool-production` |
| 对局助手 | `#/matchup?me={en}` | `crosshair` | `civ-tool-matchup` |
| 文明对比 | `#/compare?a={en}` | `scale` | `civ-tool-compare` |
| 科技树 | `#/tree/{en}` | `git-branch` | `civ-tool-tree` |

文案保持文明页现在的「生产对照」，不改成导航里的「持续生产」。图标沿用这一条上已经在用的四个，科技树沿用侧栏和科技树页的 `git-branch`。五个都已在 `Icon.tsx` 登记，不新登记。

`users` 不再出现在这一条。打开职业选手仍是 Tab，地址仍是 `#/civ/{en}?tab=pro`。

建议整条 `data-testid="civ-related-tools"`，Tab 列表 `data-testid="civ-tabs"`。

只改文明详情这一处顺序。单位页、科技页现有的 `tabsTop`（例如「回对局助手」）仍在标签上面，本刀不动。

## 3. 侧栏去重

侧栏继续只放实体。亚美尼亚线框里能看见的是：独特单位（复合弓箭手、牧师战士）、同资料片文明（格鲁吉亚）、句末「共 56 个文明」。区域单位、独特建筑、区域建筑若该文明有，仍按现有组件渲染。本刀不重排、不改名、不加减这些块。

删掉整个「快速入口」。删掉之后侧栏不再出现：科技树、文明对比、对局助手。不留一个更短的菜单代替它。

科技 Tab 正文里现在有一句「查看完整科技树」，链到 `#/tree/{en}`。这和情境条是同一处跨页工具。本刀删掉这一句（含旁边的 `tree-deciduous` 图标）。城堡时代 / 帝王时代独特科技两段保留，不改写。这不是重做科技页，也不是 #603 的概览分区。

概览里的「查看完整加成表」仍链到 `#/bonuses`。加成表不在上面的五件工具里，本刀不动。
