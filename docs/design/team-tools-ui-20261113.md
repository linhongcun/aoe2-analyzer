## 文明搭配

候选与队友仍先于结果。桌面候选占约三分之一，队友在其余空间按卡片横排；手机候选先于队友。真正空配置保持空，不补默认文明。

将底部现有“查看完整团队加成 / 带入团战分工”以及范围声明整块提前到结果开头，标题“继续核对与分工”。链接只带真实文明，研究/兵种/任务仍留空；少于一名队友仍不启用分工链接。

双向来源各为独立区域：候选提供什么、队友关联到候选什么。完整列表、可展开详情、直接与生产关系、部分/未知覆盖、研究未完成说明均保留。兵种形态比较仍在来源之后，不增加推荐或战力结论。

结果全宽，先显示“阵容来源总览”与原三项统计，明确计数不随目标筛选缩减。之后常驻、需要研究的科技、未核实关联各自保留分区，卡片按实际宽度自适应，不能让细窄栏强塞两张卡。来源统计与匹配卡数量不混用，记录研究不是系统验证完成。
