# #668 两张浅滩的显示名消歧

维护者已授权处理开一局走查批。本项只修复首页地图选择与地图目录中 Shoals / Wade 的同名辨认，沿用现有布局、搜索、预览和英文副标。

固定双语 API 原始档案的两个中文名均为“浅滩”，原档、来源 URL 与 SHA pins 不变。在人工元数据中配置“浅滩（Shoals）”和“浅滩（Wade）”，由原生成器产生目录 `name`；这是本站消歧显示名，不声称更正官方译名。显示名若存在，只接受对应固定中文名加对应英文名的全角括注，不接受空白、非文本、错误英文或自造译名。

保留83个地图ID、中英对应、排序、说明、图片、其它81图，以及未配置覆盖的同名不去重行为。不得手改生成产物、改原始快照或顺改其它重名地图。旧 #422 的定位按本次批准显示名迁移，Wade“不通航”、Shoals“征服大海”和其它同名图断言保留。

验收：Python先红后绿；原生成脚本重建及`--check`；首页地图步和`#/maps`搜索“浅滩”均只出现两张互异主名，ID与预览一一对应；360/375/390/1280截图核对主名、重复英文副标可读，无横向溢出和页面错误。执行独立复核、适用CI、真实部署与正式Release后关闭。
