# #592 开一局引导 · 交互规格（Jony · 体验设计 · 2026-11-01）

> 产品已软锁（Steve，#592，2026-11-01）。路径见软锁评论。本稿只定首刀界面。不重开范围，不排优先级，不改首页以外的页面。

玩家打开首页，第一件事是走完一局开打前的选择。模式在地图前面。组队才问路位。走完看到「本局摘要」，再自己点进已有工具。没有数据就写「暂无建议」，不编造胜率，也不连游戏大厅。

## 1. 放在哪

只改首页 `#/`。不新开路由。导航、搜索、数据版本徽章保持原样。当前项仍是「首页」。

| 区域 | 位置 | 不放 |
| --- | --- | --- |

## 2. 步骤壳

一条流程，步骤用名字，不用写死的 1–5。当前步琥珀色字加 1px 琥珀圈。已完成的步是白底细边，可点回去。还没到的步是灰底，不是按钮。

| 路径 | 步骤条里有什么 |
| --- | --- |
| A，还没选模式，或选了 1v1 | 模式、地图、文明、对手。没有路位 |
| A，组队（2v2 / 3v3 / 4v4） | 地图和文明之间插入路位 |
| B 起点 | 模式（已预填或已跳过）、地图（已预填或已跳过）、文明、对手。路位先不占一格 |

摘要不是决策步，不进步骤条，也不占编号。组队走完会看见五格，1v1 是四格。这是结果，不是规格里的固定步数。

当前问题是一块白卡片：标题、一句「为什么」、选择或空态、底部「上一步」「跳过此步」。第一步没有可回的上一步，按钮禁用，仍占住位置。

建议测试 id：

| 节点 | id |
| --- | --- |
| 整段流程 | `data-testid="start-game"` |
| 步骤条 | `data-testid="start-steps"` |
| 当前问题 | `data-testid="start-step"`，并带 `data-step="mode\|map\|lane\|civ\|opponent"` |
| 上一步 | `data-testid="start-back"` |
| 跳过此步 | `data-testid="start-skip"` |
| 已在大厅 | `data-testid="start-lobby"` |
| 先练文明说明 | `data-testid="start-practice"` |
| 空态那句 | `data-testid="start-empty"` |
| 摘要卡 | `data-testid="start-summary"` |
| 更多工具 | `data-testid="start-more-tools"` |

空态节点在空白折叠后的文字正好是「暂无建议」。有「已跳过」时，这四个字在节点外面。

## 3. 跳过与回退

| 动作 | 结果 |
| --- | --- |
| 跳过此步 | 这一格记为已跳过，不替玩家选默认值。进入下一个还在的决策步。对手是最后一格，跳过进入摘要 |
| 上一步 | 回到上一个还在的决策步。不清除当前步已经点过的值 |
| 点步骤条里已完成的名字 | 同「上一步」，可以跳回那一格 |
| 改了更早的答案 | 清掉它后面的选择。组队改成 1v1 时，路位步消失，路位答案丢掉 |
| 还没到的步 | 不能点 |

跳过模式之后，地图步和文明步的建议都是「暂无建议」。不猜测热门图，也不借用组队路位稿。

可点区域不小于 44×44。步骤条、选择卡、跳过、回退、摘要里的「修改」、深挖链接都算。

## 4. 各步

### 模式

两张卡，都未选时停在这一步。

| 卡 | 文案 | 接下来 |
| --- | --- | --- |
| 1v1 随机地图 | 选这条不会出现路位 | 进入地图。步骤条仍无路位 |
| 组队随机地图 | 再选 2v2、3v3 或 4v4 | 人数未选，模式不算完成 |

人数三枚不包在模式按钮里面。还没点组队时禁用。1v1 没有这一排。首刀不画死亡竞赛、帝国战争、场景。

「为什么」写流程，不写胜率：先定这局是单挑还是组队。模式定了，后面才看地图；组队才问路位。

### 地图

标题「选地图」。建议槽没有按模式的热度，固定「暂无建议」。不写「热门」「常打」「胜率」。不把 `mapCatalog.json` 里 `featured: true` 的图标成热门。

建议槽下面是地图目录，名字用目录里的中文和英文，可搜索。点一张即选定并进入下一步。另有链接「地图页」到 `#/maps`。地图页今天不能从地址还原选中项，所以这条链接只是打开地图页，不承诺已经选中刚才那张图。本刀不改地图页。

线框第 2 张上的阿拉伯半岛，是玩家已经点选的结果，不是推荐排序。目录名以 `mapCatalog.json` 为准：`arabia` 是阿拉伯半岛 / Arabia。

### 路位（条件步）

只在模式为组队时出现，插在地图和文明之间。1v1 的步骤条、问题和摘要都没有这一行。

两张卡：中路、边路。叫法与地图页一致（中路 / 边路，英文 Pocket / Flank）。本步只选侧，不列文明，不写胜率。

「为什么」：只有组队才有这一步。中路 / 边路沿用开图 4v4 的编辑叫法，不是天梯排名。

可以跳过。跳过之后摘要的路位行是「暂无建议」，旁边小字「已跳过」。

### 文明

已选路位，且这张图在 `src/features/maps/positions.ts` 的对应侧有稿：按稿的顺序全列。每条是文明名、英文名、稿里的那句理由，标签「编辑口径，不是胜率」。不按天梯重排，不改稿的措辞。

整行是选定并进入对手。名字旁的「查看」另走 `#/civ/<英文名>`，不推进流程。

这一侧没有稿，或地图被跳过：建议槽「暂无建议」，链接「文明页」到 `#/civs`。选择槽仍可搜全部文明。个数用 `civs.length`，不写死；当前数据是 56。

未选路位却已经在文明步（路径 B）：不合成一张榜。分成「中路」「边路」两组，各组用该侧的稿。点某一组里的文明，同时记下这一侧路位，再进入对手。没稿的一侧单独写「暂无建议」。1v1 不借用这两组。

线框每侧只画头两条，用来看密度。阿拉伯半岛中路稿的前两条是法兰克、匈奴；边路是不列颠、埃塞俄比亚。实现按稿全列。理由用稿里的原句，例如法兰克：「骑兵从封建时代起生命更高，磨坊科技免费，中路适合发育后出骑士。」`civs.json` 里法兰克是骑兵文明，加成包括磨坊科技免费、骑兵从封建时代起生命更高。本刀不改这些句子，也不把生命加成写成胜率。

### 对手

首刀没有已核对的克制数据。建议槽只有「暂无建议」。不出现对手文明名，不出现胜率，不出现「克制」名单。

「跳过此步」和「完成本局」都进入摘要。链接「对局助手」到 `#/matchup`，打开后不会自动带上本局文明。本刀不加预填参数。

## 5. 本局摘要

页标题换成「本局摘要」。步骤条里已走过的格子都是完成态，摘要自己不占一格。卡内小标题写「这一局」，不再重复页标题。

每一行：名字、值、「修改」。修改回到那一格。

| 行 | 有选择时 | 没有选择或没有数据 |
| --- | --- | --- |
| 模式 | 例如「组队 · 4v4 随机地图」。「4v4」不换行 | 暂无建议。已跳过时，节点外再加「已跳过」 |
| 地图 | 目录中的中文名和英文名 | 同上 |
| 路位 | 仅组队，且这一步出现过：中路或边路 | 组队且跳过：暂无建议。1v1：整行不渲染 |
| 文明 | 中文名，链到 `#/civ/<英文名>`。有编辑理由就附一句，并标明不是胜率 | 暂无建议 |
| 对手 | 首刀不会有 | 暂无建议 |

深挖链接只打开现有页面，不新造地址，也不把本局选择写进查询参数：

| 链接 | 地址 | 说明 |
| --- | --- | --- |
| 地图页 | `#/maps` | 不保证选中摘要里的图 |
| 文明页上的文明名 | `#/civ/Franks` 这一类 | 只有真的选了文明才放 |
| 天梯数据 | `#/ladder` | 现有静态快照，不是这一局的胜率 |
| 对局助手 | `#/matchup` | 不自动带文明 |
| 开局流程 | `#/builds` | 不自动带文明 |

「再开一局」清空这条流程，回到模式步。不读取对局，不写账号。

线框用的一局是：组队、4v4 随机地图、阿拉伯半岛、中路、法兰克。对手是「暂无建议」。这是走完 A 的样子，不是推荐榜第一名。

## 6. B 次入口

模式步下方一个次按钮：「已在大厅」。点开后仍是首页上的同一套壳，当前步变成文明。

目标态是预填后再开始：模式和地图在步骤条里显示「已预填」，当前问题是「选我方文明」。预填只使用本站已有的模式和地图目录，玩家自己点。线框示例是组队 4v4 和阿拉伯半岛，标注这是入口里填好的，不是从游戏客户端读的。

路位先不插入。文明步按第 4 节分成中路 / 边路。另有「补路位」，按下后才把路位插回地图和文明之间，并变成当前步。

若预填控件来不及做：按钮仍在。点进去之后模式和地图是「已跳过」，文明步写「暂无建议」，用「修改」回去补。这是同一条 B，不是第三条路径。线框画的是预填成功的起点。

B 不连接大厅，不登录，不接实时接口。

## 7. C 不做

「先练某个文明」只出现在模式步，是一段灰色说明，文案带「首刀不做」。不是链接，不是按钮，不进 Tab 序。其它三张线框用脚注重复这一句，避免看起来像漏做的入口。

反推「这个文明适合哪张图」不在本刀。另开 follow-up 之前，不要从文明页链回这条流程。
