# 波兰翼骑兵的区域单位分类（#460）

维护者提供立陶宛页面截图，明确指出波兰和立陶宛共享的波兰翼骑兵应归区域单位。仅纠正1707 Winged Hussar；不改441普通翼骑兵、1699弗拉芒民兵或其它单位。

## 来源与处理

已实际核对[固定上游3bb43b1的LITHUANIANS树](https://github.com/SiegeEngineers/aoe2techtree/blob/3bb43b1439eef88dfe7fe892d7f7dc41ac9dd76f/data/trees/LITHUANIANS.json)和[POLES树](https://github.com/SiegeEngineers/aoe2techtree/blob/3bb43b1439eef88dfe7fe892d7f7dc41ac9dd76f/data/trees/POLES.json)，1707均可用且标为UniqueUnit。现有生成器直接沿用该字段，因此误归独特单位。依维护者本次明确指正，在生成阶段以精确ID校正1707为RegionalUnit；记录此源分类差异，不伪称上游已经修正，不按拥有文明数量扩展规则。上游版本、游戏数值、名称、时代、科技、护甲类别和可用文明不变。

独立数据审计实际扫描全部56树：1707是唯一有多个可用文明的UniqueUnit；独立的691不可用节点类别冲突不在本次修复范围。当前目录248形态，总数口径不变，UniqueUnit形态157变156、RegionalUnit形态34变35。

## 展示与行为

- 波兰、立陶宛共用文明侧栏：独特单位中无波兰翼骑兵，区域单位中恰有一个；其它独特/区域单位及区域建筑保留。两文明均不再显示“本文明没有区域单位”。
- 区域单位链接分别是`/unit/1707/Poles/4/`和`/unit/1707/Lithuanians/4/`；科技模拟器与刷新保留文明和帝王时代。
- 单位列表的区域筛选包含1707，独特筛选排除1707，详情类型标签为区域单位。科技树底色和建筑生产分组自然沿用修正后的统一字段，不做页面特判。
- 不新增样式或重排侧栏；复用现有SideBlock/uchips/UnitIcon。360/375/390/1280浅深主题均无溢出、重叠或页面错误，标签最小44×44px，文字与主题沿既有令牌，键盘可访问。
- 继续沿用现有加载/空态，无新增请求或异步状态。其它无区域单位文明仍显示原空态。

先失败：真实导出目录1707仍为UniqueUnit；波兰、立陶宛侧栏区域区缺少对应单位。Python验证精确校正规则与其它ID/类型透传，TypeScript验证真实目录、两文明归属、441/1707分叉与原始总数。四宽浅深截图、单位筛选/详情及模拟器/刷新回归。重新生成数据后按ID比较，仅1707的type变化与生成器既有排序变化；其它248形态字段相同。生成产物不得手改，不改受保护验收期望。

本次涉及数据生成器和导出数据，执行一次适用完整CI及固定数据再生成检查。合入main按同树可信证据复用，仍重建实际SHA并短烟测，线上确认两文明归属与正式Release。最终独立复核SHA、截图和真实范围记录在PR。
