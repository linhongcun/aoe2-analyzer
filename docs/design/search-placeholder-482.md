# 全局搜索窄屏占位（#482）

依据：[issue #482](https://github.com/linhongcun/aoe2-analyzer/issues/482) 与本轮[冻结范围](grok-feedback-2026-10-28.md)。基线中搜索加载外壳与正式面板均使用较长占位文案，窄屏输入区域还需容纳搜索图标和 Esc，文字被截为半句。

## 范围与可验收行为

- 加载外壳和正式面板采用同一简短占位文案「搜索文明、单位、科技…」，可访问名称继续为「全局搜索」，搜索范围与能力不变。
- 在360／375／390／1280及明暗主题下，占位完整显示，或通过明确省略号结束；不出现半截字、半个括号或横向溢出。输入框可随容器收缩，Esc始终在面板内可见。
- 沿用现有搜索面板布局、字体及设计令牌，不改搜索索引、别名、结果排序、键盘导航或分包策略；只改占位与必要的输入框尺寸／省略样式，不新增公共组件或依赖。
- 保留分包加载时立即输入的行为；中文文本及组合输入事件从加载外壳交接到正式输入框时不丢失。正式面板仍可继续编辑、返回匹配结果，并用Esc关闭和归还焦点。
