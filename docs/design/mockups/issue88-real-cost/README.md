## 文案（逐字）
- 开关：「等资源」「等采集时间」（后者带 Lucide `clock` 图标）。
- 预算：默认「村民时间 10 个村民 × 10:00」，用户可修改（Steve 已定）。
- 行：「食物 60」后面跟 muted 小字「按农田计」（只在有食物时出现）；「黄金 75」；合计行「单个用时」后面跟 muted 小字「1 个村民」；「派出数量」。
- 口径行：`clock` 图标 +「{时代} · 经济科技全研究 · 按农田计」，右侧链接「口径」（Lucide `info` 图标，点击区域 44px 高）。
- 口径浮层，标题「采集时间怎么算」：
  1. 采集速度按{时代}，该时代能研究的经济科技全部算上；选了文明就叠加文明加成。
  2. 食物按农田算，播种耗时计入。
  3. 金和木离放置点 3 格，农田贴着磨坊；每趟 = 携带量 ÷ 采集速度 + 往返路程 ÷ 村民速度。
  4. 有文明折扣先按折扣价，再换算成时间。
  - 浮层底部小字：「不模拟地图和资源分布，和实战会有出入。数据：游戏 .dat（DE Update 185872）」
- 已计入：「已计入：{文明} 采金 +{n}%」，百分比只写一次。
- 未计入：「未计入：{文明} {加成名}（数据读不准，按通用速度算）」。
- 时间一律写成 `m:ss`，满 1 小时写 `h:mm:ss`；负号一律用 U+2212「−」。

## 数字说明（重要）
- **红色虚线框里的数字（m:ss、NN）都是占位**，等 Kent 按 #120 口径手算后替换。
- 农田的播种耗时在 `src/data/eco.json` 里没有（`buildings.50` Farm 只有 buildTime 15 / cost Wood 60，无 seed/sow/reseed 字段）。按 Steve 决定，页面和口径浮层写「播种耗时 未核实」，任何位置不填具体数字。另外 Horse Collar / Heavy Plow 的 workRate 是 ×1.0，Heavy Plow 是 carry +1，和其他携带量乘数谁先谁后也不清楚，所以食物这一侧没法算。
- S1 里「黄金 2:54」是我按 `eco.json` 推出来的设计演算，只用来验证排版宽度，**最终以 Kent 手算为准**。推法如下：
  - 采金速度：0.38 × 1.15 × 1.15 = 0.5026/s（Gold Mining、Gold Shaft Mining）。
  - 携带量：10 × 1.2695 × 1.5 = 19.04（Wheelbarrow、Hand Cart）。
  - 村民速度：0.8 × 1.1 × 1.1 = 0.968 格/s。
  - 每趟耗时：19.04 ÷ 0.5026 + 6 ÷ 0.968 = 44.09 s，有效速度 0.432 金/s。
  - 75 金 ≈ 173.7 村民秒 ≈ 2:54。
  - 同样的算法：伐木有效速度 0.475/s，所以 25 木 ≈ 0:53，35 木 ≈ 1:14，45 金 ≈ 1:44，60 金 ≈ 2:19。

## 边界情况
- **文明加成**：可计入的走 S5，读不准的走 S6，不猜。
- **折扣单位**：时间只按「实际」价算，原价不出时间（S3）。
- **只花金子或只花一种资源**：照样显示合计行，不写「按农田计」（S4）。
- **含石头的单位**：同样处理，石头行用采石速度。
- **不在范围内**：「不按农田」（浆果、羊、猎物）这种食物来源选项本版不做；不做地图和路径模拟。
