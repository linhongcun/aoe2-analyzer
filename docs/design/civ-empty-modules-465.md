# 文明侧栏隐藏空模块（#465）

维护者明确要求：文明没有某模块内容时不显示，不占空间。本规格取代此前区域单位/独特建筑/区域建筑的空态卡片要求。

- 数据已加载且过滤结果为空：对应组件返回null，不渲染SideBlock、标题、边框、空态文字或占位。父层原本就是Fragment，卡片会按既有布局自然上移，无需隐藏样式或保留空wrapper。
- 数据未加载：保持原role=status加载提示。单位需units和families都就绪才能判空，建筑需buildings非null；已加载的空数组是有效空目录。不能因初始list为空就提前隐藏未知内容。
- 有内容：原图标、名称、精锐合并、文明/时代链接、44px热区和顺序保持。仅当前真实存在的模块参与排列；独特单位、同资料片文明原有条件渲染保持，快速入口始终可见。
- 具体案例：日本仅保留独特单位及快速入口/同资料片；保加利亚保留独特单位、独特建筑营垒；亚美尼亚保留独特单位、区域单位、区域建筑；波兰保留独特单位、区域单位和独特建筑大庄园。没有内容的三个模块均不出现“本文明没有…”或留下空白卡片。
- 状态：切换文明后同步重算显示性，含有内容→无内容→有内容；tab切换和刷新一致。受控请求验证加载提示先存在，数据释放后日本三个模块整块移除。
- 布局：复用原颜色、字号、边框、间距及响应式规则，不改CSS。360/375/390/1280×浅深主题检查日本最简侧栏和保加利亚/波兰/亚美尼亚的不同组合，没有空SideBlock、横向溢出、页面错误或模块间额外空位。
- 验收：真实先失败的日本空模块用例；新增组合与加载/SPA切换回归。现有非受保护3份spec及短烟测按本轮明确授权迁移空态和标题顺序，其内容、链接、加载、键盘、axe等断言保留。旧规格标注空态规则由本页取代。

只改3个局部组件的空结果渲染、相关规格/回归和部署短烟测，不改共享布局、分类、生成数据/管线或计算，不改受保护验收期望。使用文明相关CI/data=false，独立预审及最终SHA/四宽复核后沿持续授权上线。
