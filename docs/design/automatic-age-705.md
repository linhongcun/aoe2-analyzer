# 升时代自动属性（#705）

范围仅为单位448与建筑72/792/117/487的概览，基础属性之后增加只读「升时代自动变化」。不改模拟器、科技选择、原基础值、生成数据、全局样式或开一局。前项#704与必要发布修复#715已完整发布v0.77.21关闭，本项单写者、单PR串行实施。

## 固定来源与数值

DE188329，`effects.json.generic` tech20对448：攻击+2、视野+2、速度+0.35；基底读units：3/4/1.2，故封建为5/6/1.55。时代从规则age读取，前一时代为age-1，不能以448目录age=2裁掉黑暗对照。tech72给72/792生命×1.66667，基底150/240，按建筑模拟器Math.round为250/400；tech71给117/487×1.666667，1080/1650为1800/2750。不提前舍入倍率。

鹰751按AC允许不单独开块：除了tech20视野+1，固定数据中tech90 Tracking也有无前置封建视野+2，不能把其中一条误标为封建总变化。无城堡自动攻/训速/对骑表，亦不宣称数据中没有其它自动规则。

## 实现边界

两个feature局部组件ScoutAgeChanges、WallAgeChanges，只负责已锁来源的投影；读取DAT.generic，严格核对tech、空req、any=false、对象类型及id。使用现有baseStats/buildingBase、toEffects/applyEffects，单位只展示攻击/视野/速度，墙门只展示生命；无文明或可研究科技混入，不另建通用计算框架。非目标实体返回null；目标缺规则/关键基底/有限结果时显示「自动变化数据待确认」。数字随来源或基底变化，输入不可修改。

## 呈现与状态

复用DetailSection与StatTiles，标题「升时代自动变化」。先写时代转折，再明确「无需研究科技，进入该时代即生效；仅列本表自动规则，不含文明加成和其它科技」。每个属性显示此前、之后与增量；墙门另显示原始倍率。数字及数字单位使用.num/.nw；无需新增table或全局CSS。来源条含DE版本、来源规则id及about-data入口；源链接使用现有44px入口样式。字15px、来源13px，颜色沿tokens。360/375/390/1280、明暗主题无横向溢出/页面错误，axe通过并保留截图。加载随详情原有core加载；目标来源缺失显示待确认，不生成0或静态兜底。非目标详情无卡片。
