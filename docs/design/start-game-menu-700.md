## 产品和结构

仅在首页 `#/` 已通过恢复核验的“开一局”区域增加原生 `details`，summary为“开一局功能菜单”。位于标题、导语之后和现有步骤条之前，默认收起，只占一行44px入口；原模式选择、已在大厅入口、步骤和更多工具的顺序与能力保留。展开是普通分组列表，不使用 `role=menu/menuitem`，不建立第二套业务步骤或写入协议。

## 状态和动作

- 初始、进行中、摘要：菜单读当前已核验 `StartState`；展开/收起仅原生DOM展示，不写flow、URL、storage，不触发新请求。
- 回到本局步骤：聚焦实际已渲染的当前步骤/摘要（允许本地 `tabIndex=-1` 辅助焦点），不触发该控件动作；没有第二套步骤状态。大厅按钮仍只用既有初始模式入口，菜单不复制会清空本局的enterLobby调用。
- 模式、地图、路位或文明未齐：说明城堡机制只在已核验条件下展示，仍能继续原当前步骤和自主选择；不强行跳到尚不可达的文明步。
- URL/local恢复pending或failed：沿原恢复区，暂不挂载菜单和上下文链接，防止未验证状态流入工具。原loading、失败重试、放弃恢复原样可用。非法URL继续原零写与保留地址规则，不擅自修复。
- 切换步骤、修改配置、再开一局、刷新、history前进后退与完整URL跨context恢复：沿现有状态机/codec/persistence，菜单不另存展开状态。
- native disabled不能获得Tab焦点。指针点击、原生`.click()`及明确目标的合成键事件均不能导航、写业务状态或触发数据/页面预加载；不能把未聚焦disabled之后对其它活动元素发Enter误作测试。
