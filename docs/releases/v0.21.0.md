# v0.21.0：村民驻军箭矢预览

维护者在本会话明确授权按 #214 → #215 → #216 → #217 → #218 完成开发、验证和部署。本版只新增 #218，设计规格见 `docs/design/issue218-spec.md`。此前已完成的功能保留并回归。

建筑页新增村民驻军箭矢预览，显示基础箭、副箭、总箭数、容量与下一箭人数阈值，可从建筑模拟器带入科技（#218）。
固定 .dat 导出与可复现检查覆盖相关弹丸、驻军贡献和文明效果，补齐斯万箭塔；分享和非法链接状态均有校验。

## 边界

只支持城镇中心、箭塔线和村民驻军；不支持城堡、军事单位混驻、火炮塔或完整建筑战斗。

不预测 DPS、命中、击杀时间或胜负；规则未核实或输入不兼容时暂停结果。
