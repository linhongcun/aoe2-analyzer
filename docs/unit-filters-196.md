# 单位目录文明与兵种筛选（#196）

文明按当前固定游戏版本 DE Update 185872 的 `Unit.civs` 判断，表示该文明科技树中可用的实际记录，不计盟友解锁、招降或战役赠予。来源为 `src/data/units.json`，上游版本见 `scripts/data_sources.json`。不从生产建筑或文明描述推断可用性。

兵种读取同一记录的原始护甲类别 `Unit.cls`，复用 `unitClass.ts` 中已有判定，不改变战斗、科技效果计算。分类允许交叉：

| 目录兵种 | 游戏护甲类别                         | 边界示例                                                                                     |
| -------- | ------------------------------------ | -------------------------------------------------------------------------------------------- |
| 步兵     | 1                                    | 战斗牧师也属于僧侣                                                                           |
| 骑兵     | 8、30（骆驼）、5（战象）或28（骑射） | 象弓手、骆驼射手也属于弓兵；铠甲象也属于攻城武器；传教士也属于僧侣                           |
| 弓兵     | 15或28（骑射）                       | 包括有该类的掷矛手、火枪兵与骑射；不按射程或伤害类型猜测                                     |
| 攻城武器 | 20                                   | 爆破者没有该护甲类别，归其他单位                                                             |
| 船只     | 16                                   | 包括渔船、运输船和贸易货船；不会仅因远程攻击归入弓兵                                         |
| 僧侣     | 25                                   | 包括传教士与战斗牧师                                                                         |
| 其他单位 | 以上均不匹配                         | 当前包括村民、贸易马车、爆破者；护甲类别39也出现在烈焰骆驼等战斗单位上，不能据此推断经济用途 |

查询、文明、兵种、单位类别、时代与DLC必须由同一实际形态同时满足，之后再合并系列。优先展示命中的普通版，否则展示命中的精锐版；同名多生产建筑与第二条精锐记录也参与匹配。原有163个系列的总数口径不变，结果数量表示命中的系列数。

“含精锐”沿用原列表的系列元信息，不受搜索词、时代或DLC限制；选中文明或兵种后，只能引用该文明、该兵种可用的精锐记录。例如土耳其掷矛手、达罗毗荼战象、蒙古炮舰不会带不可用的精锐标记。精锐卡片名称、数值、图标、版本与链接均来自实际命中记录。

筛选跨站内路由保留；“清空筛选”同时重置六类条件。手机使用双列原生下拉，文明和搜索各占一整行，文明选择器沿用窄屏抽屉、搜索、键盘与Esc行为。无结果显示明确提示和清空入口。

验证：`tests/unit/unitFilters196.test.ts` 覆盖数据类别边界与同记录组合；`tests/e2e/unitFilters196.spec.ts` 覆盖六条件、不可用精锐、交叉分类、清空、四宽度与两种主题。界面配色和字号沿用浅色编辑风令牌。
