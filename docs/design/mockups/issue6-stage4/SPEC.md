## 规则
1. 卡片在深色下去阴影，改 1px border #38383a 区分层级。
2. 分段控件 / 主题切换选中项：#636366 底 + 白字（不用琥珀，不用白底，避免深色里出现大块亮面）。
3. 升级路线当前项：浅色是黑底白字，深色不反转成白底，改 #48484a 底白字加粗。
4. 中性评分条 #636366（浅色 #aeaeb2）；琥珀仍每页最多 2 个，位置与浅色相同。
5. 资源色块（食物/金/木/石）沿用浅色值，非文字、只作辅助，旁边总有数字。
6. 主题切换：默认「跟随系统」（prefers-color-scheme）。选择只存本机 localStorage，**不写进 URL**，分享链接与主题无关。桌面：顶栏最右**一个图标按钮**（图标随当前选择：sun / moon / monitor；aria-haspopup=menu，aria-label「主题：{当前}」），点开小菜单三项「浅色 / 深色 / 跟随系统」（role=menuitemradio），当前项右侧打勾并加粗；Esc / 点外部关闭，焦点回按钮。390 宽收进菜单抽屉「外观」分组，三段带文字，默认选中「跟随系统」。
7. axe CI 增加深色主题：首页、单位、文明、列表、模拟器 × 1280/390。
数据：掷斧兵、法兰克，与阶段3相同（main@8510871 src/data/*.json）。Lucide 图标，Inter。
