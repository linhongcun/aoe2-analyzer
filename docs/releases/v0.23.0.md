# v0.23.0：商路、施工、队伍与回血工具

本批围绕玩家讨论中的四个具体问题新增工具：持续补兵需要多少贸易车船，多派村民施工是否值得，队友究竟提供哪些加成，以及受伤单位驻军后需要多久恢复。各工具支持方案分享，坏链接要求显式重置，编辑中的非法数字保留供修正并暂停结果。

## 面向玩家的变化

- **商路供给（#226）**：用每次实际交金量、同一交金点两次连续交金之间的完整游戏时间周期，换算单个与全部车船收入。目标可手填，也可保留原持续生产方案并重算金耗；所需数量向上取整，投资按资源分别列出。实测值已经包含科技、队伍和路线条件，不再次叠加；默认值是测量示例，不是固定商路收益。基础造价只计已核常驻折扣，手填实际价格须注明来源，更换对象后需重新核对。
- **多人施工（#227）**：比较目标与基准人数的理论完工时间、总村民秒和增加一人的边际变化；明确选择原采集任务后才估算停采资源。模型假设普通村民同时到场，保留文明工作率、时代、科技与首座城镇中心门槛。城镇中心采用真实施工附属物，可能与旧详情或开局工具的口径不同；本批不宣称已修正所有历史模拟结果。渔船施工、特殊建造者、步行和分批到场不在范围内。
- **队伍加成（#228）**：保留最多四个玩家槽位，重复文明的同一来源合并展示并列出提供者；常驻加成与需要研究的团队科技分开查看。团队科技列出时代、地点、前置及研究状态，默认未研究；效果按不同来源分别显示，不合成未经核实的倍率。目标筛选依靠已核静态关联，未知或部分覆盖会明确提示；本页不向原有 PK、建筑或经济模拟器注入队友效果。
- **驻军回血（#229）**：复用完整驻军兼容性，针对一个已经在建筑内、没有继续受伤的单位，查看建筑提供的恢复速度和理论时间，比较草药效果并核对最大生命条件。免费科技与前置各应用一次；已达到目标、宿主零速率、不具资格和资格未核实分别处理。机械攻城器、船、牧畜、骡车等特殊对象不因能驻留就自动开放治疗估算；自身再生、主动僧侣、路程、战斗和批次调度不计入。

## 数据与边界

固定游戏数据为 DE Update 185872，新增字段由固定 `.dat` 经可复现脚本导出；原始文件和缓存不随站点发布。贸易收益是用户测量输入，施工和回血是公开规则与固定字段支持的理论估算，队伍页是来源目录。`engineVerifiedInPinnedBuild=false` 明确表示尚未运行相应固定版本客户端实验，软件测试和数据复现不能替代该证据。

市场工具 [#215](https://github.com/linhongcun/aoe2-analyzer/issues/215) 的同版本交易引擎对账仍未完成，保持开放；本批没有改变其核实状态，也不把商路收入混作市场资源买卖价格。

详细口径：[商路](../TRADE-INCOME-DATA.md)、[施工](../CONSTRUCTION-MODEL.md)、[队伍](../data/team-bonuses228.md)、[回血](../GARRISON-HEALING-DATA.md)。
