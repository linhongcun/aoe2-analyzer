# 游戏与现实时间换算

对应 #237，路由 `#/game-clock`。本模块只做显式倍率下的时钟算术，不依赖游戏模拟器或未核实的游戏速度预设。

- 倍率定义为每现实秒经过的游戏秒数；游戏转现实用除法，现实转游戏用乘法。初始倍率1是数学起点。
- 输入单位为秒或严格的“分:秒”，秒位00–59、可加小数；不接受负号、指数、分组符或单位文字。输入最多64字符、总时长最多100000000秒，倍率大于0且不超过1000。输出超过安全整数秒范围时暂停。
- 单位切换按输入十进制文本重新排列，保存原有小数，不把输出写回输入；方向切换保留原始数值并重新解释其时钟含义。极长小数在换写后超过64字符时保留原输入并解释。
- 分:秒输出四舍五入到整秒，秒数最多显示6位小数；小于0.000001的正数用科学记数法显示，避免误显示为0。计算不使用显示值。
- URL为 `v=1&direction=game-to-real|real-to-game&unit=seconds|minutes&duration=原始文本&ratio=原始文本`。未知/重复/缺失/过长/损坏编码或版本不符的链接锁定并提供重置；数字草稿保留可编辑，数值不合法时暂停计算与分享。
- `gameClockHref(seconds)` 为其他工具生成上下文链接，始终传游戏秒、倍率1，不改变源模型结果；不能表示的负值/非有限/超限/过长文本返回null。

本页不能从单个倍率还原暂停、变速、卡顿后的对局耗时。默认速度名称与倍率尚未在DE185872配置中核实，故不预置；1.7仅是明确注明的数学示例。需求来源记录在 #237，本模块不把旧社区回复当作游戏参数证据。
