# v0.14.0 发布范围

维护者于 2026-10-19 明确授权将 #204、#205、#206 按顺序逐项开发、验证并部署。本版只包含 #204；后两项分别在本版上线后发布，不改动既有冻结范围或其他待办。

## 本版功能

- 新增持续生产计算器：文明、时代、专用生产建筑数量及显式科技方案。
- 显示单价、单位/分钟、各资源/分钟及汇总后向上取整的村民配置。
- 支持可复现链接、空/无效输入状态与具体未计入说明。
- 接入工具导航、页面元数据和站点说明，保留既有真实费用默认计算行为。

数据固定 DE 185872。农田补种、住房扩建、建筑建设与研究投入不纳入稳态训练开销；不做完整经济优化或实战保证。具体支持机制及四宽度布局见 `docs/design/issue204-production-spec.md`。
