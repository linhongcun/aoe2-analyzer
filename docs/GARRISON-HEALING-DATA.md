# 驻军回血数据与边界（#229）

此功能计算单个单位已经驻军、没有继续受伤时，建筑本身提供的静态恢复时间。固定 DE Update 185872；未运行游戏客户端，`engineVerifiedInPinnedBuild=false`。软件回归、数据可复现检查与客户端实测是不同的证据。

## 可复现来源

`scripts/garrison_healing_build.py` 经 `scripts/dat_source.py` 读取 `scripts/data_sources.json` 固定的 SiegeEngineers/auto-mods `.dat` 提交与 SHA256，使用固定 genieutils-py 0.1.2 解析。生成 `src/data/garrison_healing.json`，不提交或发布 `.dat`、解析缓存。

```bash
python3 scripts/garrison_healing_build.py
python3 scripts/garrison_healing_build.py --check
python3 -m unittest discover -s tests/py -p test_garrison_healing229.py
```

导出原字段：`Unit.hit_points`、`Unit.type`、`Unit.class_`、`Building.garrison_heal_rate`、`Building.garrison_repair_rate`、属性 108 的普通效果（type 0/4/5）。对象集合直接复用 #224 的完整对象与时代建筑形态，不另维护一份候选名单。固定版全部 411 对象、62 个原始文明副本的这些基础字段没有文明差异；以后出现差异会阻止生成，要求重新审计，不能被忽略。

属性 108 表示 HP/游戏秒；属性 109 是单位自身 HP/游戏分钟的再生率，不能混为一谈。字段含义核对 [AoE2DE UGC 属性文档](https://ugc.aoe2.rocks/general/attributes/attributes/#108-garrison-heal-rate)。宿主原始值保留浮点精度，显示时才格式化。

| 建筑                                             | 固定版基础 HP/游戏秒 | 备注                                   |
| ------------------------------------------------ | -------------------: | -------------------------------------- |
| 城镇中心、箭塔系、炮塔、城楼                     |               约 0.1 | 原始 float 为 0.10000000149011612      |
| 城堡、营垒                                       |               约 0.2 | 原始 float 为 0.20000000298023224      |
| 设防教堂                                         |               约 0.4 | 原始 float 为 0.4000000059604645       |
| 修道院                                           |                  1.5 | 僧侣仅能训练后留驻，不能从外部重新进入 |
| 兵营、靶场                                       |                  0.5 | 仅支持训练后留驻的合法对象             |
| 马厩                                             |                 0.25 | 仅支持训练后留驻的合法对象             |
| 攻城武器厂、市场、码头、巨港、磨坊、房屋、定居点 |                    0 | 可以驻留仍不代表提供治疗               |

以上潜在宿主的原 `garrison_repair_rate` 均为 0。该字段不能作为骡车等特殊对象无治疗资格的证明，也不能替代普通 `garrison_heal_rate`。

## 治疗资格

第一层完全复用 #224 的文明、时代、宿主容量、单位类别、garrison task、生产名单、科技迁移训练地点和驻留方式检查。`enter`、`created`、`deposit` 分别表示外部进入、训练后留驻、圣物存放，不能互相替代。

第二层是显式保守模型策略，生成文件的 `eligibility` **不是原 `.dat` 存在的布尔字段**：

- 普通有机陆军、村民、宗教单位和国王（type 70，原始类 0/4/6/12/18/23/36/43/44/47/59）可按建筑原速率建模；仍须通过第一层合法驻留检查。国王额外提示对局模式限制。
- 圣物等非受伤对象为不具治疗资格；没有恢复秒数。
- 机械攻城器、船、牧畜、骡车等特殊对象的治疗资格暂停核实，不能因其可进入或使用宗教单位 size class 就开放治疗。骡车是 type 80 的移动建筑，也不能据此武断断言不回血。
- 宿主原速率明确为 0 时，单独显示零速率状态。未知资格与零宿主速率是不同问题；不会把未知恢复时间伪装为 0 秒。

普通驻军回血及部分建筑只允许生产留驻的机制，还核对了 Microsoft/Ensemble 原版《Age of Empires II: The Age of Kings》手册，印刷页 37–38、40（[PDF 镜像](https://manuals.plus/m/bede02f48ca7b2aae252168379555520636b871dcd6c6fdba8ba2766ea0186e2.pdf)）。这是原版游戏说明书，不用它的旧容量、旧科技和旧数值替代固定 DE185872 原字段，也不把它当新特殊单位的验证。生产留驻时输入受伤生命值是假定该单位已经在建筑内的静态状态，不表示受伤单位可以从外部进入兵营、马厩或修道院。

## 草药、最大生命与科技

草药科技 441、effect 41 的普通命令对 class 52 与 class 3 的属性 108 各乘 6，前置城堡时代科技 102。另存在 type 202、A=82、C=108、D=6 的命令，本模型不会把它扩展为对所有宿主额外施加的一次全局普通乘法；未模拟场景与局部对象科技。明确区分“增加 500%”和“最终为原来的 6 倍”。固定版只有该项直接研究型驻军治疗速率科技；出现新的速率科技会阻止生成并要求审计。

条顿科技树 effect 262 对草药的费用与研究时间置零；复用 #224 的免费科技解析、文明禁用和时代门禁，城堡时代起自动计入一次，不能取消，也不能因手动选择再应用一次。未研究状态在条顿对应时代不可构造，草药前对比明确暂停。

最大生命复用 `simulator.ts` 的 `simulate()`、完整 HP 科技与文明触发效果、已有 HP 取整规则，并计入当前文明自身的团队加成；没有自行添加其他文明队伍效果。HP 相关科技列表由 `simTechs()` 的实际 HP 效果派生，另加治疗速率与相关生产位置/解锁设置，不沿用弹丸预览的筛选。女村民复用村民 HP 模型且保留单位 ID 293；国王原基础生命为 75，原固定文件没有针对 ID 434 / class 59 的普通 HP 科技命令。其他无可复用正常 HP 模型的特殊对象不输出假定最大生命。

阿兹特克自动科技 456 需要 102 + 441，effect 470 对僧侣加 5 HP，因此草药可能同时改变最大生命。草药前后比较保持相同绝对当前/目标生命；若目标超过未研究草药的最大生命，基线比较暂停，不夹到较小值，也不伪造严格六分之一的秒数。

所有科技前置、免费项和勾选去重后各应用一次。输入 HP 须为大于 0 的有限十进制值且不超过当前配置最大生命，0 HP 的死亡单位不能复活。资格已核实的合法有机对象已经达到或超过目标时明确无需恢复，返回 0 秒；此时即使宿主速率为 0 也无需恢复。未知资格和圣物不通过“已经达到目标”绕过暂停状态。

## 公式与分享

每游戏分钟恢复量 = 每游戏秒恢复量 × 60；理论秒数 =（目标生命 − 当前生命）÷ 每游戏秒恢复量。保存原字段浮点值与小数 HP，不在计算前取整。不同单位自身再生、主动僧侣、范围治疗、路程、战斗、批次调度和资源回本均未计入。

路由 `/garrison-healing`，版本化查询契约 `hv=1&b=<建筑>&civ=<文明>&age=<时代>&u=<单位>&entry=<方式>&techs=<科技ID列表>&current=<HP>&target=<HP>`。完全空查询使用默认方案；非空查询必须完整，拒绝重复、缺失、未知参数、无效对象、科技、HP、超长链接。坏 URL 的错误独立保留直到显式重置；编辑中的坏数值保留字符串供修正。

`healingLink()` 为旧驻军/模拟器入口迁移单一目标：保留合法指定单位与驻留方式，过滤无关科技，未指定单目标时选择新合法默认，不暗取混合驻军第一行。合法但零速率/未核实对象仍可进入查看解释。
