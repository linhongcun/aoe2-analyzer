# #417 补丁页科技树得失汇总

v0.34.0 范围冻结：仅 #417 与 #424。先串行交付 #417，再 #424；均使用独立 PR。当前用户已授权将今天两项 issue 处理完，沿用独立复核及持续发布授权。

在补丁详情现有筛选和主列表之间增加默认折叠的「按文明汇总科技树得失」。展开后按现有文明目录顺序列出文明，每个文明标题链接至其科技树；每条以目标名称链接至科技/单位详情，显示「改动前 已开放 · 改动后 未开放」或相反方向。复用现有条目数据及 patchTarget，不改生成 JSON，也不重新解释数值或增益/削弱。

纯函数只接纳 targetType 为 tech/unit、civIds 非空且 before/after 恰为未开放/已开放互换的记录，按文明拆分，保持输入条目顺序。当前固定 DE 185872 为 57 条、21 个文明；萨拉森脚踏起重机为已开放到未开放。多文明记录分别归入每个文明；空输入为空组，不改变输入。

汇总跟随现有文明、改动类型、目标类型和搜索过滤；无匹配时显示「当前筛选下没有科技树开放或移除项」。无版本详情/未知版本不显示。原主列表、URL 筛选、来源说明不变。明确写明按当前筛选汇总、改动前来源于官方记录、改动后核对固定数据，不声称两个 .dat 自动差分；后续版本复用相同分组函数。

布局使用已有 patch-civs、patch-values 和 note 样式；组标题 h4，内部条目为列表。颜色使用现有 color-text/link/muted/border，文字继承 16px、说明至少12px。链接和 summary 最小44px高，组间保持现有1rem间距，不固定内容宽度。360/375/390/1280、浅深色检查：无溢出或错误，展开、筛选、空态、恢复、文明及科技/单位链接可用；键盘可聚焦展开与链接，对比度符合AA。截图仅作测试附件，不提交PNG。

失败用例：实际数据57条/21组、萨拉森科技54与单位链接；排除普通 buff/nerf/global/civ/bad transitions、多文明分组与输入不变；浏览器展开汇总（旧版缺入口失败）、筛选仅萨拉森、搜索无结果、主列表仍在、四宽明暗和axe。
