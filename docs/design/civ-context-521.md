# 查文明情境入口（#521 / S2）

依据 [#521](https://github.com/linhongcun/aoe2-analyzer/issues/521) 和已合入的 [#517 信息架构](site-linking-517/site-linking-517.md) §3.3–3.4、§5.4–5.7、§10 S2。仅完成 S2，不重做 S1 的对阵入口，不实现 S3，不改游戏数据、计算公式或开局覆盖。

## 页面与状态

- 文明详情头部、标签页上方增加 `nav[aria-label="本页相关工具"]`，沿用现有 `ctx-bar` / `community-tool-entry`。依次为开局流程 `/builds?civ={en}`、生产对照 `/production?civ={en}`、对局助手 `/matchup?me={en}`、文明对比 `/compare?a={en}`、职业选手视角（现有本页 `?tab=pro`）。侧栏已有快捷入口也保留当前文明；科技树入口保留。
- 文明目录整卡改为 React Router Link，保留 `data-civ`、筛选、文字、图标和原卡片视觉，支持 Tab/Enter、中键、新标签和复制地址。无嵌套交互控件。
- 对比表双方文明名为真实文明页链接。合法完整组合、未知参数及其重复项/相对顺序、复制、前进后退、同文明对比均保留。
- 持续生产的既有解码器已支持单独 `civ=`，直接复用并用浏览器检查，不改跨文明训练对照协议或默认单位。
- 单位和科技详情标签页上方在有合法 `civ` 查询时展示文明真链接；单位现有模拟器路径的文明优先于查询，用户在模拟器改选后链接随当前路径更新。首次进入模拟器而路径尚无文明时，合法且可用的查询文明可作为初始文明；未指定或不可用时沿用既有回退。保留原模拟器路径、时代、科技、团队配置及公式。
- 两类详情页的概览侧栏可用文明列为可点击的既有 CivChip；长列表仍可进入原完整文明/相关标签。已存在的完整文明列表继续复用。无合法文明上下文时不虚构当前文明；未知查询不产生无效文明链接。
- 详情页同时带合法 `me`、`opp` 时提供“回对局助手”真链接，保留原双方语义；缺失或无效时不猜测对阵。切换详情标签及单位普通/精锐保持查询上下文。
- 加载、缺失实体、空文明列表沿用原有状态，不新增全局状态或 Context Provider；选择器继续承担选择操作，旁边的文明链接负责导航。

## 对旧 #403 单边规则的定向更新

旧 [#403 规格](issue403-spec.md) 要求任何缺失参数整组回退；新 S2 明确要求 `/compare?a={en}` 可从文明页预填，故本项仅覆盖这一条旧规则：恰有一个合法且唯一的 `a`、完全没有 `b` 时保留 `a`，缺侧用原默认 Britons；对称地仅合法 `b` 时缺侧用 Franks。不引入 sticky。空值、未知文明、重复键或已提供的非法完整组合仍整组回退 Franks/Britons。规范化使用 replace，用户确认改选使用 push，未知参数保持原合同。

普通 `compare403` 回归中合法单边案例从“无效”矩阵迁移为更严格的单边保留、规范化、未知参数、历史与复制/刷新检查，不删覆盖，不放宽非法输入。`v0*-acceptance`、金标准 fixture 和计算期望不变。
