> 产品已锁定（Steve，#581，2026-11-01）。三选一里采用**旁注**。不重开 tooltip，不重开展开摘要。不改 #555 的预填 URL。

玩家在 `#/siege?unit=422` 点「报错/反馈」或「功能建议」之前，要在本页读到将写入 GitHub 的「中型冲车 / 422」。不登录、不离开本站。

## 1. 放在哪

旁注跟现有反馈簇走，不新做一条反馈入口，不做成卡片，不放进标题。

今天攻城页上，#555 会改写这些链接的预填（`siegeFeedbackText` 非空时，标题和正文「类型/ID」都是「名 / ID」）：

| 簇 | 现有入口 | 旁注 |
| --- | --- | --- |
| 页顶 `main .fbbar` | 紧凑「报错/反馈」 | 同一行，紧挨链接左侧。簇仍右对齐 |
| 页脚 `footer .fbfoot` | 「报错/反馈」和「功能建议」 | 只写一条，紧挨在这两个链接之后、现有说明句之前 |
| 未核实卡 | 「反馈数据缺口」 | 与该链接同一行，紧挨在右侧。中型冲车对城堡不出现这张卡，线框不画 |

一条簇一条旁注。不要把旁注写进 `FeedbackLink` 内部，否则页脚两个链接会各重复一句。

旁注不是链接，不是按钮，不包进 `<a>`。链接的可点区域保持不少于 44×44。

## 2. 文案

可见文字（空白折叠后）是：

`将附带：` + `siegeFeedbackText` 的返回值。

`#/siege?unit=422` 且单位表能解析出中文名时，返回值是 `中型冲车 / 422`（`units.json` 的 `zh` 与地址里的 `unit`）。整句：

`将附带：中型冲车 / 422`

「名 / ID」与 #555 预填标题逐字相同，中间是空格、斜杠、空格。ID 用 `.num`，「名 / ID」整段用 `.nw`，不从斜杠两侧折开。

[#589](https://github.com/linhongcun/aoe2-analyzer/pull/589) 的失败用例认这一个 testid，不要另起名字：`data-testid="siege-feedback-context"`。写在显示「名 / ID」的那个元素上。空白折叠后，这个节点的文字正好是 `siegeFeedbackText` 的返回值，例如 `中型冲车 / 422`。前缀 `将附带：` 紧挨在它前面，不写进这个节点。整行仍是 `将附带：中型冲车 / 422`。节点若把前缀包进去，裸 `#/siege` 收成默认单位后，#589 要求节点文字正好等于当前单位的「名 / ID」，会对不上。

节点放在对应入口的父元素里面，不放进 `<a>`。页顶「报错/反馈」、页脚「报错/反馈」、页脚「功能建议」都要能在自己的父元素里读到它。页脚两个链接共用父元素时，一条节点就够。未核实卡里的「反馈数据缺口」一旦出现，它的父元素里也要有一条，文字仍是同一个「名 / ID」。同一页可以有多条，testid 都是 `siege-feedback-context`。

旁注 12px，颜色用 `--color-muted`（`#636366`，浅底约 5.99:1）。不加底、不加框、不用 accent。Accent `#a65a14` 仍只留在攻城页原有的锤子和选中芯片上。

默认不加图标。链接上已经有 `message-square-warning` 或 `lightbulb`。若实现时簇里分不清，只允许已登记的 Lucide `info`：14px、muted、`aria-hidden`，不能拿掉这行字。不为此登记 `link-2`。

## 3. 两态

开关就是 `siegeFeedbackText(ctx)`，与 #555 同一条件：路径是 `/siege`，地址里有 `unit`，且 `unitName` 去空白后非空。

| 态 | 旁注 |
| --- | --- |
| 有单位 | 渲染。例：`将附带：中型冲车 / 422` |
| 无单位 | 不渲染旁注，也没有 `siege-feedback-context`。没有占位、没有「未选单位」、没有「将附带：—」、没有只剩 ID |

攻城页会把没有 `unit` 的地址 replace 成默认参数。Replace 完成且名字解析成功之后，这是有单位态，旁注必须出现。默认单位是攻城锤 1258，句子是 `将附带：攻城锤 / 1258`。那不是无单位。

`wire-siege-no-unit-1280.html` 冻结的是地址里还没有 `unit`（或有 id 但没有中文名）的那一帧。选择框里的「示意」只属于这张线框。实现不增加空选项，页面上不出现「示意」。

其它页面今天不画这行。#555 不把攻城单位名写进 `/unit/:id` 一类路由，那些页的预填标题仍是「单位 4」，不是「名 / ID」。不要为了统一再画一遍实体标题。

若以后某个工具页已经共用同一反馈簇，并且预填标题就是同一套「名 / ID」钩子，复用这一句旁注，不要另做 tooltip。本切片的线框和验收只锁 `#/siege`。

## 4. 无障碍

- 静止即可读。不依赖 hover、focus、`title`，也不是 `<details>`。
- 现有链接的 `title`（「自动附带页面与数据版本」）保持不动，但不能再当唯一说明。
- 旁注在无障碍树里，不设 `aria-hidden`。不把同一句再塞进链接的可访问名称，避免读两遍。
- 旁注不进 Tab 序，没有键盘陷阱。
- 字号不小于 12px。对比度沿用 muted 令牌，不新写一个更淡的灰。
