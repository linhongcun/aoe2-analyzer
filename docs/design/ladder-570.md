# 天梯地图筛选（#570）

状态：**设计待锁**。Jony 的地图筛选规格还没挂到 issue 上。这一版按现有天梯筛选和设计令牌先做可调整实现，不代替审批。

## 三态

| 状态   | 条件                                                                     | 界面                                                                         |
| ------ | ------------------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| 有数据 | `mode=arabia1v1` 且 `map=rm-arabia` 或 `map=arena`，对应静态文件通过校验 | 表和来源条都只读该文件                                                       |
| 无数据 | 当前模式没有这张图，或文件校验失败                                       | 按钮禁用并写「暂无数据」；直接打开地址时主区是空态，不沿用另一张图的胜率     |
| 低样本 | 原始 `agg_n_matches` < 100                                               | 行上标「低样本」。100 是本站暂定，来源没有这条线，状态是待确认，不是平衡建议 |

默认 `#/ladder` 仍是 4v4 全图。这两张图属于 RM 1v1，在 4v4 下禁用，避免切地图时暗改模式。阿拉伯 1v1 原来的 Age of Notes 固定快照还在，地址不带 `map=rm-arabia` / `map=arena` 时不变。

## 四宽

沿用天梯筛选卡：360 / 375 / 390 / 1280 页面本身不横向滚动，表放在现有横向滚动容器里。按钮沿用至少 44px 的规则。数字用 `.num` / `.nw`。窄屏不另做一版视觉。深色和浅色都走现有令牌，不新加颜色。

## 来源条

切地图时来源名、链接、RM 1v1、地图、Elo、补丁声明、采集时间和查询 URL 一起换。采集时间不写成统计截止。全时段不写补丁日期。样本单位见数据说明。
