# 战斗与模拟工具界面优化

基线：670952cf7b1561c2e3af219916484d3fed5d9ded。维护者授权工具页批量优化；常规界面通过复核与验证后直接部署，重大功能决定另询问。

## 冻结范围

- `/duel`：保留紧凑双栏和手机单列、A/B 顶部颜色识别。现有圆角卡改用 radius-lg，选择器/模式/科技预设改为胶囊，选中态使用 accent-soft/accent，结果标题与次级用时区分。控制区保持44px，不因增加留白把桌面结果大幅推离首屏；不隐藏参数或说明。
- `/siege`：保留桌面左参数右结果与 sticky、手机先参数后结果。攻方/目标标题提升为18px，原12px说明不缩小。卡片统一radius-lg与16px间距，select和独立按钮胶囊，数值步进器保持组合边框。对照表表头浅底、目标高亮不变；不改模型边界与缺数据状态。
- `/simulator`：筛选卡radius-lg与16px内边距，控件胶囊；结果目录增加独立surface卡与浅色表头，桌面列与手机结果字段顺序不变。手机文明/兵种占两列，数量与筛选按钮另排一行，避免“全部文明”被挤成“全…”。保持目录基础价说明、计数、空态、筛选折叠和返回恢复。
- PK单选交互：浏览器已复现模式1v1按ArrowRight不切换、三个选项均tabIndex=0。模式、比法、普通/精锐和科技预设使用现有button/radio语义，补一组一个Tab入口与方向键循环、Home/End。事件只处理本组直接子radio按钮，忽略输入与修饰键；移动并聚焦后调用既有click回调，不重写参数或计算。自定义科技无匹配预设时第一个选项可聚焦但不自动选择。A/B组隔离。

## 不在范围

不改domain、生成数据、单位/文明可用性、URL和科技预设含义，不删功能、不改科技模拟器详情（入口仍进入现有单位详情模拟器）。不引入新的全局设计令牌或依赖。
