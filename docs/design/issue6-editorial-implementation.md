# #6 浅色编辑风实施范围

依据用户在本轮明确选择「浅色编辑风」的决定，采用 `DESIGN-SYSTEM.md` 与 `mockups/issue6-stage3/SPEC.md` 的编辑风模板，完成其配套主题能力。阶段 3/4 的较新说明优先于设计系统中的早期示例。

## 本次范围

- 默认浅色，提供深色与跟随系统。偏好仅存本机，不进入分享 URL；首屏在加载样式前应用偏好。
- 中性标题、导航和控件；琥珀用于选中提示和少量关键数字。全站本地 Inter、系统中文无衬线字体及等宽数字继续复用。
- 顶部导航保持现有入口和模块高亮，手机采用分组抽屉；反馈、应用版本、数据版本和构建号常驻页脚，完整来源声明可展开。
- 首页入口卡片以数据生成的数量、清楚的中英文层级和工具入口表达内容；手机首屏保留搜索和至少四个入口。
- 单位、文明、科技、建筑详情统一 H1 页头、复制链接、费用首区块、统计卡和内容标签页；标签页同步 `tab` 参数，普通/精锐继续沿用现有单位 ID 路径，保留文明与科技配置。
- 单位精锐变化使用现有数据字段，升级费用和克制等资料保留；文明开局置于概览首块，评分明确标注主观参考。
- 模拟器先展示累计研究投入；PK、时间线、表格、列表和新资料页统一中性卡片及主题语义，不改变计算和游戏数据。
- 浅深两套主题均检查 360 / 375 / 390 / 1280，无页面横向溢出；手机主要控件至少 44px，行内链接至少 24px；表格数字和数字单位不拆行。

## 验证

新增主题、导航、详情与移动布局验收；使用 axe 对代表页面的真实渲染执行 `color-contrast` 检查，补足旧对比度脚本仅校验预设色表的局限。既有受保护版本验收不改期望值，领域计算和生成数据保持原样。

- #33 文明胜率、外链版或统计数据接入，继续按用户决定整体暂缓。
- #62 中不属于本次界面模板和通用样式的独立信息架构调整，后续逐条复核。
