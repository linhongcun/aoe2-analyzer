# 文明详情：文明历史

授权：维护者 2026-11-03 要求获取官方文明历史资料，并合理嵌入文明详情页。此项是新授权范围。

## 范围与来源

在 `#/civ/:en` 的概览末尾、现有来源说明之前增加独立的「文明历史」区。沿用现有详情页，不增加导航页或 Tab。保留 `?tab=history` 的「更新历史」补丁记录与现有语义。

覆盖当前 `src/data/civs.json` 的全部56个文明，按英文身份一一映射。来源仅使用实际打开核对过的 Forgotten Empires 开发商官网历史段落与 Age of Empires / World's Edge 官方文明介绍。每篇保留来源名称、完整 HTTPS 原文地址和核对日期。中文为本站撰写的简短整理摘要，明确标注，不能称官方译文；每篇控制在原文200词以内的信息量，不转载全文。原文只含短介绍时不扩写未经来源支持的历史，不从玩法加成推导史实。

## 视觉与状态

- 以独立 `article.detail-section` 呈现历史阅读内容，标题为 h2「文明历史」，沿用 `.detail-section` 的分区间距和边界；现有四块玩法 section 保持原结构。主文字 `--color-text`，次文字 `--color-muted`，链接 `--color-link`，无新增颜色。
- 默认显示一段约60–100字中文概览，字号 `--fs-body`，行高1.8；下方标注「根据官方资料整理的中文摘要」。
- 其后为原生 details / summary「展开历史背景」；展开后显示1–2段有序背景正文，summary可收起。每个点击目标至少44×44px。历史年份和数字单位用 `.nw` / `.num` 保持不换行。
- 来源链接始终可见，文案包含「官方原文」与出版者，原窗口打开，避免未告知的新窗口；核对日期为次文字并保持日期不换行。
- 360 / 375 / 390：正文自然换行，来源行可折为多行，展开控件整行；1280：沿用详情主栏宽度和侧栏，不新增多栏文字。明暗主题均使用现有令牌。
- 原文无更多历史段落时显示概览和来源，不提供空展开控件。没有已核实条目时显示「该文明的官方历史资料仍在核对中。」且不显示虚构来源或展开控件。当前56项应全部有已核实条目；空态用于后续新增文明。
- 内容本地打包，不依赖打开详情时再访问官方站点，无额外远端加载状态。路由切换文明或离开概览后再返回，默认收起；原生控件支持键盘与屏幕阅读器。

1. `#/civ/Chinese`、`#/civ/Franks`、`#/civ/Khitans` 与当前新增文明页出现各自历史，不能串文明；单测对照当前生成文明名单确保56项完整且无多余身份，来源域、核对日期与正文非空有效。
2. 默认背景正文隐藏，summary键盘可展开、可收起，展开不离开当前URL，收起后来源仍可见。概览切换或文明切换重置收起状态。
3. `#/civ/Chinese?tab=history` 仍显示原有补丁记录，不出现文明历史区；其余Tab和工具链接保持原功能。
4. 四宽明暗共8种展示无横向溢出、无 console error / pageerror；展开前后均查溢出，来源及summary命中44px目标，正文区通过WCAG 2A/2AA axe检查。保留对应截图供独立复核。
5. 失败验收：新增 `tests/e2e/civHistory.spec.ts` 在当前 main 的站点上应因找不到文明历史区而失败。新增数据覆盖与来源单测，不改受保护验收期望。
