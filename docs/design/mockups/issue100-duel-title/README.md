## 文案
副标题格式不变：`{文明} · {时代} · {费用}`。**时代取该侧 URL 参数**（`.1.` 黑暗时代 / `.2.` 封建时代 / `.3.` 城堡时代 / `.4.` 帝王时代）。

## 定稿口径（Steve 已定）
- 战斗模拟用每一侧 URL 自己的时代；标题、价格、模拟三者一致。
- 无时代参数（如 `a=38.Franks..f.`）：标题显示「帝王时代」，价格按帝王时代。
- 「按X时代价格」一行删除（见 #97/#103 稿）。
- 现有 N=11 / N=16 锚点用例参数改为 `.4.`；城堡时代另补用例，期望值以 Kent 实测为准。

## 令牌与数值
- 标题 h3：18px `--fs-h3` 700，`--color-text` #1d1d1f
- 副标题：13px `--fs-sm`，`--color-muted` #636366（5.99:1）
- 时代文字：13px 600，`--color-text-2` #3a3a3c（加重以便扫读，不用颜色区分）
- 费用组 `.res` 整体 `white-space: nowrap`，副标题允许整段折行（`overflow-wrap:anywhere`），不出现横向滚动
