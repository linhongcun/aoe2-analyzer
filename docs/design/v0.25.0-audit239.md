## 建议schema

```ts
type Mode = 'aoe2' | 'return-of-rome' | 'chronicles' | 'appearance' | 'audio' | 'graphics';
type ContentKind = 'civilizations' | 'campaigns' | 'scenarios' | 'cosmetics' | 'soundtrack' | 'graphics';
type Acquisition = 'base-game' | 'included-with-base' | 'paid-add-on' | 'free-download' | 'unverified';
type EvidenceStatus = 'verified' | 'unverified' | 'stale' | 'conflict';
interface Evidence {
  id: string;
  url: string;
  title: string;
  verifiedAt: string;
  publishedAt?: string;
  status: EvidenceStatus;
  note: string;
}
interface ContentBlock {
  mode: Mode;
  kind: ContentKind;
  names: { id: string; en: string; zh?: string; siteCivEn?: string }[];
  count?: number;
  summary: string;
  sourceIds: string[];
}
interface CatalogProduct {
  id: string;
  steamAppId: number;
  zh: string;
  en: string;
  releaseDate?: string;
  acquisition: { kind: Acquisition; sourceIds: string[] };
  prerequisites: { productIds: string[]; status: EvidenceStatus; note?: string; sourceIds: string[] };
  includedProductIds?: string[];
  // 可选回链历史发行组，不得用于权益推导
  historicalReleaseIndex?: number;
  contents: ContentBlock[];
  sources: Evidence[];
}
```

目录顶层写 `schemaVersion`、`platform:'steam'`、`verifiedAt`、`scope`、`region:'unspecified-public-store'`、`products`。`productIds: []` 只在已证实无前置时表示不需要其他产品；`status:'unverified'` 时必须显示未知，不将空数组渲染成“无需本体”。内容实体ID带模式：`aoe2:Romans` / `return-of-rome:Romans`；Chronicles Macedonians与RoR Macedonians同理。`siteCivEn`仅赋给现有56常规文明，其他不创建死链接。

最关键的筛选函数必须在同一content block上取交集：

```ts
products.filter((p) => p.contents.some((b) => (!mode || b.mode === mode) && (!kind || b.kind === kind)));
```

不能先聚合全卡 `modes.includes(mode) && kinds.includes(kind)`：RoR的常规AoE2 Romans与RoR战役会被错误拼成“常规AoE2战役”。关键词搜索与过滤同样取交集。搜索可以先产品级匹配标题，内容级匹配名称；要固定语义，避免产品标题匹配又绕过mode/kind。

## 可直接变成AC的关键例子

1. **Burgundians历史与购买不混淆**：文明详情仍标“西方霸主首发”；目录西方霸主显示“当前本体购买项已包含”，没有“必须单独购买”文案。原DLCS14期、各期数量 `[13,5,5,4,4,4,2,2,3,1,2,5,3,3]` 及56文明映射保持不变。
2. **单人剧本也可搜**：搜索 `Victors` 或 `Ragnar`，命中19单人剧本包；不要求有 `civs.length`。筛“常规AoE2+单人剧本”命中该包，搜索不匹配则无结果。
3. **RoR交集**：模式=`aoe2`、类型=`campaigns` 时不显示RoR；模式=`return-of-rome`、类型=`campaigns` 时显示RoR七战役；模式=`aoe2`、类型=`civilizations` 时显示RoR的Romans。RoR的Trajan/17文明不误显示为本站常规56文明。
4. **Chronicles**：模式=`chronicles`、类型=`civilizations` 恰有希腊之战和亚历山大两包；各3文明；无常规文明详情死链，标注不进排位和支持自定义/AI。Alexander前置仅本体，不添加Battle for Greece依赖。
5. **年代不当模式**：三国、最后酋长、维京传奇均命中常规AoE2文明，不命中Chronicles；新包不改变原Chinese、Vikings等文明的权益。
6. **免费与外观**：筛`graphics`命中画质包，显示免费可选下载及需本体；筛`cosmetics`命中且仅命中三头像包，各8动态头像；不声称增加战役/文明。
7. **真实未知状态**：原声产品显示已核实音乐内容/另购，同时前置字段明确“暂未核实”；不因为该字段缺证给它写“必需购买本体”或“无需本体”。另用测试夹具模拟missing/stale/conflict，断言不输出已证实的购买建议，不伪造线上商品来展示空态。
8. **来源齐全**：每张卡能打开HTTPS官方/Steam商品页，能读到平台Steam、2026-10-20核对日期；已包含关系能追到本体购买项或五周年公告；无动态价格。
9. **交集无结果保留选择**：`chronicles+cosmetics`结果为0，保留两个筛选值、显示可操作的清空入口；屏幕阅读器读到结果数量，选择控件有标签，键盘可操作。
10. **页面完整性**：360/375/390/1280 × 深/浅主题均无横向溢出、console error、pageerror；长英文商品名可断行；数字+单位保持不换行；点击目标44px、正文≥12px、令牌颜色且AA对比度。
