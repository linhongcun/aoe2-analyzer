# #206 文明必备单位与科技组合筛选

实施规格，2026-10-19。依用户授权实现与独立复核，不代替 Steve / Kent 本人签字。数据口径为 DE Update 185872。

## 布局与交互

在文明列表既有筛选栏下增加“必备单位与科技”面板，沿用文明卡片和结果计数。面板依次展示标题及复制操作、名称搜索与类型选择、搜索候选、已选条件、计算口径。候选按具体单位形态 / 科技 ID 区分，不合并普通与精锐；点击原生按钮添加，已有项目不再出现。候选显示图标、中文名、英文名与生产 / 研究建筑；搜索支持现有数据中的中文、英文与拼音。

所有条件取 AND，并与已有名称、类型、DLC、团战位置筛选取交集。每个条件附详情链接和单项移除按钮。“清空组合条件”只清空新增条件，既有“清空筛选”清空全部。没有匹配时保留条件，允许逐项移除；不扩大查询或推荐其他文明。

## URL 与状态

- `#/civs?req=u:569,t:435` 表示游侠与血统，类型与 ID 联合标识；重复参数的所有条件参与 AND，有效重复条件去重。
- 当 URL 含 `req/q/ty/pos/dlc` 任一参数时，完整筛选均以 URL 为准，缺项为空，不叠加接收者的 sticky。裸 `#/civs` 延续旧 sticky 行为。只读打开分享链接不覆盖原 sticky。
- 裸入口只操作既有筛选时继续使用旧 sticky，不写 URL，完整刷新恢复默认。添加组合条件或已有显式筛选参数时，将完整筛选快照写 URL，空旧条件仍写空值，避免删除最后一个组合条件后意外恢复旧筛选。复制链接始终包含完整快照；显式链接的刷新、前进、后退和详情返回均由当前 URL 恢复。
- 复制操作包含全部条件；成功显示状态文本，失败时展示只读链接输入框供手动复制。
- 非法格式、不安全整数、未知或已移除 ID 保留为可删除的错误条件。此时计数显示“条件无效”，结果区阻止显示文明。孤立空条件也必须经过 URL 往返保留，不能变成有效空查询。
- 单位 / 科技与科技树均加载完毕前，有组合条件的页面展示加载状态，不先显示全部文明，也不将待加载 ID 误判为失效。

## 数据语义

以 `civStatus` 的 `u<id>/t<id> === 1` 和目录可用文明共同核对。单科技结果与科技详情一致；免费研究不影响“拥有科技”判定。游侠与萨瓦尔是不同条件，不能互相替代；普通与精锐单位分别查询。不计算队友解锁、升级效果或“满科技”推断。
