# #224 通用建筑驻军数据

`python3 scripts/garrison_general_build.py` 生成 `src/data/garrison_general.json` 与轻量入口清单 `garrison_hosts.json`；`--check` 比较完整再生成结果。旧 #218 的导出脚本和 JSON 保持独立。

所有游戏数字来自 `scripts/data_sources.json` 固定的 DE Update 185872 `.dat`：`SiegeEngineers/auto-mods@0c38027504532826c9922e4db77e2c1d33554291`，SHA256 `4aa2f0a719e88e5f1502517eddb27c669aeb40c2fe9d8c4f3eec7751c01e7baa`。解析器沿用固定的 `genieutils-py==0.1.2`。缓存和游戏数据文件不提交。

站内单位、建筑中英文和可用性沿用站内生成目录；新增对象先查询同一固定版本的科技树语言表。该语言表是精选子集，缺少牧畜、国王、圣物等名称时，脚本按 `.dat` 内部名称直接翻译为中文，并在 `extra_label` 中保存这些文字映射。文字映射不提供游戏数值。

## 结构与边界

- `units[id]`：站内对象、女村民、牧畜、弑君模式国王、圣物及持圣物僧侣、建筑时代形态与实际主/副/蓄力弹丸。保留原始分类、容量、穿刺和近战攻击、理论间隔、火力、总/最大弹丸、弹丸 ID、属性 163 大小类别、特征与战斗能力位、蓄力字段、当前 DE 单位任务和训练位置。
- `rosterIds`、`herdableIds`、`specialOccupantIds`、`relicIds` 区分候选占员和特殊存放通道。持圣物僧侣用于证明存放任务，不把它与僧侣再计成两个驻军单位。圣物容量和驻军槽位关系仍由领域模型明确决定，数据层不暗算。
- `buildings[id].eraForms` 为四时代的实际建筑单位 ID，`aliases` 为同目录建筑的时代形态，`predecessors` 保存原始升级链的前身，用于训练位置和圣物任务匹配。`produces` 是站内科技树收录的生产项目，并不表示任何文明、时代、前置科技下都能立即生产。
- `techs` 包含站内研究科技，`effects` 可以为空；`ageRules` 单列时代效果；`conditional` 和 `civs[].automatic` 还保留没有直接数值效果的自动标记科技。`requires` 与 `count` 保留原始 n-of 依赖。`civs[].disabled` 是原始科技树禁用项；`free` 要求原始研究时间与全部有效资源费用明确同时归零。
- `effects` 解码属性 2/9/10/16/30/54/63/65/102/107/130/163，只提取穿刺攻击类别用于火力模型。属性 9 的倍率低字节按百分数解码。时代形态目标映射回站内建筑 ID，同一原始类别命令对同一家族仅生效一次。
- `trainingLocations` 解码属性 158 选择的槽与属性 42 的新地点，因此无政府状态新增兵营训练位置不会覆盖城堡位置。`unitUpgradeTechs` 可将选定的精锐/升级形态视为对应升级已完成；`unitUnlockTechs` 仅记录原始启用命令，不能直接当作排他的强制前置。
- `civs[].baseOverrides` 显式记录文明原始基底差异，计算时须先应用到对应时代形态。当前导出仅有高棉民居的资源容量差异，不能因当前数值差异少就忽略此字段。

## 已核对的特殊情形

入口清单覆盖 20 种潜在建筑形态：自然驻军建筑、只能自产留驻的生产建筑，以及文明加成开启的高棉民居、瞿折罗磨坊和图皮聚落。容量大于零不等于允许任意单位回驻；生产留驻、主动回驻与圣物存放是独立通道。

当前 DE 必须读取 `unit.bird.tasks`。原始 `unit_headers` 中渔船缺少驻军任务，但实际 `bird.tasks` 有建筑目标；所有站内舰船中只有渔船有此主动驻军任务。因此不能按船坞的舰船类别位直接允许战船回驻。

普通船坞四时代实际 ID 为 45/133/47/51，总/最大弹丸分别为 1/1、1/4、1/5、1/6。城楼原始攻击和弹丸为零，其时代效果另加总弹丸 1/1/1、最大弹丸 5/3/4。直接使用目录 ID 的基底会漏掉时代变化。

条顿炮塔的容量与最大弹丸修正来自开局自动科技 353 的箭塔类别效果：容量加 5、最大弹丸加 4。垛口科技 11 在当前数据中给步兵属性 130 设为 -2.5，并没有这个炮塔上限修正。炮塔基础有主弹丸而原始总/最大弹丸为零，领域模型须单独处理这种主弹丸口径。

骡车 1808 保留 `type=80` 建筑结构，但可以移动、具有主动驻军任务且 `sizeClass=4`。它不在宿主入口清单中，但不能因为其结构类型而从驻军候选中丢失。武僧 1811、传教士 775、火焰骆驼 1263 同样证明必须优先应用显式大小类别，不能只按对象类别猜兼容性。

本脚本没有运行游戏客户端。导出证明原始字段与效果可复现；它不证明多箭、蓄力、炮塔、槽位等领域公式在同版本客户端已经实测。`engineVerifiedInPinnedBuild` 明确为 `false`。
