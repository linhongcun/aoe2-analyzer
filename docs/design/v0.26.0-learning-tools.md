## 共用设计

沿用 tokens.css 与编辑风。首屏依次呈现用途、模式/适用范围、关键选择或编辑入口；来源与长边界放在可展开的资料区，不能挤掉主要任务。1280 可用双栏，360/375/390 单列，内容 min-width:0，中文自然换行，普通数字与单位不折断。正文 15px、小字 13px、最小 12px；控件触点不小于 44px，键盘焦点可见，双主题 AA。图标用现有 Lucide，禁 emoji 图标。

覆盖默认/空草稿/未填写、未知、未覆盖、陈旧信息、无适用解释、无效参数、损坏或超长备份/链接、复制成功/失败、存储拒绝/容量不足、打印长文等状态。警告 role=alert，保存/复制反馈 role=status。非法恢复不得静默变成默认结论；明确保留原始链接/备份并提供用户主动重置，不能截断后声称成功。

所有资料有稳定 ID、来源性质、URL、核对日期和适用版本；真实发布时间未知时不猜测。游戏数字只读固定数据或可追溯官方规则，不从社区评论采纳旧数值。源页面实际打开范围与未核实项记录在审计中。

## #256 六张一局与观赛卡

固定六卡：goal（本局目标）、roles（TC/村民/侦察角色）、resources（经济转化）、ages（时代与发展/施压）、counters（条件化克制）、watching（观赛关注）。每卡有短解释、一个例子、自查问题和可核对的答案说明、细节链接、来源。自查是阅读辅助，不评分或证明用户学会。

默认范围为常规 AoE2 DE 随机地图、通用黑暗时代开局示例、明确的征服设置。显示模式/开局/胜利设置；游牧、帝国战争、文明特殊开局和战役脚本选择均提示未覆盖，不沿用通用起始人数或默认单位。正文优先讲角色而非无必要起始数字。征服、投降与其他可选胜利规则分开说明；奇观/圣物胜利不被描述成所有天梯默认。分数不等同已赢，兵种克制有数量/升级/地形/操作等条件。

URL v1 包含 card、context（standard/nomad/empire-wars/special-civ/campaign）和 victory（conquest/other/unknown），缺省为首卡/standard/conquest。全部键严格校验，未知/重复/非法键显示无效并允许显式重置；合法范围外参数保留并显示未覆盖。单卡选择/刷新/分享恢复完整条件。不复制术语、操作、购买或战役目录；链接现有页面，首版不聚合视频和赛事。

## #257 手填复盘和一个下局目标

一份随机地图 1v1 复盘草稿，最多 8 个事件和 8 次目标跟进尝试；单一目标可暂不填写，不做多目标课程和长期仪表盘。上下文含标题、地图、双方文明、已知游戏版本和可选比赛/视频链接，未知保留空值，不强填本站版本或首个文明。

事件按稳定 ID 编辑、调整顺序和删除，分字段记录：游戏时间、视频播放位置、当时可见事实、当时行动、回看新事实、可能解释、未解问题。两个时钟由用户分别记录，允许未知，不互推。三组可选引导为经济执行、军队用途/升级、侦察信息；引导不是自动诊断或所有文明统一阈值。

唯一目标含触发情境、想做的动作、观察标准；跟进尝试含可选日期、场景/备注、用户自报结果（未评估/做到/未做到/无法判断）与观察。结果不计算成功率、能力/胜率或败因。事实与回放全知信息分开，不能倒推当时必然该如何操作。

文本上限按 Unicode 码点计数：标题/地图/文明/版本各 120；事件各长文本、目标各字段、尝试场景/观察各 400；链接 2048；时间字段 32；日期 10。事件/尝试 ID 唯一且稳定。JSON v1 最大 256 KiB（UTF-8）。不截断字段或删除未知内容后宣称保存成功。

本机存储 key 为 aoe2-match-review-v1，JSON 结构版本 1。备份严格检查版本、对象键、类型、枚举、唯一 ID、数量、长度、总字节和禁止控制字符（长文允许换行/tab，不接受隐藏双向控制或孤立代理项）。结构安全与语义提示分开：输入中的非空错误时间/日期/链接保留可修正，不静默规范化成另一项；备份可恢复结构安全的未完成草稿，逐项显示语义提示。链接只允许明确 http/https 作为可点击链接；其他原文显示错误，不执行或抓取。

载入损坏存储不得在 mount 时覆盖；保留原始文本可复制备份和主动重置。保存失败明确告知当前修改未保存，并保留页面输入/可用备份；不假称落盘成功。同一 key 多标签已有变化须防止静默覆盖：以最后读取快照比较，冲突暂停自动保存并提供重载/保留本页草稿的明确操作，不能丢掉当前内容。

导入先预览并明确替换本页草稿，失败不得覆盖有效输入；本机保存与备份真实行为可见。输出设置允许选择上下文/事件/目标/尝试是否包含，默认全选；摘要预览、复制、打印使用同一份选定内容，备份始终包含完整草稿和输出设置。复制失败保留可手动选择文本，用户自己决定向何处发送；不自动联系教练/社区。

不上传/解析录像、不读截图或游戏、不自动计算 APM/闲置/浮动资源，不生成自动教练建议。打印用静态文本视图，全部选定内容跨页完整、长文本不截断，深色屏幕打印为白纸黑字；不只打印当前 textarea 高度。页面元数据不携带用户草稿内容。

## #258 两组侦察情报辨析

范围为常规开局、1v1 Arabia：early（早期生产建筑已见，但军队/持续投入未知）、walled（城堡阶段墙内外信息不全，发展与隐藏推进难分）。每组至少两个相容解释；资料固定列共同证据、不足以区分的观察、各解释补证与反证、下一次补查、条件/代价/风险/失效反例、来源。

不是另一个通用日志。输入只选固定观察、当前阶段/计划、该观察的游戏时间、用户明确标记陈旧与限定范围。观察状态区分见到/未见到/未知/在此时刻与限定可见区域内确认不存在；缺少范围或时刻的“不存在”不能当全图事实。未知/陈旧不自动变成没有军队、一定发展或必然转型。一个资源人数不唯一推导开局；不按固定分钟自动判真伪。可撤回信息并重算解释/缺失信息/补查。

共享状态 v1，严格键/类型/枚举/重复参数/长度校验；损坏参数无效并暂停解释，合法地图/阶段范围外显示未覆盖；全 unknown 可显示相容解释但先列共同未知和补查，不强推行动。输入字段/分支清单在 audit258 中先固定，再实现；所有解释为条件资料，不输出分数、确定预测、配比或胜率。

资料优先使用无需声称已就绪的观察动作；涉及具体单位/建筑/科技的立即执行建议时，核对文明、时代和前置或明确列为条件，不能套科技树最终资格。固定两组附分支清单与相反例用于独立来源/可复现场景复核，社区原问答只证明困惑，不证明战术正确。确认具体威胁后链接 #35/#242/#241 等既有应对，不复写它们。
