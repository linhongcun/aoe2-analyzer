## 这一刀的界面决定

单位页 `#/unit/:id` 概览固定一块「鲜为人知」，放在「造价与生产」正下方。没有条目也留着，正文写「暂无」。

文明页 `#/civ/:name` 概览按 #603 四卡。官方定位和特色兵种在能力评分卡的脚注里，不是卡外两大段。有洞察时，槽插在评分卡和文明加成卡之间。没有条目就不挂槽，不写「暂无」，评分卡下面直接是文明加成。

有内容时是短列表，同页可以有两条或更多；再加一条只多一行，外框不变。线框有内容的例子：单位页是撒克逊人的扈从部队（①自带标枪与无粮造价，②无粮步兵对照火矛兵）；文明页是孟加拉（③战车无粮造价，以及无粮骑兵 UU 对照骑士线）。两页都不写驻扎射箭，也不写「第一个」。
