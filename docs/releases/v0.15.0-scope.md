# v0.15.0 发布范围

维护者于 2026-10-19 授权按 #204、#205、#206 顺序开发、验证和部署。本版只包含 #205；允许在独立工作区准备代码及自动验证，必须在 v0.14.0 正式站点和 Release 核验完成后才合并本版功能、发布到 main。

## 本版功能

- 单位 PK 的 1v1 保存 A 的升级前方案并固定 B，选择 A 科技后显示前后与差值。
- 保留完整具体科技与同文明、时代、单位形态、团队条件，比较失效时解释原因。
- 展示新增前置闭包、基础研究费用与总研究时长，明确取消不退款及模型限制。
- 比较链接可还原，独立方案链接可核对；非法或不支持条件不能静默回退。

固定 DE 185872，不模拟射程、移动、地形、操作或科研期间的战斗。研究投入按基础价，注明文明科研折扣、免费科技、返金和研究速度未计入。具体行为见 `docs/design/issue205-upgrade-comparison-spec.md`。
