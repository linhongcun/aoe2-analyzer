# 文明详情背景插画

授权：维护者于2026-11-03明确要求从 `denniske/aoe2companion` 获取各文明背景图，用作文明详情页背景。

## 来源与范围

在 `#/civ/:en` 的标题区融入对应文明的历史插画，覆盖当前56个文明及全部详情Tab。固定上游 `d9e9ef68c761b3bd5304f704629662d41bee2d96`（2026-11-01），依据 `src/helper/civs.ts` 的 `civHistoryList` 实际映射，优先沿用其 `civs2` 版本。

素材为透明底线稿，36个早期文明主要为约233–460px方形，20个较新文明为1000px宽横幅。使用无损WebP、保留透明度和原始尺寸，不裁剪或重画。56项映射中有54份不同原图：波希米亚/条顿、意大利/西西里沿上游共用图片。每张保留源路径、原图/输出SHA256、尺寸、字节数；单图最多300KiB，仅请求当前文明的一张图片，不将所有图内联进JS。

素材与可复现导入器放在 `src/features/civs/`，由Vite输出带哈希的本地资源地址，兼容GitHub Pages子路径。背景独立于核心游戏数据和图标生成管线，不改游戏数据或现有素材pin。记录仓库与Microsoft游戏美术归属，不把无LICENSE的第三方仓库或游戏美术称为MIT素材。

## 视觉与状态

- 使用文明页局部wrapper和CSS伪元素背景，不修改共享DetailPage或body。标题区右侧保留画面，装饰层 `pointer-events: none`，不进入无障碍树，不遮挡复制或Tab操作。
- 桌面1280：标题卡最小高度264px、padding24px，画面在右侧约46%的区域，以contain保持比例；标题/图标在左侧，复制按钮在右上角使用原有实色底。标题、次文字、标签不直接叠在图案上。
- 窄屏360/375/390：标题卡上方预留160px画面及间距，文本和控件接在下方实色区域；不按横幅强行裁剪方形图，不让图片加载改变几何尺寸。继续使用原有标题字号、移动端图标和复制布局。
- 通过CSS alpha mask和 `--color-text` 令牌为插画着色，装饰透明度约0.30，使浅色显示深色线稿、深色显示浅色线稿；背景仍为 `--color-surface`。全部正文卡片保持实色。仅用现有设计令牌，不新增颜色。
- 页面底部提供「背景插画 · AoE2 Companion」原图链接和「© Microsoft」归属，字号 `--fs-xs`、链接 `--color-link`、点击高度至少44px。详细固定版本与转换信息留在来源清单和README。
- 加载前/失败时保留预留尺寸与正常主题底色，标题、Tabs和正文均可使用。未知文明无对应映射时不提供伪造图或来源，已存在的not-found流程保持原行为。
- SPA切换文明立即更新背景地址与来源；切换Tab保留本文明背景；离开文明页自然移除，单位等详情页无背景残留。无背景动画、轮播或额外开关。

## 验收

1. 对照 `src/data/civs.json` 保证56个英文身份完整对应原图，不猜URL；本地文件、输出SHA256、尺寸、透明度与清单匹配。Hindustanis等非机械文件名映射正确。
2. 中国方形图、丹麦横幅图在四宽×明暗主题均可成功加载，computed mask使用本地URL，contain不裁剪，无横向溢出、console error或pageerror；标题与控件通过WCAG 2A/2AA检查。
3. 延迟背景响应时标题可先读，释放图片后标题卡及正文首卡位置不变。主动模拟图片失败时主题底色、标题、Tab和复制按钮仍能使用，不产生JS异常。
4. 从 `Chinese?tab=data` 切到 `Danes?tab=data`，背景/来源同步更新且数据Tab保留；切至单位页后无背景wrapper，单位页伪元素没有残留mask。
5. 失败验收为新增 `tests/e2e/civBackgrounds.spec.ts`，在main基线因缺少背景wrapper/实际mask而失败；不改受保护用例。

验证：必要lint、类型/构建、严格分层；背景映射/输出校验单测、相关文明回归、四宽明暗截图与axe、加载/失败/SPA状态。CI沿既有civ-ui范围执行，不改CI策略。
