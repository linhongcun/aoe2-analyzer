## 页面与状态

`#/maps` 原有介绍之后、标准筛选之前加入独立 `details`，默认折叠。summary 为「SD3 猝死赛事图合集」加不可换行的「11 张」；不含「展开/收起」，避免与标准目录操作混淆。内容依次为赛事/来源说明、独立搜索、结果数、资料卡、工具入口。

- 搜索标签「搜索猝死赛事地图」，支持中英文及大小写、空格、连字符归一化。空查询显示全部11张；例如 Holy Hollow、holy-hollow、圣谷均命中同卡。输入不抢焦点。
- 每张卡用 `ul/li`、h4中英文标题、「暂无预览」占位、一句可追溯要点；不用 article、标准 `.map-selector` 或 `.map-overview`。普通地图详情始终是原唯一 article。
- 无结果显示「没有匹配的赛事地图」，独立「清除赛事搜索」恢复11张。折回再打开保留本页赛事查询；不写 URL、localStorage 或持久化。无运行时数据请求，因而不伪造加载/网络失败状态。
- 标准「搜索地图」、地图类型、选择、83张统计、默认8项预览、展开/收起、来源与边中路稿完全保留。赛事查询与标准查询/当前选择双向独立，标准无结果时合集仍可用。

共用真实站内入口 `/siege?unit=1258&n=1&bldg=109`，文字「用攻城拆建筑估算拆主城」。实际目的页必须预填1台攻城锤与城镇中心；邻近说明只按站内固定DE版本估算普通城镇中心，不模拟赛事机关、多主城失败条件或胜率，不把普通拆城结果声称为赛事模拟。

## 视觉与可访问性

沿地图页浅色编辑风和深色令牌。PC1280资料卡两列，360/375/390自然一列；仅新增局部 `.sd3-*` 选择器，不能影响标准目录或其它页面。

- 正文使用 `--fs-sm`（13px）及现有文字/弱化/链接令牌，标题沿现有h3/h4；文字不小于12px。
- 卡片使用 `--color-surface`、`--color-border`、`--radius-md`，间距使用 `--space-*`；无自定义色值或新图标。
- summary、搜索、清除及站内外链接实际触点至少44×44；计数与数字单位用 `.num/.nw`。无水平溢出、console error 或 pageerror；正式axe按同站wcag2a/wcag2aa配置核对展开内容。
- 用原生details/summary、label/input、列表和标题语义；键盘可打开、搜索、清除、访问链接并折回，不人为移动焦点。
