## 怎么看

用浏览器打开 `wire-overview-1280.html`（需要 `civ-overview.css`），或直接看 PNG。只做 PC 1280。图标方块上的字是 Lucide 名；实现换成图标，不把名字留在界面上。文明、单位、建筑上的灰块是原版图标的位置，实现用现有 `CivIcon` / `UnitIcon` / `BuildingIcon`。

## 这一刀的界面决定

概览主栏从连续正文改成四块：开局卡、评分卡、加成清单、优劣芯片。开局只露一行路线、匹配到的流程、次要「查看全部开局」；说明收在「路线说明」里。官方定位和特色兵种收进评分卡脚注。没有洞察条目就不占位。优势和劣势是芯片，位置单独一行。

线框用亚美尼亚，因为走查红圈图上的评分、加成和侧栏「同资料片：格鲁吉亚」都是这一页（文件名写成了格鲁吉亚）。规则不绑这一个文明。
