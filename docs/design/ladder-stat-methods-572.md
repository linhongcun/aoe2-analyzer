## 当前来源与边界

- `src/data/ladder-4v4-rm-e1200-1400-90d.json`：已有 56 行，胜率、出场率、出场人次及 `ci95Low` / `ci95High` 已显示。上下界原样保存了来源的 `wilsonLow` / `wilsonHigh`，方法为 Wilson 95% 置信区间；页面只把已有百分数舍入为两位小数，不重新估算。来源证据见 [4v4 快照说明](../data/ladder-4v4-rm-e1200-1400-90d.md)。
- `src/data/ladder-arabia-p185872.json`：已有胜率、出场率、出场人次；不含胜场或置信区间字段。样本为 114500 人次，不是来源页另列的完整对局总数。出场率直接读 `playRate`，它不等于逐行 `games / brackets[0].games`。不由舍入胜率反推胜场、区间或校正值。来源证据见 [阿拉伯快照说明](../data/ladder-arabia-p185872.md)。
- 两份快照的 `sample.unit` 均为 `player`；都没有技能校正字段。以后启用技能校正须先扩展 schema、固定可核实的来源与字段、明确统计口径，再实现切换。本轮不增加假开关，不把未核实上游处理叫作 Raw。

## 可验收界面

在现有表格卡片之首、表头之前放一块紧凑的“统计口径”说明，两行正文，不新建卡片、不加控件。沿用 `--color-muted`、`--color-line` 和现有无衬线字体，13px / 1.6 行高，12px 16px 内边距；段间4px，底部细分隔线。浅色编辑风和深色令牌都保持。数字、`95%` 使用 `.num` / `.nw`。

1. 两模式都显示：“胜率、出场率按快照原值展示；技能校正数据未收录。”
2. 玩家样本显示：“样本为玩家出场人次，不是完整对局数。”不把人次写成局。
3. 4v4 有完整上下界时显示：“95% 区间来自快照提供的 Wilson 置信区间。”继续展示已有的区间列和同一份数据。
4. 阿拉伯显示：“本快照未收录置信区间，不作估算。”不新增空区间列、零值或伪造上下界。缺少完整区间时仍按既有规则隐藏整列。
5. 没有快照的模式 / Elo 组合仍显示现有明确空态，不显示另一档表格或统计说明。

现有“怎么读表”里的胜率、出场率解释改用“来源公布口径”，不再把玩家出场统计笼统称为“完整对局占比”。尤其阿拉伯的 `playRate` 不能由本表 `games` 除以总人次重算；提示文字据此澄清，数值和排序保持。

说明区使用 `role="note"`、中文可访问名称“统计口径”，建议 `data-testid="ladder-stat-methods"`。仅表视图有说明；不重做分层或分布视图。已有出场列、窄屏展开样本、排序、低样本筛选和来源 / 截止 / 非当前平衡提示保持。
