采集时间怎么算

  1. 采集速度按城堡时代，该时代能研究的经济科技全部算上；选了文明就叠加文明加成。
  2. 食物按农田算，播种耗时计入（播种耗时 未核实）。
  3. 金和木离放置点 3 格，农田贴着磨坊；每趟 = 携带量 ÷ 采集速度 + 往返路程 ÷ 村民速度。
  4. 有文明折扣先按折扣价，再换算成时间。
