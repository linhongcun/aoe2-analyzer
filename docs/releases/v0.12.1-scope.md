# v0.12.1 修复范围

维护者在本会话明确选择 #192、#193、#194 作为本批修复。其他候选继续等待排期。游戏数据仍固定为 DE 185872。

## 范围与验收

- #192：单位列表使用同一形态满足全部筛选条件，卡片名称、属性、图标、版本和链接对应命中形态；无筛选及同时命中时保留普通代表和既有系列计数。
- #193：单位详情从与科技作用对象、模拟器同源的结构化规则查询相关科技；有文明上下文时过滤可研究项，独特科技注明文明，完整结果可查看，未建模的文本效果不冒充数值效果。
- #194：文明评分只描述相对强弱，删除从低评分推导缺兵种的建议；保留强项门槛及本方可用反制过滤。

每项先补失败用例，使用独立分支和 PR；不修改 `tests/**/v0*-acceptance*` 的期望、不手改生成游戏数据。各 issue 正文记录了具体复现与验收。

## 检查与集成

三项文件改动相互独立，建议按 #192、#193、#194 顺序集成到 `release/v0.12.1`。每项检查修复回归；发布前在合并后的代码运行 lint、类型检查、完整 Vitest、构建、完整 Playwright，并核对 360 / 375 / 390 / 1280 两主题下的页面与截图。

界面沿用已有浅色编辑风、组件与设计令牌；本批不进行设计改版。检查记录将附在 PR，实际部署结果以 GitHub Actions 为准。

## 不在范围

- #195 科技首发版本专项核对。
- #196 文明与兵种筛选。
- #197 开局模拟文明覆盖扩展。
- #33 文明强度统计与外部胜率数据。
- 新的兵种推荐引擎、时代选择、游戏数据更新或其他视觉改版。
