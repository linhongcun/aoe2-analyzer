# #204 持续生产工具规格

本规格随用户于 2026-10-19 授权的 #204 开发提交，供审查；不代表 Steve 或 Kent 签字。数据版本固定为 DE 185872，游戏数值只读取仓库生成数据。

## 布局与交互

- 路由 `#/production`，首页工具卡和工具导航可达。标题、文明、时代、复制链接按钮在顶部。
- 360 / 375 / 390 px：单列，文明和时代两列；结果摘要位于设置之后、生产需求之前，添加或编辑需求后原位更新。资源摘要两列卡片，每个数值和单位不换行；生产行按单位、建筑、建筑数量、删除按钮纵向排列。
- 1280 px：设置与结果摘要在上方，需求列表和科技设置并排；每条需求可在内部两列排列。容器使用 `minmax(0,1fr)` 和 `min-width:0`，无页面横向滚动。
- 每行建筑专用于该行单位；允许重复行。最多 12 行，建筑数为 0–100 整数，0 为暂停需求。添加行默认选择当前文明时代可用的村民及城镇中心；文明或时代变化后不静默替换已有需求，显示对应不可用错误并要求重新选择。
- 科技按经济（城镇中心、伐木场、采矿场、磨坊）和生产相关建筑分组，复选框显式控制；“经济科技全研究”只选当前文明时代可用项目，清空保留确认为免费的科技。前置科技联动选择，取消前置会取消后续科技。
- 参数直接写入 URL，复制完整当前 URL；刷新、前进后退还原文明、时代、距离、需求和科技。非法 URL 不悄悄计算为有效方案：显示原因、清除无效项后再计算，提供重置按钮。

## 状态与令牌

- 加载：沿用全站 Loading；空需求：显示“添加生产需求后查看配置”；零建筑：单行显示“已暂停”，总配置为零。
- 错误：文字说明具体行号和原因，阻止输出部分结果；非法数量保持输入，显示 0–100 整数约束。上限按钮置灰并显示上限；分享失败显示可手动复制的 URL。
- 未计入：结果旁展示具体文明、科技或机制原因；不能只写泛化“可能不准”。基础成本、训练时间、每分钟产量和各资源收入有明确单位。
- 使用 `--color-surface` / `--color-surface-2` / `--color-border` / `--color-text` / `--color-muted`；错误 `--color-bad`，提醒 `--color-warn`。字号正文 `--fs-body`，说明 `--fs-sm`，最小 `--fs-xs`；间距 `--space-2/3/4/6`，圆角 `--radius-md`；按钮和输入最小高度 44px。图标仅现有 Lucide `calculator`、`plus`、`x`、`copy`。

## 计算与支持机制

1. 单位、建筑、科技可用性以当前文明科技树、目录文明列表和时代共同校验；明确编码数据中说明的提前解锁（亚美尼亚步兵、勃艮第重装骑士、波希米亚火枪手、库曼攻城锤与中型冲车、勃艮第经济科技）。多建筑使用 eco.units.at / timeAt，额外生产建筑须具备对应解锁科技。
2. 基础单价、训练秒数来自 eco.json。被动文明折扣使用已有 `discountedCost`（保留已核实/未计入和 0.5 取整口径）。显式生产科技读取 effects.json 的费用属性、训练时间及建筑工作效率；未知联动整项不计并列原因。
3. 生产速度 = 基础训练时间 × 单位训练时间倍率 ÷ 建筑工作效率倍率。计本文明团队加成，其他盟友加成不计。城镇中心和码头的时代形态按所选时代匹配，避免把黑暗时代倍率重复应用到后续时代。
4. 经济科技只计入显式集合；默认不自动全研究。免费科技通过 effects.json 验证所有原价资源和研究时间均被设为零，再自动生效，不能直接相信 eco.civEco.freeTech（部分零资源费用被误判为免费）。测试覆盖维京、波希米亚与越南经济升级误判。既有 realCost 默认按时代全研究行为不变。
5. 采集沿用真实费用已核实的文明加成清单、有效采集模型和未支持提示；允许设置木金石与农田单程距离（0–10 格），默认分别为 3 / 1 格；农田设为 0 时提示不会体现推车移速和携带量的全部实际收益。新显式集合不改变旧 API 默认值。
6. 每行单位/分钟 = 建筑数 × 60 / 实际训练秒数；同资源开销先汇总，理论村民数 = 总开销/每村民分钟采集量，最后按资源向上取整，保留未取整值供审查。
7. 不计农田补种、住房扩建、生产建筑建设、科技研究投入、资源耗尽、战斗损失、自动赠送单位、额外资源产出和实战操作；这些限制直接展示在结果旁。未知文明采集机制按通用速度并列具体名称；不输出“保证不停产”。

已核对的生产特殊机制：自身团队生产加成；波斯 TC/码头随时代形态；阿兹特克类别训练倍率；征招、井喷、骑士精神、造船匠；卡曼达兰等固定数据可完整表达的费用变化。化学控制火枪手、炮舰（含精锐）与手推炮；无政府、掠夺者控制附加生产地点；弗拉芒革命控制弗拉芒民兵。马普切聚落缺少可靠地点映射，首版不开放；土堡等带未解码资源标记的生产科技整项排除并说明。丹麦存放食物等未建模经济机制以文明原文列明。
