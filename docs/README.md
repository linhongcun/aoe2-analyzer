5. [贡献与授权规则](../CONTRIBUTING.md)、[维护说明](MAINTENANCE.md)及[角色指南索引](../role/README.md)，包括[产品管理](../role/product-management.md)、[体验设计](../role/experience-design.md)与[软件开发](../role/software-development.md)。

当前需求、授权、设计图和交付证据以原 Issue 为准；版本摘要见 [CHANGELOG](../CHANGELOG.md)，发布核验流程见[发布流程](RELEASING.md)。`EFFECTS-AUDIT.md`、`ECO-DATA.md`、`HISTORY-DATA.md` 与 `PATCH-NOTES/` 属于生成或被流程消费的资料，应由各自来源/生成器维护，不作为自由编辑的历史手册；`docs/design/` 下 JSON 是固定来源、生成结果或验证证据，按其索引和来源规则维护，不在文档清理中改写。仓库不另存一次性功能规格或逐版本交付日志。
