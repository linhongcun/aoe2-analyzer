# v0.19.0：开局专注跟练与打印

维护者在本会话明确授权按 #214 → #215 → #216 → #217 → #218 完成开发、验证和部署。本版只新增 #216，设计规格见 `docs/design/issue216-spec.md`。此前已完成的功能保留并回归。

已有开局可进入专注跟练，突出当前动作与下一步，手动推进、撤回和重置，手机推进后定位到当前卡片（#216）。
可打印完整步骤清单，保留来源、参数、村民分配、文明支持限制与估算说明；深色网页也以白底黑字打印。

## 边界

手动进度不代表游戏已完成动作，不读取游戏画面或资源，也不提供自动计时、全局快捷键或悬浮窗。

使用已有开局及模拟范围，不扩展开局文明机制覆盖；未支持文明仍明确按通用估算。
