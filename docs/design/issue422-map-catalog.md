# 常见地图库验收规格

本次补齐黑森林等常见地图，并把四类资料扩为可搜索的地图库。资料范围为 AoE2 Companion 双语 API 快照与固定官方预览图的交集，共 83 张标准随机地图；常用 30 张优先排列。争夺圣物、随机选择器与其他模式不进入目录。此目录不代表实时天梯池或当前游戏的完整地图清单。

## 来源与内容

- 名称和原始地图说明使用 `zh-hans`、`en` API 归档快照；以地图 ID 唯一标识，不能按中文名称去重。浅滩、沼泽等重名条目同时显示英文。
- 图来自 denniske/aoe2companion 固定提交 `155d64511a22570ff49b47edb73355464063e428` 的 `app/assets/maps/`，经 SHA256 校验生成本地 WebP。阿塔卡马原图为 423×420，其他图为 420×420，保持比例，不裁切地图。
- 侦察与开局提示是本站根据地形整理的建议，不添加资源数量、胜率或未经核对的文明推荐。阿拉伯、竞技场、游牧及岛屿保留原有详细开局和文明跳转。
- 详情保留图像版权、固定图源、API 来源及核对日期。原始 API 快照与图源同在固定来源清单登记，脚本默认不读取实时 API。

## 查找与选择

- 标题仍为“地图与开局”，显示实际收录数量。
- 搜索框有可见“搜索地图”标签，匹配中文、英文、地图 ID 与英文首字母，例如“黑森”“Black Forest”“blackforest”“BF”。空格、连字符、下划线归一化，大小写不敏感。
- 单一“地图类型”下拉可选全部、开放陆图、封闭陆图、水陆混合、海图、游牧开局、其他地图；与搜索条件取交集，不提供功能重复的第二套筛选控件。
- 默认展示排序靠前的 8 张图，可展开全部匹配结果及收起。若当前选择不在前 8 张，紧随常用入口保留当前项，使选中状态可见。
- 搜索与类型变化收起扩展列表。若原选择不匹配，显示第一张匹配地图；无匹配时显示明确空状态和“清除筛选”，不显示不匹配的地图详情。清除恢复全部类型和空查询。
- 入口使用游戏预览与中英名。原生按钮通过 `aria-pressed` 表示当前选择，统一控制恒定的 `map-details` 面板。
- 每次只显示一张地图详情。点击或 Enter 选图后焦点进入详情并滚到标题；初次加载与输入搜索时不抢焦点。再次选择当前项仍可定位详情。
- 初次选中排序首项阿拉伯半岛。筛选导致显式选择不匹配时，临时显示第一匹配项；清除筛选后恢复仍存在的显式选择。输入与清除不移动焦点。搜索同时接纳原 `rm_` 前缀 ID 和站内去前缀 ID。

## 布局与样式

360 / 375 / 390 为双列入口，1280 为四列。入口图约 88px，详情预览最大宽 224px、保持原比例，窄屏放在文字上方，640px 及以上与说明并排。图库图片使用延迟加载，默认首屏不请求全部 83 张。

颜色只用既有 `--color-*` 令牌；标题、正文和说明沿用 `--fs-h3`、`--fs-body`、`--fs-sm`，文字不小于 12px。输入、选择、清除与展开按钮至少 44px 高，地图按钮至少 44×44。数字数量使用 `.num` / `.nw`。不引入渐变、纹理或新的界面图标。

## 验证

- 先在旧页面证明黑森林查找与地图目录行为缺失，再验证实现通过。
- 覆盖 83 个唯一地图 ID、全部本地图片存在及解码、归档快照与固定来源哈希、重名中文不去重。
- 四宽浅深色覆盖搜索、分类、无结果与恢复、展开收起、选择与键盘定位、预览比例、无横向滚动和页面报错，以及 WCAG AA。
- 旧四类地图的开局、文明、码头与渔船说明继续可操作。
- 固定生成脚本 `--check`、完整 CI、实际 Pages 页脚和线上地图专项通过后正式发布。
