## 裁切
第 13 步那一行在页面上离摘要约 1000 CSS px，1200×630 和 1080×1350 都放不进一张连续截图。所以每个尺寸截两段真实截图上下拼接，中间用一条细分隔条标出拼接处，数字都不改：

| 版本 | 输出 | 视口 / DPR | A：摘要+时间线（CSS px） | B：卡点步骤行 |
|---|---|---|---|---|
| 电脑 | 1200×630 | 1280×900 / 2 | x20 y215 w1240 h400 | 高 243，下沿在第 13 步下方 44px |
| 手机 | 1080×1350（4:5） | 390×844 / 1080/390 | x0 y84 w390 h350 | 高 130，下沿在第 13 步下方 30px |

B 的 y 是运行时按「主要卡点」里的步号找到那一行的位置算出来的，所以步号变了也能对上。尺寸和 #19 分享卡一致。

- 包含：① 琥珀色到达时间 ② 主要卡点 ③「按{文明}计」④ 时间线前段 ⑤ 第 13 步那一行
