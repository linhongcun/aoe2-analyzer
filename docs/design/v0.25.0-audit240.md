## 建议schema与模块边界

实现文件按根合同：`src/content/campaigns.json`手工策展数据；`src/domain/campaigns.ts`纯查询；`src/features/campaigns/Campaigns.tsx`、`campaigns.css`；`docs/CAMPAIGNS.md`；`campaigns240`单测/e2e。它不是`src/data`自动生成文件，不更改数据生成器或已有DLC首发表。

```ts
type Campaign = {
  id: string;
  nameZh: string;
  nameEn: string;
  aliases: string[];
  kind: 'tutorial' | 'campaign' | 'historical-battle';
  modeId: 'aoe2' | 'chronicles' | 'return-of-rome';
  civilizationIds: string[]; // 复用civs.json现有英文稳定键
  regionIds: ('europe' | 'asia' | 'africa' | 'americas')[];
  settingZh: string; // 说明地区多标签为何存在
  originalContentPackId: 'age-of-kings' | 'the-conquerors';
  contentPackId: string; // 本批全部base，仅联接#239购买导航
  releaseYear: number | null;
  releaseDate: string | null;
  catalogOrder: number; // 固定策展并列序号，不暗示同包先后发行
  historicalStartYear: number | null;
  historicalEndYear: number | null;
  swords: 1 | 2 | 3 | null;
  verifiedAt: string;
  fieldEvidence: Record<
    string,
    {
      sourceIds: string[];
      locator?: string;
      status: string;
      note?: string;
    }
  >;
};
```

顶层`sources`保留title/url/kind/checkedAt/version；GitHub镜像保留完整commit、SHA256。每项逐字段证据必须覆盖nameZh、nameEn、kind、mode、civilization、region、originalContentPack、releaseYear、historicalRange、swords。派生地理标签标`editorial-derived`，没有证据的剑数标`not-provided`；不为null制造引用。

地区标签规则：按开发方剧情简介与对应客户端叙事地点归纳，**不是游戏菜单分组**。萨拉丁是非洲+亚洲，成吉思汗是亚洲+欧洲，巴巴罗萨是欧洲+亚洲；同项命中任一标签即可。JSON已逐条定位，历史战役为欧洲，不把Historical Battles菜单所在位置错误当“非洲”。当前购买要求只跳`/content-guide?pack=base`；`base`不被解释成历史上的AoK/AoC两商品。

## 查询、排序与覆盖范围边界

- 路由`/campaigns`。建议参数`q`、`region`、`type`、`releasePack`、`sort=release|history`；根规格可定最终名称。首发包筛选UI明确写“首发内容包”，与当前购买外键`contentPackId`分开，勿让`pack=base`和`age-of-kings`同义。URL用`URLSearchParams`序列化，HashRouter内query，不操作hash外location.search。
- 搜索仅匹配中英文标题与明确本站别名；trim、NFKC、大小写归一、合并空白；全角标点/中点/空格可统一后匹配。输入不得拼正则；不把玩家文明名、年代默认当标题。`EL CID`、`Joan of Arc`、`威廉华莱士`、`蒙特祖玛`可复现命中。
- 不同筛选维度取交集；`q`同样参与交集，地区成员关系即可。失配时保留输入与筛选，不自动重置；“清除条件”可恢复10条。
- 发售排序用`releaseYear`升序，未知年末尾，再`catalogOrder`升序，再ASCII稳定`id`；同包是同次发布，不宣称包内叙事先后等于发售先后。日期只有年精度不补1月1日。默认发售排序即表内10条顺序。
- 历史排序用已知`historicalStartYear`升序，未知起点末尾，再`catalogOrder`、`id`稳定并列；结束年不参与排序。预期本批顺序：阿提拉、熙德、黑斯廷斯、巴巴罗萨、萨拉丁、成吉思汗、华莱士、阿金库尔、贞德、蒙提祖马。区间重叠原样显示，不切分虚假的单一路线；Barbarossa1152–1191与Saladin1163–1191同时存在。只知终点不推起点。单年只显示1066/1415。
- URL非法枚举回退“全部”或默认sort，未知参数忽略；不要把未知筛选值变成现实数据项。URL刷新、粘贴、前进后退恢复筛选与排序。
- 教程常驻入口指向华莱士结果，可用`/campaigns?type=tutorial`。它不因历史排序被误标“最早”或“最容易”。
- 顶部覆盖声明：首批10项，教程1、战役7、历史战役2。历史战役是独立关卡类型，当前仅两项。常规AoE2的其他战役、孙子兵法、Chronicles、Return of Rome、合作变体与模组暂未收录；“没有结果”说明“当前有限目录暂未收录或没有符合条件的条目”，不说游戏不存在。
- 无运行时抓取/账号登录/Steam成就同步/存档上传；不给唯一必玩顺序，不补逐关攻略或剧情梗概长文。
