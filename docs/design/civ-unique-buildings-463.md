# 文明独特建筑侧栏（#463）

无内容模块的空态规则现由[#465隐藏空模块规格](civ-empty-modules-465.md)取代：加载完成后空模块不渲染。

维护者指出文明详情缺少独特建筑，例如保加利亚营垒。新增与区域建筑一致的紧凑卡片，建筑区按独特在前、区域在后排列。

- 顺序：独特单位、区域单位、独特建筑、区域建筑、快速入口；各tab共用侧栏。1280沿既有右栏，360/375/390沿既有正文后布局。正文不新增大模块。
- 内容：复用SideBlock、uchips、ulink、BuildingIcon，只有标题、游戏图标和名称，局部样式仅设置44×44px最小触控区域。字号、边框、圆角、间距和浅深配色全部沿用现有令牌。
- 身份：固定[aoe2techtree@3bb43b1](https://github.com/SiegeEngineers/aoe2techtree/tree/3bb43b1439eef88dfe7fe892d7f7dc41ac9dd76f/data/trees)的UniqueBuilding节点为1021大商站、1189巨港、1251营垒、1665城楼、1734大庄园。独立代理实际核对全部56树，拥有者分别为Portuguese/Malay/Bulgarians/Sicilians/Poles，与现有Building.civs一致。生成目录未保留node_type，因此沿用有来源的精确ID集合；不使用civs数量猜测，也不混入区域建筑（含契丹牧场）。下次更新DE来源时复核集合。
- 查询：在现有纯展示domain/civBuildings.ts增加只读投影，按输入civs动态筛选，保留原对象和目录顺序；不复制文明归属表。区域查询保持不变。
- 链接：与现有区域建筑一致，`/building/:id?civ=:civ&age=:age`，时代参数读取现有目录字段；建筑模拟器继续按既有规则校验可用性。营垒链接为`/building/1251?civ=Bulgarians&age=3`；切模拟器和刷新保留文明与时代。不校正目录时代或修改建筑详情行为。
- 状态：未加载用role=status“正在加载独特建筑…”；确无项目用“本文明没有独特建筑。”。切文明立即重算，不保留旧项目；无独特建筑也保留短空态卡片，与区域模块一致。
- 验收：所有56文明矩阵、五类完整性及区域/普通负例、动态可用性、只读性；五文明可见、其它文明空态、受控延迟加载、tab/刷新、营垒进入模拟器；四宽×双主题截图，44px、键盘、axe与无错误/溢出。

树交叉核验边界：营垒、城楼、大庄园有独立列；巨港是船坞内building cell；大商站因空grid不进入本地trees，不要求所有项目都有列。既有区域建筑/单位测试仅迁移标题顺序，内容和行为断言保留；新增独特建筑短烟测。不改受保护验收、生成数据/管线、计算、全站建筑分类或单位分类；沿文明相关范围验证，未变数据不再生成。
