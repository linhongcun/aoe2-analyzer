# 文明与开局资料适用范围（#480）

冻结基线：`6b9cc7eb3ddef630888145cdedd8be73f7deaf0e`，DE Update 188329，计划版本 `0.60.0`。本规格落实已通过独立预检的 `/tmp/issue480-preflight.txt` 及 `/tmp/batch-protected-readiness.txt`；实现与实际先红记录另附验证收据。范围只改变现有文明/开局页面的选择、说明和链接。

## 行为

文明页保留“推荐开局”语义区、原 `c.op` 的有序列表及名称展示流程。局部纯函数先选择全部 `bo.civs` 包含当前文明的流程，保持目录顺序并按 ID 去重，显示“资料标注适用的开局流程”。空文明名单不等于所有文明，不参与明确匹配。

邻接说明区分原兵种转型路线参考与按资料适用名单列出的起手流程；例如玛雅原雄鹰路线继续保留，而开局入口显示资料明确列出的弓手流程。

没有明确匹配时，只复用原 `openingBuildIds(c.op)` 的首阶段结果，保留其顺序，显示“通用流程示意”，每个链接旁单独标“通用示意”，说明“暂无资料标注适用的流程，请结合文明加成调整”。既没有明确匹配、也没有旧首阶段匹配时显示“暂无匹配流程”，保留“查看全部开局”。不新增方案或推导最优、专属资格。

每个文明页流程链接带原 `bo` 和当前 `civ`。原链接文字保持完整可访问名称，尤其蒙古的“18 人口侦察骑兵速攻（单马厩）”；标签位于链接之外。原有序列表不增加 `li`，保留蒙古的两个路线项。

时间线在原 `section#builds` **之前**增加独立语义区域，名称“开局适用文明”，宽度与计算器相同。其内容与列表展开详情复用同一 feature-local 展示组件：直接从所选原始 `bo.civs` 展示文明名称及 `/civ/<en>` 链接；空名单仅显示“通用”。不改变列表 `summary` 的名称、顺序或未支持标记。

时间线非空名单不包含当前请求文明时，在邻近显示“资料未列出该文明，当前作为通用示意”。读取既有解析后的 `q.civ`，不读取未校验原始参数，也不使用回退后的 `simCiv`。因此汉等未支持文明保留资料范围说明和原模拟限制；关闭原限制提示不会移除此处说明。缺省、未知及 Generic 参数继续沿用原解析口径。名单为空时不制造排除名单。

跟练/打印仍走原分支、原内容与链接。`bo.civs`、全部开局 JSON、`c.op`、domain/simulator、数据及 CI 政策不修改。

## 界面与状态

- 沿用既有链接、字体与 token。正文沿用页面 15px；说明与通用标签使用 `--fs-sm`（13px），不低于 12px；新资料标题使用 `--fs-sm` 粗体。链接用 `--color-link`，说明用 `--color-muted`，面板用 `--color-surface`、`--color-border`、`--radius-md` 和 `--space-*`。
- 文明流程仍为纵向链接；通用标签可在窄屏换到邻近下一行，不进入链接名称。新反查链接可换行排列，每个触控框至少 44×44px，焦点可见。数字与“数字+单位”用 `.num/.nw` 包裹而不改变原文本。
- 明确匹配、通用回退、无匹配、空名单、当前文明不在名单、未支持文明、异步核心未就绪都保留明确的静态内容。选择依赖本地已加载开局/文明登记，不新增网络请求；原核心名称加载和错误处理保持。
- 新面板只存在于正常时间线分支，位于移动端固定分享栏之前的正常文档流。原 `#builds` 全部节点、文字、数值和计算区保留；不移动其内容，不过滤金标准捕获。
