# #97 + #103 定稿 · PK 等资源费用块与来源浮层（v0.6.0，#109）

合为一张稿，两边验收同时满足。`mockup.html` 基于 `src/shared/styles/base.css` 中 `.pk-*` 现有样式复刻；截图 `pk-discount-{360,375,390,1280}.png`（移动端 2x）。

## 改法
1. **#97-1 去绿底**：`.pk-applied` 背景 `--color-good-soft` → `--color-surface` #ffffff（不再有任何绿色行底）；仅勾图标 `--color-good` #1f7a35（5.39:1）；文字 `--color-muted` #636366 12px。
2. **#97-2 百分比只一次**：内联行前缀只写「已计入：{文明}」，百分比只留在下方原文 `.pk-orig`；浮层「已计入」条目写 `{label} −{pct}%（{时代}）`，label 本身不带 %。所有负号统一显示为 U+2212「−」（原文里的连字符 `-` 渲染时替换）。
3. **#103 标签**：有折扣的格子显示 `原价 ~~55~~  实际 **47**`：
   - 标签「原价」「实际」：12px `--fs-xs`，`--color-muted` #636366，左间距 8px（首个 0）、右间距 4px
   - 原价数字：15px `--fs-body`，`--color-muted`，删除线
   - 实际数字：15px 700，`--color-accent` #a65a14（5.13:1）
   - 派出数量行：标签用「按原价」/「实际」，实际数字 28px `--fs-num-xl` 700
   - 没变化的格子只显示单个数字，不加标签
   - 单元格 `white-space: nowrap`，四档宽度不折行
4. 「按X时代价格」`.pk-basis` 从数字前移到表格上方单独一行（12px muted），避免和标签挤在同一格；#100 修好后正常不会出现，只做兜底。

## 状态清单
S1 已计入·全部资源有折扣 / S2 已计入·浮层展开 / S3 已计入·部分资源有折扣·数量不变 / S4 未计入（尚未核实）/ S5 折扣未计入（数据对不上）/ S6 无可计入加成 / S7 取价时代≠标题时代（兜底）/ S8 非等资源模式（不渲染）。
