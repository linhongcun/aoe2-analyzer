# 普通 / 精锐单位去重设计（ELITE-DEDUP）

## 背景

游戏里大部分独特单位和部分区域单位都有「普通 + 精锐」两档，比如掷斧兵和精锐掷斧兵。两者名字、图标、定位都一样，只差一次城堡升级和少量数值。以前站点把它们当作两个独立单位，到处成对出现，信息密度低，也容易看漏。

## 规则

| 概念 | 判定 | 处理 |
| --- | --- | --- |
| 精锐家族 | 英文名为 `Elite X`，且存在普通单位 `X`（78 个精锐，全部配对成功；精锐钦察 1260 没有 `from_`，按名称配对） | **合并为一个条目**，名字后加「精锐」小标 |
| 同名多 id | 例如答刺罕（马厩/城堡两个 id）、近卫军、保加利亚骑兵：英文名相同 | 列表里只保留第一个，避免同一单位重复出现 |
| 中文同名、英文不同 | 楼船（Thirisadai 1750 / Lou Chuan 1948）、战车（War Chariot 1962 / Ratha 1759） | 各算一个，两个都出现在列表里（#14） |
| 有独立名称的升级路线 | 骑士、重骑士、圣骑士；弓箭手、弩手、劲弩手；掷矛手、精锐掷矛手、帝国掷矛手 | **不合并**，因为这些是名字不同、定位不同的单位。只在「作用对象」里按路线合成一组 |

实现：`src/domain/family.ts`（`buildFamilies` / `collapse` / `groupLines`），在 `loadCore()` 时生成 `core.fam`，各页面共用。

## 逐场景前后对比

| # | 场景 | 之前 | 之后 |
| --- | --- | --- | --- |
| 1 | 文明详情 · 侧栏「独特单位」 | 狂战士、精锐狂战士两个标签 | 只有「狂战士」一个标签，后面带「精锐」小标 |
| 2 | 单位列表 `#/units` | 248 张卡片，普通版和精锐版各一张 | 163 张卡片，有精锐版的卡片标题带「精锐」小标；搜「精锐掷斧兵」也能找到这张卡 |
| 3 | 单位详情 | 普通和精锐各一页，互相只能从升级路线跳 | 标题下有「普通 / 精锐」切换。概览顶部有「普通与精锐对比」表，只列有变化的属性和克制加成，下面写精锐升级的费用和时间。旧的精锐链接，比如 `#/unit/531`，仍然能打开，打开后选中的是「精锐」。切换时保留模拟器路径（文明、时代、已选科技） |
| 4 | 科技「作用对象」 | 血统的骑兵组有 70 多个标签，一半是「精锐…」 | 每个家族一个标签。同一升级路线合成一个组合标签：叠放图标加上「骑士 / 重骑士 / 萨瓦尔 / 圣骑士」，每个名字都能点 |
| 5 | 建筑「生产」页签 | 城堡列出 61 个单位，精锐版和普通版都在里面 | 每个家族一行，加「精锐」小标 |
| 6 | 全局搜索 Ctrl+K | 搜「长弓」会同时出现长弓兵和精锐长弓兵 | 只出一条，副标题写「含精锐」；搜精锐名会命中这个家族 |
| 7 | 科技模拟器入口 `#/simulator` | 普通版和精锐版各一张卡片 | 合并成一张卡片，精锐版在单位页里切换 |
| 8 | 单位详情 · 升级路线 | 掷斧兵 → 精锐掷斧兵 | 不变：路线本身就是要展示两档。从普通版进入时不再列出别的精锐版本 |
| 9 | 自动链接（说明文字） | 「精锐掷斧兵」链接到精锐页 | 不变：文字里写的就是精锐版，链接到精锐页，进去后选中的是「精锐」 |
| 10 | 科技树 | 普通格和精锐格之间连线 | **不变**：要和游戏里的科技树一致，精锐升级本身就是一格要研究的科技 |
| 11 | 文明对比 / 对局助手 / DLC 页 | 不列单位，或只列文明 | 没有受影响的地方 |

## 待定

1. 「作用对象」里同一升级路线合并成一组后，萨瓦尔这种分支（从重骑士升级）也会算进骑士系，要不要单独成组？
2. 单位列表要不要加一个「展开精锐」开关，恢复成每档一张卡片？
3. 卡片和标签上的「精锐」小标，现在表示「有精锐版」。要不要改成「普通/精锐」两个图标叠放？
