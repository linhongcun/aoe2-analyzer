# #472 时间线短段标签与可读取详情

基线 `d2c7f91`。本轮冻结范围仅修复已有时间线的文字截断，不改模拟、分段、起止时刻、图段比例、开局数据、时代标记、卡点或研究赠村展示；不涉及在审 #484。

## 行为与状态

- 每个现有 `.tl-bar` 保留由原始 `from/to` 计算的 `left/width`、完整 `title` 与 `aria-label`，条内文字放入独立标签元素。以标签实际渲染宽度和图段可用内容宽度判断：能容纳则完整显示，容纳不了则整段隐藏，不能显示半截文字或用固定百分比阈值代替测量。
- 初次挂载、字体就绪、容器或窗口宽度变化、开局/文明/步骤变化时，重新核实可用空间。宽度扩大后原先隐藏且已能放下的标签应恢复；不能只在初次挂载测量。
- 图下复用已有原生折叠容器 `.tl-extra-controls`，摘要为「时间线分段、操作与村民生产」，保持原收起高度，不增加默认可见行，也不把390×844首屏第一步挤出视口。默认收起，支持触屏点击和键盘 Enter/Space；摘要命中区域至少44×44。展开后先按现有五行顺序逐项展示行名、完整标签与起止时间，再保留原操作与村民生产分组，覆盖全部图段。资源行补充「人」的单位；原村民标签已经带有同一时段时不再重复显示时段，完整标签与时刻仍保留。窄段即使隐藏条内文字，手机和键盘用户也能在这里读取相同信息；不能只依赖鼠标悬停 `title`。
- 选择步骤只保留原有高亮行为；详情中的数据始终对应当前图段。无图段时该行不生成虚假条目，不增加空态模拟结果。

## 视觉规格

保持现有色块、图例、轨道与标记层级。新增标签和详情至少12px，使用现有 `--fs-xs` / `--fs-sm`、`--color-text` / `--space-*` 令牌；颜色不得硬编码。时间与人数等数值不换行，详情允许在字段间换行。折叠区复用图下原有位置，不引入新浮层或横向滚动。

360 / 375 / 390 / 1280，各检查明暗主题：可见标签完整位于图段内容框内，不相互溢出；详情文字可读；无页面横向滚动、控制台错误。图段狭小时允许完全没有条内标签，完整信息仍可展开读取。
