# #545 天梯顶栏只露有数据的分段 · 交互规格（Jony · 2026-10-31）

> 产品已锁定（Hongcun，#545，2026-10-31）。MVP = 路径 2。本稿只定这一刀的界面。不重开范围，不补中/高分段快照（#547），不改新手友好度（#546），不编统计。

这一刀两件事：顶栏不再放出没有文明数据的 Elo 芯片；首页和工具入口不再写成「已经能看多段胜率」。深链指向空分段时回到「全部」，并拿掉无效参数。

## 1. 有数据才出现

可见分段 = `DISPLAY_BRACKETS` 里 `viewBracket(snapshot, key).empty === false` 的那些，顺序不变。

`empty` 就是 `civs.length === 0`（`src/domain/ladder.ts`）。空分段的 `games` 会被置 0，只供给来源条。不要另写一套 `games > 0`，以免和空态分叉。

当前快照 `ladder-arabia-p162286.json` 只有 `all`（文明非空，样本 504,189 局）。`<850`、`850-1000`、`1000-1200`、`1200+`、`1900+` 不在快照里，过滤后只剩「全部」。

以后某档写入非空 `civs`，对应芯片自己出现。不设开关。本切片不填那些档。

## 2. 只剩一个分段：只读 pill，不留单选

**决定：** 可见分段少于 2 个时，不渲染 `role="radiogroup"`，也不留一枚永远选中的 chip。上下文行末加一枚只读 pill，和地图、模式同一行。

| 项 | 规格 |
| --- | --- |
| 控件 | `<span class="ladder-pill">`。不是 `button`，没有 `role="radio"` |
| 文案 | 天梯分段 · `<span class="nw">全部</span>` · muted「当前快照」 |
| 样式 | 沿用 `.ladder-pill`：`surface-2`、12px、全圆角。不要 accent 描边（那是选中控件） |
| 图标 | 不加。不新登记 Lucide |
| testid | `ladder-elo-static` |

「当前快照」与地图 pill 上的「固定」同一写法：短、muted、不可点。

**不采用「天梯分段（Elo）」加一枚选中 chip。** 方向 C 里，分段控件用来切换同一份数据（设计规范 §5.4）。只剩一项时没有可切换的东西。单枚 radio 读屏是「1 / 1」，方向键空转，看起来像坏掉的筛选。地图和模式已经是只读标签，Elo 在没有选择时同样是上下文。

可见分段 ≥ 2：这枚 pill 不出现。恢复 #33 的标签「天梯分段（Elo）」和 radiogroup。芯片只含有数据的档。方向键只在这些芯片之间移动，选中项仍 `scrollIntoView({ inline: 'nearest' })`。

可见分段为 0（当前快照不会发生）：不画 pill，不画 radiogroup。主区走现有空态。不新做第三种空页。

## 3. 深链

回落目标固定是「全部」。用现有的 `navigate(..., { replace: true })` 写成 `canonicalSearch('all')`，也就是 `#/ladder`、没有 `elo`。不另开一套 history API。

| 输入 | 结果 |
| --- | --- |
| 无参数、空串、`all` | 「全部」。无 toast。地址无 `elo` |
| 不在 `DISPLAY_BRACKETS` 里 | 与现在相同。toast：「未识别的分段「{原值}」，已显示「全部」。」 |
| 在名单里，但 `viewBracket` 为空 | 同样回落，去掉参数。同一条 toast，文案改为：「「{显示名}」暂无数据，已显示「全部」。」显示名用芯片文案（如 `<850`），不用 raw key |
| 在名单里且有数据 | 保留 `?elo=`，选中该芯片。无 toast。今天除 `all` 外不会发生 |

Toast 仍是现有那一条：`data-testid="ladder-fallback-toast"`，`role="status"`，约 5 秒后消失。不新做第二种提示。

空态面板（`inbox`，「这个分段暂无数据」，「不推算，不补数」）从芯片和深链都到不了。组件留着，只在选中分段仍然 `empty` 时出现。文案不改。若「全部」自己也没有文明，回落之后才会看到它。不改成「跳到第一个有数据的档」。

## 4. 入口文案

三处都去掉「分段」，避免暗示可以按 Elo 换表。首页资料卡和工具菜单读的是登记表 `desc`，没有第二份句子。

不把「当前只有全部」写进登记表。那句话在 #547 补上分段后会过期。页面上的范围由只读 pill 的「当前快照」说明。

| 位置 | 现值 | 改为 |
| --- | --- | --- |
| `pageRegistry` `desc` | 阿拉伯 1v1 分段胜率、出场率与新手友好度 | 阿拉伯 1v1 胜率、出场率与新手友好度 |
| `metaDescription` | 查看阿拉伯 1v1 随机地图各文明的分段胜率、出场率与样本局数。 | 查看阿拉伯 1v1 随机地图各文明的胜率、出场率与样本局数。 |
| H1 下 `.ladder-desc` | 阿拉伯 1v1 分段胜率、出场率与新手友好度。 | 阿拉伯 1v1 胜率、出场率与新手友好度。 |
| `label` / `metaTitle` | 天梯数据 | 不变 |

`src/data/page-metadata.json` 由 `scripts/page_metadata.mjs` 从登记表生成，不要手改。这句说明不改拼音索引。

侧栏「本分段里」、来源条「本分段样本」、表 caption「阿拉伯 1v1 {label}」保持。当前 label 是「全部」，这些句子不承诺还有别的档。
