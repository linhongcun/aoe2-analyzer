# v0.22.0：完整驻军预览

驻军入口从城镇中心和箭塔的村民预览，扩展到全部可驻留建筑和所选文明的合法单位。区分主动回驻、训练后留驻与特殊驻留，支持混合配置、容量校验、完整分享和原方案兼容。

理论弹丸按固定 DE185872 数据与已核机制计算，非射击建筑展示容量与兼容性。盟友和招降单位各自科技、治疗及经济收益、DPS和战斗胜负未纳入。本版本不改变 #215 尚未完成的同版游戏引擎对账状态。

开发与部署范围来自维护者对 #218 的扩展要求及“同时支持各类可驻军单位”的明确选择，对应 #224。设计与数据规格见 `docs/design/issue224-spec.md`。完整 CI、Pages 和正式站交互通过后发布 tag、ZIP 与 SHA256；实际工作流和核对结果回填 PR/issue。工程复核不代替他人署名。
