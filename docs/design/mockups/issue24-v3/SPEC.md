## 1. 折后价怎么标
- 每种资源一行：原价 muted #636366 + 删除线，后接折后价（琥珀 #a65a14，700）。无折扣只显示原价。
- **折后价按游戏规则四舍五入，显示整数**（hongcun 游戏内确认 10/11：拜占庭精锐掷矛手显示 19 食物 / 26 木头）。不加「约」。
  - 例：拜占庭精锐掷矛手 25F/35W ×0.75 = 18.75 / 26.25 → 19 / 26；长戟兵 35F/25W → 26.25 / 18.75 → 26 / 19；马扎尔翼骑兵 80F ×0.85 = 68。
- 单价合计、派出数量按显示的整数价计算：长戟兵 26 + 19 = 45，3000 / 45 → 派出 66（向下取整）。实际扣费是 19 还是 18.75 仍在实测，若不同只改这一个常量。
- 「已计入：{文明} {加成} −p%」绿底行 + 「来源」。**删除所有按时代分档的写法**（拜占庭是黑暗时代起统一 −25%，tech 284）。
- 每视图琥珀数字 ≤ 2。
- 界面上不出现「待核」「约」等字样。

## 2. 「来源」浮层
- 标题「{文明} · {单位} 的费用」。
- 「已计入」：check 图标 + 加成名 −p% + muted 一行「食物 80 → 68」（整数，四舍五入后）。
- 「未计入」：circle-slash 图标 + 加成名（**不写任何数字或百分比**）+ muted「尚未核实，暂不计入」。
- 「不影响费用」：马扎尔锻造/铸铁/鼓风炉「免费且瞬间完成，但仍需在铁匠铺研究」，muted「不改变数量与攻击数值」。
- 底部保留「查看文明加成 →」（#/bonuses），点击区 ≥44px。桌面悬停/点击、移动点击；Esc 或点外部关闭。
