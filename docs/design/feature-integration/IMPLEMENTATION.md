# 功能整合实施规格

维护者已在审阅完整方案与在线原型后明确同意改造正式系统。本次范围记录于 [#531](https://github.com/linhongcun/aoe2-analyzer/issues/531)，从 `381f2a11ade448c510975b70ed4a1865c971ad30` 开始实施，统一以一个 PR 集成现有页面的交互。原型是设计参照，正式系统沿用既有完整计算器与页面结构。

## 本次完成的路径

- 文明、科技树、单位、科技、建筑间继续查询，保留当前文明、适用时代与上一工具；默认无情境的通用链接继续原行为。
- 文明对比可明确以左侧或右侧为我方进入对局，亦可进入同组合的科技树差异。科技树 `mode=1|2|3`、`compare={文明 en}` 写入 URL，合法 URL 优先本机选择。
- 对局的推荐模拟入口保留原双方；PK 明确选择 A/B 后进入待配置生产，不把军队数量作为生产建筑数量。
- 文明页的推荐开局与全部开局入口保留当前文明、原对阵及文明页来源；开局的适用文明链接可返回完整原配置。路线、列表、跟练、打印和步骤资料钻取保留兼容条件，换路线清除失效步骤并说明原因。
- 持续生产保留完整多行来源进入经济科技收益。玩家主动选择理论供给假设或填写人数；理论假设经手动调整后仍标明来源。返回原生产配置；仅主动打开新科技假设时生成变更方案。
- 商路、圣物、多人施工接收合法导航情境，读写与复制保留回链，原严格计算协议保持。圣物只带其实际支持的文明，不带并不存在的时代字段或自动叠加产金；生产配置无效时提供新建独立圣物方案的入口。
- 从资料、开局、对局进入现有复盘先预览来源，确认后只补空白上下文字段。原事件、正文、唯一目标、练习结果与输出选择不改变。

市场库存与持续流量的转换、更多战术工具的侦察映射、开局步骤到后续经济的模型快照仍为后续独立设计；不推断实战事实、不修改公式或生成数据。

## 情境协议

`ctxReturn` 保存上一工具的相对站内路径和查询，长度上限为 8192 字符。生成时剥离来源自身的 `ctxReturn`；读取时拒绝嵌套来源、绝对 URL、协议、双斜线、反斜杠、控制字符、路径穿越、重复导航键和未登记路由。来源失效只关闭回链并提示，不清除有效计算输入；不会截断后声称分享成功。

`me/opp` 保持原对局方向，当前工具的 `civ` 可与它们不同。上一工具恰好也是对局时，只有其完整双方与原对局一致才合并回链；不一致时分别显示“回上一对局配置”和“回对局助手”。

`stripNavigation` 只分离 `ctxReturn/me/opp`，其他字段、重复项和顺序仍送入原工具校验。严格训练对照、商路、施工和圣物的未知字段拒绝保持；新增导航不等于放宽计算协议。控件编辑、模式切换和复制重新附加合法导航，复制到新标签或刷新不依赖来源页内存。

经济收益新增 `ctxPeople=none|theory|adjusted|manual`，由收益页单独校验，不进入原收益计算器。无此字段的已有直接深链沿用旧设置。来自生产的新入口默认 `none`；明确选用理论人数后为 `theory`，修改人数后为 `adjusted`，主动选择手动填写为 `manual`。超出收益工具人数上限不夹断，要求玩家明确输入。

农田距离未被收益模型表示，带入区直接说明其固定基准；木金石距离按现有含义带入。科技仅投影目标模型可解释的部分，不自动研究前置，免费已获得与玩家手动研究分别显示。

## 对旧单边兜底规则的定向更新

原 S2 在单位页面收到合法但本单位不可用的查询文明时，允许模拟器回退为另一文明。此次维护者确认的设计要求保留显式分析条件，因此仅对此类明确不满足资格的输入更新：保留当前文明、单位与时代，展示不可用或时代不足说明，不挂载会静默改选的模拟器。缺失文明的既有直接访问默认规则、原模拟器计算和所有数值金标准保持。

`civContext521` 中相应普通用例迁移为更严格的保留条件与不输出误导模拟结果检查。其他普通链接测试仅迁移新情境 URI 并增加来源验证；受保护验收期望不修改。旧 S1 的文明标题和开局单边参数含义继续兼容。

## 草稿与状态

复盘来源自由文本不写入查询、OG 或来源快照。来源 URL 转为同源 HTTP(S) 完整地址并遵守原 2048 字符上限；过长时不填链接、不截短。按钮确认前重新检查最新草稿及存储锁，持久化失败或跨标签冲突时连当前页面草稿都不改，取消无写入。

加载、未支持、无效来源、无效计算输入、未建模、免费与已研究分别说明。新增界面沿用语义令牌与 Lucide，四宽与浅深主题验证，触点至少 44px。数字及单位不拆行；来源说明贴近结果，不将理论供给当成实有经济。

## 验证与独立复核

实施前已由独立代理完成规格与失败场景预审；各模块实际在基线观察到缺入口、丢文明或缺回程的失败，再实现转绿。导航安全、字段投影与草稿合并具有独立单测；新增浏览器检查覆盖多行生产往返、人数假设、原双方方向、PK 双侧、开局步骤、来源无效与草稿冲突。

共享导航和多页面映射属于完整验证范围，CI 运行一次全量单测与浏览器检查，不重生成未变数据。训练对照的构建分包拦截用例必须在正式构建预览或 CI 执行，Vite dev 上未拦截不能当成功证据。

实现完成后由未参与相应代码实现的代理复核实际提交和界面；结果及真实测试 SHA 写入 PR。上线与正式 Release 以 main 的实际构建、部署及发布结果为准。
