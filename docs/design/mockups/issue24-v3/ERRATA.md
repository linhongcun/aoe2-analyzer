# #24 / #25 v3 勘误与补充裁定（2026-10-12）

v3 样稿图片不重出，以下几条优先于 SPEC.md 和样稿里的数字。出处：Steve 在项目组的裁定、#24 勘误评论 6115003915、PR #84 设计复验。

## 数值
1. **折扣按 PK 当前所选时代取档。** 柏柏尔骆驼城堡时代 −15% = **30 个**（v3 样稿写的 32 是按 −20% 算错了，作废）；帝王时代 −20% = 32 个。未选时代时按单位最早能造的时代取价。
2. **折后价正好是 .5 的单位：标「未计入」，按原价算，不显示取整后的数。** 游戏里 .5 往上还是往下取尚未实测，核实前不放开（只要有一项资源落在 .5 就整单位按原价）。
3. **韩国：标「折扣未计入」，按原价算。** 数据里木头有 0.5 和 0.8 两个系数，和加成文字对不上，原因查清前不计入。
4. 折扣数值从游戏数据的科技效果导出，不按文明描述手抄；读不出或对不上的文明一律「折扣未计入」，不猜。

## 样式裁定
5. **「已计入」行用加成原文**（如「骆驼骑兵、掷矛手和长矛兵系的费用 −25%」），不用 v3 的短名「反制单位费用」。muted 12px（`--fs-xs` + `--color-muted`），可换到 2 行，不截断、不加省略号；绿色只用在 check 图标上。
6. **「按X时代价格」放在价格旁**（单价合计那一格，价格下方 12px muted）。只在取价时代 ≠ 卡片头显示的时代时出现，相等时隐藏。
7. 「折扣未计入」「未计入」沿用 v3「未核实」样式：muted + Lucide info，显示原价，不出估算值。
