> 产品已锁定（Steve，#577，2026-11-01，P1）。本稿只定界面。不重开范围。不写可抄进仓库的胜率。A 先做表和走势；B 是分层和分布，可同 PR 或紧随。#576 / #578 仍只刷新阿拉伯 1v1，与本刀的 4v4 切片分开。

## 1. 默认打开什么

无参数 `#/ladder` = 下面这一刀，视图是表。

| 维 | 玩家文案 | 地址（默认则省略） |
| --- | --- | --- |
| 模式 | 4v4 随机地图 | `mode=4v4` |
| 时段 | 近 90 天 | `period=90d` |
| 天梯分段 | 1200–1400 | `elo=1200-1400` |
| 地图 | 全图 | `map=all` |
| 视图 | 表 | `view` 省略；分层 `view=tiers`；分布 `view=meta` |

`view` 不用 `map`，免得和地图参数撞车。

旧地址只带 `elo`、没有 `mode`：仍走阿拉伯 1v1（#545 的回落不变）。`#/ladder?elo=all` 规范成 `#/ladder?mode=arabia1v1`。这样已经复制出去的分段链接不会被 4v4 吃掉。什么参数都没有，才是新的默认切片。

深链用现有的 `navigate(..., { replace: true })` 收成规范地址。不另开一套 history。

| 输入 | 结果 |
| --- | --- |
| 无参数 | 默认切片 + 表。无 toast |
| 只带 `elo` | 阿拉伯 1v1，分段按 #545 |
| `mode` 不是 `4v4` / `arabia1v1` | 回到默认切片。toast：「未识别的模式「{原值}」，已显示「4v4 随机地图」。」 |
| `view` 不是 `table` / `tiers` / `meta`（含空串以外的错值） | 表。toast：「未识别的视图「{原值}」，已显示「表」。」`table` 与省略相同，无 toast |
| 当前模式的快照里没有这个 `elo` / `period` / `map` | 该模式的默认档，去掉无效参数。toast 沿 #545 的句式：「「{显示名}」暂无数据，已显示「{默认显示名}」。」 |
| B 未合入时打开 `view=tiers` 或 `view=meta` | 留下参数，主区仍是表，不 toast。见第 4 节 |

Toast 仍是 `ladder-fallback-toast`，`role="status"`，约 5 秒。不新做第二种提示。

## 2. 筛选条

筛选在标题下的一张卡里，`data-testid="ladder-filters"`。四行：模式、时段、天梯分段、地图。行标签 12px muted。

**有几档就画几档。** 沿 #545：某一维少于 2 个真实快照时，不渲染 `radiogroup`，不画禁用的空芯片，不做法续滑杆。滑杆会让人以为任意 Elo 都有数。

A 的模式只有两枚，这行才是 `role="radiogroup"`（`ladder-mode`）：

| testid | 文案 | 图标 |
| --- | --- | --- |
| `ladder-mode-4v4` | 4v4 随机地图 | `users` |
| `ladder-mode-arabia1v1` | 阿拉伯 1v1 | `swords` |

不画 2v2、3v3、1v1 帝国战争、团队帝国战争。以后某模式写入非空快照，芯片自己出现。不设开关。

默认切片若只有一个时段、一个分段、一张全图，这三行是只读 pill，不是按钮：

| testid | 文案 |
| --- | --- |
| `ladder-period-static` | 近 90 天 · muted「当前快照」 |
| `ladder-elo-static` | 1200–1400 · muted「当前快照」 |
| `ladder-map-static` | 全图 · muted「当前快照」 |

时段图标 `calendar`，地图图标 `map`。分段 pill 不加图标，和 #545 一样。选中的模式芯片用 accent 描边和 `#a65a141f` 底；只读 pill 用 `surface-2`，不要 accent 描边。

以后同一维 ≥ 2 档：pill 消失，改回芯片 radiogroup，只含有数据的档。

## 4. 视图切换

标题行右侧一组分段控件，`role="radiogroup"`，`aria-label="视图"`，`data-testid="ladder-view"`。这是同一份数据的三种看法（设计规范 §5.4），不是页面标签页。

| 按钮 | testid | query |
| --- | --- | --- |
| `table` · 表 | `ladder-view-table` | 省略 |
| `rows-3` · 分层 | `ladder-view-tiers` | `view=tiers` |
| `chart-scatter` · 分布 | `ladder-view-meta` | `view=meta` |

当前项：槽内白底、accent 字重 600。三枚都至少 44px 高。

切换只改 `view`。模式、时段、分段、地图、来源条、隐藏低样本的勾选都留着。三视图和来源条读**同一次**解析好的切片，不换文件，不重新默认。

**A 先做。** B 未合入时，分层和分布两枚 `disabled`，文案不变，`title` 为「随下一刀」。点了不改地址、不清筛选。深链 `view=tiers` / `view=meta` 先停在表上，参数留着，等 B 合入后同一地址直接变成那一视图。B 去掉 `disabled`。线框 `wire-table-1280.html` 是 A；另外两张是 B。

实现时把 `table`、`rows-3`、`chart-scatter` 登记进 `Icon.tsx`。锁定的 lucide-react 若没有同名导出，改用已有的图表图标，testid 和文案不变。`calendar` 同样补登记。不要 emoji。

## 5. 来源条

沿 #547，不新做组件，不在标题下再挂一条新鲜度。#569 的「更新多久前」以后并进 `ladder-cutoff` 这一行，本刀不画第二行，也不做第二张横幅。

- 容器仍是 `ladder-source`，`data-cutoff="mismatch"` 或 `aligned`，Lucide `database`
- 第一行 `ladder-cutoff`。不一致：warn 色「非当前平衡」，左边 3px `--color-warn`，卡底仍是 `surface-2`
- 黄条仍是 `ladder-patch-note`，只在不一致时出现，全文只有「胜率可能未反映最新平衡改动。」
- 4v4 第二行样本句用「本切片样本 N 局」。阿拉伯仍用「本分段样本」
- 外链是该切片的 `sourceUrl`，`external-link` +「（外部）」。页面不出现 aoe2scout，不出现 wayback
- 两态文案、禁止词（实时、最新排名、当前平衡、自动更新）与 #547 第 3 节相同。Accent 不涂这句
- `.ladder-desc` 不写截止日

线框上的 `2026-04-01`、补丁 `100000`、「示意」只用来看不一致态的语气。实现读该切片的 `fetchedAt` 和 `patchNote`。页面上不出现「示意」。本站 DE 号仍是 `DATA_SOURCES` 的 build（现为 188329），不是线框里别的数。

**没有 4v4 文件，或文件没有 `fetchedAt`：** 不拿阿拉伯的表来顶，不手写胜率。主区空态 `ladder-empty`：「这个切片暂无快照。不推算，不补数。」按钮「看阿拉伯 1v1」切到 `mode=arabia1v1`。这种空态不画截止行，避免编一个日期。#576 / #578 不负责创建这份 4v4 文件。

4v4 文件本身另开数据 PR：静态 JSON，不进 `npm run data`，页面不 `fetch`。抄数规则沿 #536 / #547（可核对的公开来源、原样写入）。本短稿不指定站点，不写抓取步骤。

## 6. 表 + 走势（A）

`data-testid="ladder-table"`。通栏，不再留 280px 侧栏；八列再加侧栏，走势会被挤没。说明收成表下的三行小字。「复制当前链接」留在说明右侧，复制当前规范地址（含非默认的 `mode` / `view` / `elo` / `period` / `map`）。不新做分享按钮。

默认按胜率从高到低。排名是这个顺序的 1…n，勾选隐藏后重排，不单独存储。

| 列 | A | 说明 |
| --- | --- | --- |
| 排名 | 必有 | 不排序 |
| 文明 | 必有 | 现有 `CivIcon` + 中文名链到 `/civ/{en}`，英文名 muted。线框用 `shield` 占位 |
| 胜率 | 必有 | 现有中线柱，`formatPercent`。默认排序，表头 `arrow-down` |
| 95% 区间 | 有上下界才渲染整列 | 没有则整列不出现，不补 0、不补破折号列 |
| 出场率 | 有字段才渲染 | 可排序 |
| 样本局数 | 有字段才渲染 | 可排序。少于阈值时，取消隐藏后标「样本少」，数字照实 |
| 相对 50% | 有胜率就有 | 胜率减 50，单位是百分点，`.num` + `.nw`。正用 `--color-good`，负用 `--color-bad`，零 muted。不单独排序（与胜率同序） |
| 走势 | 必有 | 见下 |
| 新手友好度 | 仅阿拉伯，且沿 #546 | 放在最后。4v4 没有 entries 就不渲染这一列，不要整列「待补」 |

走势：快照里的 `trend` 数组，旧→新，折线宽约 72×24，线宽 1.5，无填充。末点高于首点用 `--color-good`，低于用 `--color-bad`，持平 muted。`aria-hidden="true"`，因为同行已有胜率。字段缺失或空数组：单元格写「无走势」，不画点。不把折线当成相对 50% 的颜色（那一列已经表达了）。

「隐藏低样本」：`ladder-hide-low`，默认勾选，不进地址。阈值是切片上的 `lowSampleGames`，缺省为现有 `LOW_SAMPLE`（300）。文案就是「隐藏低样本」，不写 aoe2scout 的 50。勾选状态在三视图之间保持。表隐藏这些行；分层和分布也隐藏，档位计数和气泡跟表同一批文明。取消勾选后行还在，并标「样本少」。

排序状态仍只在内存里，和现在一样不进地址。离开表再回来，排序回到胜率降序；勾选不重置。

表下说明（12px muted）：

- 胜率：这一切片里，该文明赢下的对局占比。
- 走势：这份静态快照里的胜率序列，不是实时。
- 相对 50%：胜率减去 50 个百分点。

阿拉伯表若带新手友好度，再加一句：「新手友好度是编辑口径，不是上面的 S–D。」两套词不要混用「档位」。

## 7. 分层（B）

`data-testid="ladder-tiers"`。五行，字母就是 S / A / B / C / D，按钮不叫「档位」。

| 行 | 待产品设计确认的胜率带 | 线框里的示意归类 |
| --- | --- | --- |
| S | ≥ 52% | 空 |
| A | ≥ 51% 且 < 52% | 中国 51.00% |
| B | ≥ 50% 且 < 51% | 法兰克 50.50%，不列颠 50.00% |
| C | ≥ 48% 且 < 50% | 匈奴 49.50%，拜占庭 49.00% |
| D | < 48% | 空 |

边界以上表为准，实现写死在这一处，不要在渲染时另切一刀，也不要按 aoe2scout 的观感改。产品若改边界，改这一张表，线框归类跟着改。

空档仍占一行：字母、计数 0、「这一档没有文明」。不要把下面的行顶上来。

药丸：`CivIcon`、中文名、胜率 `.nw`，链到 `/civ/{en}`，至少 44px 高。一行放不下就换行。计数是这一行的药丸数。

主区下一条说明：「分层按胜率带，空档仍留着。不是新手友好度。」

## 8. 分布（B）

`data-testid="ladder-meta-map"`。

- 横轴出场率，纵轴胜率。轴上用百分数，`.nw`
- 横虚线固定在胜率 50%（不是胜率中位数）
- 纵虚线是**当前可见文明**出场率的中位数。隐藏低样本会改这一条线
- 落在线上：≥ 50% 算强，≥ 中位数算出场更多。不列颠在示意数据里卡在两条线上，归「强且常见」
- 四块说明，不是按钮，点了不隐藏别的点：

| 位置 | 文案 | 小字 |
| --- | --- | --- |
| 左上 | 强且少见 | 胜率不低于 50%，出场率低于中位 |
| 右上 | 强且常见 | 胜率不低于 50%，出场率不低于中位 |
| 左下 | 弱且少见 | 胜率低于 50%，出场率低于中位 |
| 右下 | 弱且常见 | 胜率低于 50%，出场率不低于中位 |

不使用 Pillars / Sleepers / Crowd-pleasers / Niche。

气泡面积按样本局数的平方根，直径夹在 10–36px。≥ 50% 用 accent 描边和淡底，< 50% 用 muted。每个气泡是按钮，可访问名称包含文明、胜率、出场率、样本局数。线框不弹出浮层。

图下一条：「气泡大小是样本局数。虚线是 50% 胜率，和当前出场率中位数。」

示意五点的中位数是 2.00%（1.00、1.20、2.00、4.00、6.00）。这只是线框坐标，实现用真实出场率重算。
