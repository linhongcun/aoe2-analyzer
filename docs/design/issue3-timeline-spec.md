# #3 开局时间线界面 交互稿（v1.0 定稿）

作者：Jony Ive（体验设计） · 页面：`/builds` · 依赖：M2（PR #5，`src/domain/buildSim.ts`，`docs/BUILD-SIM.md`）
样稿：`docs/design/mockups/issue3/`（电脑 1280 + 手机 390，正常 / 卡人口）
视觉：浅色编辑风（`docs/design/DESIGN-SYSTEM.md`），`--color-muted` = `#636366`。

## 0. 设计原则
- 三秒内看出开局卡在哪：首屏只有时间线 + 卡点摘要。
- 时间线是主角：占首屏 ≥60%；不铺表格。
- 资源数字点开才显示。
- 所有时间写成「约 xx 秒 / 约 m:ss」，旁有「估算」徽标和不对称误差带。

## 1. 页面结构（自上而下）
1. **参数条**：开局选择 ｜ 文明选择 ｜ 走路距离（近 2 / 中 4 / 远 7 分段 + 滑块 1–10，默认中 4）｜ **自动造房开关**（默认开）｜ **激进 / 保守** 分段（仅有变体的开局显示）。旁注「羊和浆果按近距离计」。
2. **卡点摘要**（4 块统计）：卡点（有则红底）｜ 到达封建 / 城堡（约 m:ss + 早晚范围）｜ **城镇中心闲置约 x 秒**（最高优先级，排第一或紧挨卡点）｜ 到达时村民数。
3. **主时间线**：横轴分钟；行：城镇中心 / 食物 / 木头 / 金子 / 军事 / 到达时代。资源色块；升级时代用琥珀色；**不对称误差带**（左 = early，右 = late）。
4. **步骤列表**：异常行浅红底 + 左侧 3px 红条 + M2 `reasonZh`。
5. **估算说明**：点「估算」徽标，浮层展示 `model.assumptions`。

## 2. 卡点与状态
| 状态 | 表现 |
|---|---|
| 正常 | 摘要「0 处卡点」；时间线无红区 |
| 空数据 | 虚线轴 +「选一个开局，看看你会卡在哪」+ 6 个开局快捷入口 |
| **城镇中心闲置**（最高优先级） | 阈值严格 **> 2 秒**；红区 + TC 图标；悬停「城镇中心闲置约 x 秒」；摘要用 `tcIdleTotal` |
| 卡人口 / 断资源 | 同套红色高亮；气泡用 `reasonZh`（如「木头差 35」） |
| **超时** | `type: 'timeout'`，摘要写「60 分钟内到不了城堡」；单独成态，不当普通卡点节点 |
| 关掉自动造房 | 时间轴出现卡人口高亮（验收用例） |
| 手机 ≤600px | 标签列缩至 64；刻度每 2 分钟；步骤在时间线下；触控 ≥44px |

优先级：`idle_tc` > `timeout` > `pop_block` > `resource_short`。

## 3. 交互与 URL
- 走路：滑块 1–10；预设 近 2 / 中 4 / 远 7；默认 4。拖动 200ms 防抖重算。
- **自动造房**：`house=1|0`，默认 1；旁注「关掉可以看到不造房会卡在哪」。
- **激进 / 保守**：`var=aggr|cons`；切换后差异步骤描边闪一次，摘要可显示「保守 约 +15 秒」。
- **URL 参数**（稳定，与 #19 / PR #21 一致）：

```
/builds?bo=scout-18&civ=Britons&dist=4&var=aggr&house=1&step=12
```

| 参数 | 含义 | 默认 |
|---|---|---|
| `bo` | 开局 id | 第一个 draft 开局 |
| `civ` | 文明 id | Britons |
| `dist` | 走路格数 1–10 | 4 |
| `var` | `aggr` / `cons` | 开局默认变体，无则省略 |
| `house` | 自动造房 1/0 | 1 |
| `step` | 当前选中步骤 index | 无 |

非法值回退默认，不报错。离开前写入 URL，返回即恢复。

## 4. M2 字段（与 `buildSim.ts` 一致）
`SimParams.walkTiles / autoHouses` · `WALK` 近 2 中 4 远 7 · `ErrBand.{early,late}` · `Anomaly.type` 含 `idle_tc|pop_block|resource_short|timeout` · `TimelineStep` 无 `nameZh` · `BuildTimeline.anomalies` + `tcIdleTotal`。

## 5. 验收（16 条，Kent）
正常时间线 · 空数据 · 断资源高亮 · 卡人口高亮 · 城镇中心闲置 >2s · 闲置 1.9/2.0 不报 · 超时状态 · 关掉自动造房出现卡人口 · 激进/保守切换 · 走路近中远 · URL 六参数还原 · 手机竖屏 · 摘要四块 · 误差带不对称 · 资源点开才显 · 估算浮层。
