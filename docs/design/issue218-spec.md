# Issue 218：建筑村民驻军箭矢预览

实施规格，2026-10-19。对应 #218；数据 DE Update 185872（2026-09-22）。本文件记录实现与证据，不代替维护者或设计、测试负责人的本人签字。

## 场景与入口

玩家在城镇中心、瞭望塔、防御箭塔或大型箭塔的详情页打开「村民驻军」，选择文明、时代、已研究科技与村民数，查看基础箭、村民副箭、总箭数、下一箭阈值及饱和人数。科技模拟器提供入口，带入文明、时代及影响箭数的已选科技。原有建筑属性模拟不变。

只处理单一建筑形态和村民。选择形态即视为相应线路升级已经完成；不假装城堡时代能使用帝王建筑，文明不可用形态阻止计算。不计军事单位、混合驻军、城堡、火炮塔、强化教堂、其他盟友加成、DPS、目标护甲、命中率与地形。

## 可复现数据与机制证据

`python3 scripts/garrison_build.py` 从 `scripts/data_sources.json` 的固定 `.dat` 生成 `src/data/garrison.json`。`--check` 比较精确生成结果，不修改生成文件。CI 增加该检查；缓存、解析器环境和 `.dat` 均不提交。

来源固定为 SiegeEngineers/auto-mods `0c38027504532826c9922e4db77e2c1d33554291`，SHA256 `4aa2f0a719e88e5f1502517eddb27c669aeb40c2fe9d8c4f3eec7751c01e7baa`，沿用 `dat_source.py` 的下载、散列及补丁标记核验、genieutils-py 0.1.2。独立的小型解析器读取以下真实字段，无须修改其他工具共用的精简 dump：

- `garrison_capacity`、`type_50.attacks` 的穿刺攻击、`reload_time`、`projectile_unit_id`、`garrison_firepower`。
- `creatable.total_projectiles`、`max_total_projectiles`。
- 科技、文明科技树、自动文明加成和本方团队加成中的相关原始属性效果；保留操作、目标、顺序、前置列表及 `RequiredTechCount`。

提取时核对站内全部 56 文明的这些基础字段一致，以及男女村民一致。有差异则停止生成，要求先支持差异，不能静默选择通用基础。当前相关文明自动效果是条顿容量/最大弹丸修正与萨克森城堡时代常驻箭修正。

## 箭数口径

记原始总弹丸为 `P`、最大总弹丸为 `M`、有效穿刺攻击为 `A`、理论攻击间隔为 `R`，村民穿刺攻击为 `Av`、理论间隔 `Rv`、负的驻军火力属性为 `Fv`。村民数量为 `n`。

- 村民贡献 `V = Av / Rv - Fv`；建筑单箭火力 `B = A / R`。这里只用作箭数阈值的中间量，不把它展示为实际齐射 DPS。
- 原始附加弹丸数 `E = min(M - P, floor(n × V / B))`。
- 箭塔有实际主弹丸，基础箭 `P`，总箭 `P + E`。
- 城镇中心主弹丸 ID 为 `-1`：数据中有一个不会发射的主槽。因此实际基础箭 `P - 1`、上限 `M - 1`、总箭 `P - 1 + E`。普通空 TC 的基础箭为零；Tigui 的常驻箭独立计入基础箭，不能用「所有空 TC 都不开火」覆盖它。

固定版本基础对账：

| 形态         | 容量 | P / M  | 主弹丸 | 攻击 / 间隔 | 空驻军实际箭 |
| ------------ | ---- | ------ | ------ | ----------- | ------------ |
| TC 109       | 15   | 1 / 11 | -1     | 5 / 2       | 0            |
| 瞭望塔 79    | 5    | 1 / 5  | 504    | 5 / 2       | 1            |
| 防御箭塔 234 | 5    | 1 / 5  | 504    | 7 / 2       | 1            |
| 大型箭塔 235 | 5    | 1 / 5  | 504    | 8 / 2       | 1            |

男女村民的原始穿刺攻击为 0、间隔 2、火力属性 -2.5。箭羽、锥子箭、护腕、化学各包含村民类别属性 130 加 -0.5，同时改变建筑攻击；不是把面板近战攻击或射程直接用作驻军贡献。箭狭槽没有该村民修正；其防御箭塔、大型箭塔额外加攻分别由科技 610、611 的 n-of 前置触发。

支持射箭线、化学、箭狭槽、Yeomen、Stronghold、Yasama、Tigui、Svan Towers 对箭数的相关效果；只列当前建筑与文明实际可用项。斯万箭塔科技 923 的原始效果 935 为 TC/塔穿刺攻击加 2、村民属性 130 加 -1：村民贡献从 2.5 变为 3.5，未研究其他科技时，格鲁吉亚防御箭塔驻 4 村民从 3 箭变为 4 箭；不计算其穿透伤害。生成时审计站内全部可研究科技，有未纳入的驻军相关效果即停止。土耳其免费化学自动生效；波希米亚化学时代沿用现有的科技可用时代规则。射箭线前置联动勾选，取消前置会取消依赖项；导入不完整前置的链接阻止计算。

下一箭通过容量内逐人数枚举寻找首次总箭数增加；饱和人数为首次达到箭矢上限的人数。区分「达到上限」与「容量内再加人仍不够下一箭」。计算使用很小的浮点阈值容差吸收除法误差，不对一般小数向上取整。

## 界面与状态

标题与复制操作在首行，窄屏自然换行。文明选择使用现有 CivPicker。1280 宽配置三列；360 / 375 / 390 宽文明占整行，时代与人数两列。核心数字三列，使用 `--fs-num-xl`，数字不换行。其余正文至少 12px，按钮、输入和技术勾选触区至少 44px。

复用 `tokens.css` 的 surface、accent、border、muted、bad 与字号/间距令牌，两种主题均可读。无新色值、图片或符号图标。详细阈值表在可键盘展开的原生 details 中；容量内全部箭数变化点及满容量行均保留。

- 加载：等 core 与 trees 都就绪后才计算，不短暂显示通用结果。
- 正常：基础、副箭、总箭三项；下一箭或上限状态；容量、上限、满容量箭数、饱和人数。
- 空驻军：TC 正常零箭；箭塔常驻箭；独特科技常驻箭按固定数据。
- 无效：非法人数、时代、文明、未知科技、缺前置、重复关键查询参数或数值溢出均显示「暂不能计算」，不显示结果数字，并提供移除科技或重置。
- 复制：完整方案使用 `tab=garrison`、`civ`、`age`、`gtechs`、`garrison`。URL 解析错误时保留原参数、停用常规编辑和复制，只允许显式重置，避免人数编辑清除非法片段或重复参数。可解析但配置无效的链接保留原参数，不能复制成更宽的有效方案。Clipboard 拒绝时显示可手动复制的只读链接；参数变化后不继续显示旧成功状态。
