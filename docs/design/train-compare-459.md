## 计算与范围

首版只接受请求的精确形态 38 骑士、283 重装骑士、569 游侠；固定城堡时代 3、一座马厩 101，目标数量 N 为 1–1000 的整数，默认 10。不是城镇中心方案，不自动升级或换形态。Savar 1813、其它单位、时代或建筑不在本轮支持范围，请求明确报错。

逐文明复用 `productionTechs`、`effectiveProductionTechs`、`productionBuildings`、`calculateProduction`。每个原配置使用 `rows:[{unit,building:101,count:'1'}]`、原默认采集距离；`count` 是建筑数量。目标 N 只乘原 `line.seconds`，不改每个间隔、单价或建筑数；排序用未取显示精度的总耗时，再以原文明目录顺序稳定排序。保持输入不变。

“本时代满生产科技”指原 API 判为城堡时代可用的生产相关科技已经研究，不计研究时间/费用，不把战斗科技当训练加速。显式说明原数据中的征招 315、骑士精神 493 属帝王科技，本档不计入；名称来自当前 core。波兰贵族特权 782 等已计入项按真实 `line.applied` 展示。原目录的勃艮第城堡重装骑士例外保留；城堡游侠等不可用请求保留原因，不能显示通用值或零秒。

原数值 oracle 不重录：法兰克骑士 30 秒/个、10 个 300 秒；匈奴 25/250；柏柏尔 51 食物/64 黄金，葡萄牙 60/60，波兰有 782 时 60/30。这里只验证现有引擎输出与复用一致，不能将本来已绿的 API 数值检查充当新功能先红。

每个有效行显示文明、单个间隔、单个费用、N 个总耗时四列；相邻展开详情展示该行实际计入的 `line.applied`、全部原 `result.warnings` 和固定训练地点/科技条件。`result.applied` 是采集汇总，不能当训练来源。任何 warning 不凭文字分类，不因无关采集 warning 丢弃合法行；未核实或未计入说明完整可见。模型不模拟资源短缺、队列空档、建筑建设、初始免费单位，不称最优文明或实战训练保证。

## 选择与 URL

明确模式链接：`/production?mode=train-compare&v=1&unit=38&age=3&n=10&civs=Franks,Huns`。分发在旧 decoder 之前处理；只有没有 mode 和新保留参数的旧 URL 进入原逻辑。空/未知/重复 mode，或无 mode 的 `v/unit/n/civs` 都显示错误，不回退旧法兰克村民方案。

新 codec 与旧生产/商路 codec 分离。`mode/v/unit/age/n` 各须恰好一次；版本仅 1，形态白名单、固定时代、严格 N、已知文明都先校验。未知/重复键、坏编码、无效数值均停止全部结果和复制，不自动清洗地址或只算有效部分。`civs` 可缺省：数据就绪后默认当前形态在一座马厩可生产的全部文明；显式 `civs=` 是空集合，刷新仍为空。文明集合按原目录顺序去重，编码器只接受已解析的实际数组；未解析的默认集合不能被复制为含糊链接。

文明选择放在可展开区域，复选框保留不可用文明以便解释请求；提供“选择当前可用文明”和“清空文明”。改变形态保留现选文明，不自动删去不可用行。空集合显示“选择文明后对照”；全部不可用时仍显示每个请求文明与原因。合法控件提交用 history push，前进/后退还原完整选择；N 草稿可暂时为空或非法，提交后明确报错且不生成结果/链接。错误页保留原始可编辑参数，提供“应用参数”和“重置对照”；不篡改原地址。复制使用原 `useShareLink`，反馈状态以完整 `location.search` 关联，失败提供完整可手动复制链接。

## 加载与界面

页面父级使用唯一 feature-local 捕获 core/trees 的 loader，向旧/新视图提供同一 context，替换本页两条未捕获 hook 链而不改全局 hooks/cache。新模式真实分包失败后切回旧模式也保持捕获错误。加载中不出排名或可复制结果；失败显示 alert 与可靠的“刷新重试”（整页 reload），不能假装同一拒绝 Promise 能靠重挂恢复。

新模式样式仅作用 `.train-compare-*`，模式导航仅作用 `.production-mode-nav`。原 `ProductionBody` JSX、表格类名、display/overflow 与不可变 #338 表格捕获不改；不是新路由，不增加 metadata 页。复用原按钮、`CostView`、数字 `.num/.nw`；正文 15px，说明 `--fs-sm` 13px，窄屏表格说明不小于 12px。颜色为 `--color-text`/`--color-muted`/`--color-link`/`--color-border`/`--color-surface`，间距 `--space-*`，圆角 `--radius-md`。四列可在窄屏按同一表格语义纵向排列，不隐藏费用、来源或未计入项；标签和单位不得挤坏数字。控件/展开与链接至少 44×44px、焦点可见、可键盘操作，图标仅现有 Lucide。
