## 行为

- 对手步直接说明“本步暂无已核对对手数据，未列出对手文明”，去掉该步“建议／暂无建议”组合。完成、跳过和已有步骤顺序保持可用。
- 对手步及摘要以 `matchupPath(我方文明)` 带入真实己方。链接旁直接说明“仅带入我方文明；对手沿用助手原有选择，非本局当前对手”。没有我方文明时保留普通助手入口，并说明未带入本局文明，原有双方不代表本局对阵。缺失对手仍采用助手原有兼容语义，不伪造为空或已知。
- 摘要以 `buildsPath(我方文明)` 带入文明上下文。说明列表仍为全部开局，地图、路位未带入，具体流程需自行选择。未选文明时说明未带入；本项不指定开局或声称筛选。
- 地图页保留 `/maps`，就近具名说明“不保证已选中本局地图，请在页内选择”；无地图时说明未带入。天梯保留 `/ladder`，说明静态快照、未按本局筛选、不是本局胜率。
- 摘要对手行只在 `skipped.opponent === true` 时显示“已跳过”，否则显示“暂无数据”。普通完成不强行清除历史跳过标记。其他空值、跳过标记、事件和严格URL/local恢复不变。
- 限制直接可见，复用既有样式；360／375／390／1280 无横向滚动、console error 或 pageerror。保持原明暗主题与数值断言。
