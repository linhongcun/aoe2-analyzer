# v0.18.0：市场买卖预算

维护者在本会话明确授权按 #214 → #215 → #216 → #217 → #218 完成开发、验证和部署。本版只新增 #215，设计规格见 `docs/design/issue215-spec.md`。此前已完成的功能保留并回归。

新增市场买卖预算，可编排交易顺序、查看逐笔报价和预计库存，并对照两份文明与科技方案（#215）。
共享链接保留两份方案、起始手续费前基价和交易序列；库存不足时指出第一笔预计无法成交的操作。

## 边界

按每笔整数报价估算。游戏内部可能保留小数余额，累计黄金与预算临界点可能不同；这不是 DE 185872 引擎逐笔实测。

不预测其他玩家对共享行情的影响，不自动推荐速城或交易顺序。手续费来自固定 .dat，其他规则来源与假设在页面列明。
