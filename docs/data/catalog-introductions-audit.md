# 单位与建筑首发版本核对（#190）

## 范围与口径

核对当前 DE Update 185872 目录中的全部 **248 条单位记录、38 种建筑**。逐项英文身份、发行版本、来源网址和证据保存在 [核对清单](../../scripts/catalog_introductions.json)。本轮纠正 **5 条错标**，补齐 **75 条单位、29 条建筑**的未标注版本，其余 177 条结果保持一致。

版本指当前具名单位或升级形态、建筑首次出现的发行时期，不是内部 ID 或美术模型第一次存在的日期，也不随可训练文明、生产建筑变化。普通与精锐分别核对；随资料片前后免费更新引入的通用内容按来源的发行时期归档，版本标签不代表当前购买限制。

例如，鹰斥候的内部 ID 和旧鹰勇士有关联，但当前鹰斥候形态始于失落帝国；不能凭 ID、整个鹰兵系或文明首发版本推断。城楼的长矛兵、长枪兵、长戟兵和兵营形态具有相同具名身份、战斗数值；仅生产渠道、适用文明和引用不同，按同一具名形态首发记录，不宣称核实了这些内部 ID 的创建历史。

## 来源匹配与冲突处理

- 以英文身份核对中文别名，避免同名误配。本站「战车」涉及 Ratha（1759/1761，印度王朝）与 War Chariot（1962，三国）；「楼船」涉及 Thirisadai（1750，印度王朝）与 Lou Chuan（1948，三国）。Jian Swordsman 对应来源「刀剑手」，不是 Man-at-Arms。
- 大庄园来源页的信息框写国王时代，但简介明确写公爵的崛起引入。[官方 2021 年 DLC 公告](https://www.ageofempires.com/news/aoe2de-dukes-preorder/)确认新增 Folwark，采信引入历史并在清单中保留冲突记录。
- 火艨艟来源页的杂项与信息框、简介不一致；[非洲王国官方发布公告](https://www.ageofempires.com/news/age-of-empires-ii-hd-the-african-kingdoms-released/)明确列为新增通用单位，采用非洲王国。
- 来源的训练时间、费用等现行数值不用于覆盖本站固定游戏数据；本轮只修正发行版本元数据。

## 可复现维护

`npm run introductions` 从逐项清单生成 `src/data/catalog-introductions.json`；`npm run introductions:check` 离线检查生成结果、全部当前 ID、英文身份、状态和有效版本。运行时按单位与建筑两个独立 ID 空间查询，未知项返回 `null`，不再继承文明版本。

新增或改名条目必须先补核对清单；无法证实的记录明确标为 `unverified` / `null`。生成文件不手改。科技版本沿用原规则，全部 199 条结果单独回归，游戏数值与既有受保护验收保持原样。
