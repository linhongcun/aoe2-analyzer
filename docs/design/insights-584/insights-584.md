# #584 鲜为人知洞察槽位 · 交互规格（Jony · 体验设计 · 2026-11-01）

> 产品已锁定（Steve，#584，2026-11-01）。槽位见锁刀评论；种子⑧以同日修订为准：空城镇中心也能射 8 箭（满驻上限 18）。修订覆盖上一句「禁锁 +N」。本稿只定这一刀的界面。不重开范围，不排优先级，不改页面其它区块。

玩家在单位页或文明页扫一眼就能看到短洞察。内容以后可以加。第一版可以硬编码种子，但看起来必须是列表槽，不是一段写死的长文。

## 1. 放在哪

两条路由各一块，数据互不共用。同一条洞察不要为了「凑满」复制到另一条路由。

| 页 | 位置 | 不放 |
| --- | --- | --- |
| `#/unit/:id` 概览 | 「造价与生产」正下方，基础属性之上 | 说明长文里、标签页里、侧栏「升级路线」 |
| `#/civ/:name` 概览 | 官方定位、特色兵种这两行短摘要下面，文明加成长列表上面 | 加成条目中间、开局建议里、侧栏「独特单位」 |

概览是默认标签。切到别的标签时槽位可以不在那些标签里，但回到概览必须还在，且不用点击展开。窄屏把主栏堆到侧栏上面时，槽位仍跟造价或摘要走，不要求 360 精修。

线框用 1px `#a65a14` 描边，方便定位。实现与相邻详情卡相同：白底、`#e5e5ea` 描边、圆角 18、现有卡片阴影。标题用正文色。琥珀色不铺底，也不拿来当列表圆点。

## 2. 结构

一块 `section`，可见标题「鲜为人知」。

| 态 | 标题下 |
| --- | --- |
| 空 | 一句「暂无」。不写「敬请期待」，不用虚线红框，不把整块拿掉 |
| 有内容 | `ul` > `li`。同页至少能放下 2 条。第 3 条起只增加 `li`，不改标题、内边距、圆角或栅格 |

建议测试 id：

- 槽位：`data-testid="insight-slot"`
- 每一条：`data-testid="insight-item"`
- 空态那句：`data-testid="insight-empty"`（有内容时不要留着这个节点）

空态和有内容态的外框是同一个。有内容时没有「暂无」。

标题 18px / 600，下边距 12px。条目 15px，行高 1.65，条与条之间 8px，左边 2px `#e5e5ea` 细线，不用圆点字符。空态「暂无」15px、muted `#636366`。槽位内边距 16px 18px。区块下边距 16px，与下一节拉开。

数字和「数字+单位」用 `.num`（tabular）和 `.nw`（nowrap）。「8 箭」「18」「80 木 + 35 金」不能从数字和单位中间折开。

不是链接，不进 Tab 序。标题是这块的可见名（`aria-labelledby`）。条目在无障碍树里按列表读出。

## 4. 文案门禁

玩家可见的句子只用下面这些。禁止项不要写进界面，包括不要写成「不要相信旧说法」这类注脚。

1. **扈从部队**（`#/unit/2705`）  
   可写：近战前自带投掷标枪；造价无粮（80 木 + 35 金）。驻扎防御建筑可因自带远程/穿刺标枪增加射箭。后一句必须单独成句，不能和文明「塔/城堡基础箭 +100%」写成一件事。  
   禁：等同步弓单兵必加。

2. **无粮步兵**（同一单位页）  
   可写：无粮步兵（对照火矛兵）。  
   禁：未枚举全库的序位。

3. **战车**（`#/unit/1759` 或孟加拉文明页，本包不画）  
   可写：无粮骑兵 UU（对照骑士线）。序位仅可写「第一个无粮的城堡骑兵 UU」。  
   禁：「全游戏第一个」。

4. **撒克逊人送石**（`#/civ/Saxons`，本包不画）  
   可写：磨坊、木营、采矿场建成得石，利于早塔/防塔爆。  
   禁：「≈2 箭塔」。不锁食物 +35 或 +50。站内 `bon` 与 `bonEn` 的食物数不一致，本刀不改那两句。

5. **高丽邑城**（本包不画）  
   可写：叠满箭羽线后约 13，可压过手推炮 12。  
   禁：单独用「盖不住」当定论。

6. **印加 −15% 石**（本包不画）  
   可写：开局 200 石可盖城镇中心 + 瞭望箭塔。  
   禁：写成开局多送石。

7. **立陶宛山城堡**（tech 691，`#/civ/Lithuanians`，本包不画）  
   可写：山城堡：城镇中心射程 6→9，盖过弩手和投石车。盖不住投石机。  
   禁：反制投石机，或「不怕投石机拆家」。  
   `techs.json` 中文名是山城堡，描述是「城镇中心的射程 +3」。`civs.json` 的城堡时代科技串仍写「山寨」。洞察用山城堡。本刀不改 `civs.json`。

8. **马里蛮王 / Tigui**（tech 576，`#/civ/Malians`）— 以修订为准  
   可写，且线框要用这一句：空城镇中心也能射 8 箭（满驻上限 18）。用途：利于前线推进 / TC 对射。驻扎仍可再加箭，可以单独成一条。  
   禁：旧 +5。不要和山城堡写在一起（山城堡是抬射程，蛮王是箭数）。  
   不用锁刀第一帖里的「禁锁 +N」。8 与满驻 18 已核实，可以写。  
   `techs.json` 的 desc 仍是「城镇中心无驻扎单位亦能自动射箭」，没有箭数。箭数以修订评论为准，本刀不改 `techs.json`。
