# 城堡前置应对（#242）

本页为 1v1 Arena 的条件化检查清单，路由 `#/castle-defense`。不模拟战场，不默认推广到 Nomad、团战或其他地图。正文、风险、失效条件和下次观察信号由本站整理，不输出最佳人数、胜率或拆堡保证。

## 观察与分支

`observation` 记录疑似采石、前压/施工、已完工三种事实；`resources` 单独记录未知、可迁移、关键资源封锁。两者组合形成四个完整分支：疑似准备、前压施工、已成可迁、已成封锁。已完工但资源未知时显示查证卡，不代替玩家选择迁移或封锁。未完工时资源输入保留但不改变阶段。

当前时代、敌护军（有/无/未知）和安全通路（安全/不安全/未知）也是独立输入。仅在护军被主动确认未见、且通路安全时出现有条件的拦截选项，仍要求玩家判断能否及时到场、应付反击并安全撤回；其余状态不推荐村民强冲。城堡完工后不再提供拦截建筑者以取消该堡的行动。

时代只约束本页列出的通用路线，不模拟文明资格。城主以前不把防守城堡和攻城器作为立即行动；帝王以前巨型投石机只出现在后续准备，绝不进入立即行动。帝王时仍明确核对实际文明科技树、生产建筑、资源、展开位置与护卫。特殊文明前置没有单独建模，因此不能把这些文字视为完整的文明生产判定。

## 分享与失效处理

`dv=1` 版本化 URL 必须同时带齐 `observation,age,escort,path,resources`。重复、未知、缺项、无效枚举、非规范时代、过长查询或损坏百分号/UTF-8 编码都拒绝，不把错误输入静默解释成有效观察。页面暂停行动，禁用观察控件与分享，等待明确重置。正常空首次访问使用封建时代、疑似采石、其余未知。

所有控制变化完整更新 URL，刷新恢复全部状态。复制失败显示可选择的完整链接；打印保留当前设置和清单。内容本地打包，无异步远程数据和本地存储依赖。
