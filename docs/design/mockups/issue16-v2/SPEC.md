# #16 版本补丁页 v1 · 交互规格（Jony）

## 路由
- `#/patches` 列表：版本倒序；整行可点 → `#/patches/:id`。列表**没有**条目筛选。
- `#/patches/:id` 详情：分区顺序 新内容 → 加强 → 削弱 → 数据修正（kind=fix）；空分区不渲染。
- 列表只列已收录版本，不放「更早版本」占位行。
- 查询参数：`civ=Byzantines,Incas`（多选）`kind=buff,nerf` `type=unit,tech` `q=关键字`。全部默认 = 不带参数。

## 筛选
- 同组内为 OR，组与组之间为 AND。选了文明时显示「该文明专属 + 全局改动」。
- 即时生效（搜索 200ms 防抖），并用 replaceState 写回 URL，不产生多余的历史记录。
- 结果条上方用可移除芯片列出已选条件，加「清除筛选」；显示「显示 x / N 条」。
- 空结果：「没有符合筛选条件的改动」/「这个版本里，{文明}没有{类型}条目。换个条件试试。」+ 清除筛选按钮。

## 深链与返回
- 卡片标题（有 targetId）→ 对应单位 / 科技 / 建筑 / 文明详情页；浏览器返回时恢复筛选（URL）和滚动位置。
- 面包屑「版本补丁 › {id}」回列表；页头「关于数据」互链。
- 未知 id：「找不到版本 {id}」/「可能是链接写错了，或这个版本还没收录。」+「返回版本补丁」。

## 移动端（≤600）
- 侧栏收起；顶部 sticky 一行：搜索框 + 「筛选 · n」按钮（44 高）。
- 点击后弹出底部抽屉：内容与桌面侧栏相同，底部主按钮「显示 x 条」，右上「清除」；点遮罩或下滑关闭，焦点回到筛选按钮。

## 标识
- kind 芯片 = Lucide 图标 + 文字 + 色：新内容 sparkles 蓝 #0066cc / 加强 arrow-up 绿 #1f7a35 / 削弱 arrow-down 红 #c4281c / 数据修正 wrench 灰 #3a3a3c；卡片左边 3px 同色条。芯片字色在各自浅底上均 ≥4.5:1。
- before → after：改动后数值用琥珀 #a65a14 加粗（这页唯一用琥珀的地方），改动前用 muted 色。
- 加载：分区标题 + 3 张骨架卡；错误：「补丁数据加载失败」/「请检查网络后重试。」+ 重试。

## v1 签字修订（Steve）
- 「数据修正」单独成区，排最后；分区标题下一行 muted 说明：「已与 185872 原版 .dat 核对，属于数据来源修正，不是平衡改动。」（版本号随 id 变化）
- 文明筛选改为可搜索下拉（combobox，多选）：桌面侧栏和移动抽屉共用。
  - 关闭：占位「搜索文明」；已选文明以可移除芯片显示在框内。
  - 展开：列表按拼音排序，已选项打勾。
  - 输入：中文名、英文名都能匹配，命中部分加粗。
  - 无匹配：「没有找到「{输入}」相关的文明」/「支持中文名或英文名」。
  - 键盘：↑↓ 移动，Enter 勾选或取消，Backspace 删除最后一个已选，Esc 收起；`role=combobox` / `listbox` / `option` + `aria-selected`。

## v2 对齐（Reid 调研 + Steve 口径，Jeff 派单）
1. **文明筛选是主入口**：从侧栏移到详情页页头下方，单独一张「按文明看」卡（Lucide users + 可搜索多选下拉，复用 v1 combobox）。未选时提示「选你玩的文明，只看它的专属改动和全局改动」；选中后显示「{文明}专属 x 条 · 全局 y 条」。手机端同样在顶部、整宽，「筛选 · n」只计类型/目标/搜索，不再计文明；已选文明不再重复出现在条件芯片里。侧栏只留搜索、类型、目标。列表页不加文明筛选（待 Steve 确认）。
2. **每条前后对比都标方向**：before → after 行首加方向标 = Lucide arrow-up「加强」绿 #1f7a35 / arrow-down「削弱」红 #c4281c，浅底上 ≥4.5:1。方向按对玩家的影响判断（训练时间、成本变多 = 削弱），不看数字变大变小。数据修正条目同样标方向（相对本站旧数据）。
3. **琥珀色**：改动后数值改为 #1d1d1f 加粗，不再用琥珀；每屏琥珀数字 0 个（≤2）。
4. **「其他」分区放最后**：顺序 新内容 → 加强 → 削弱 → 数据修正 → 其他。其他 = 「Bug 修复」（默认折叠，只有标题行 +「展开」，展开后列条目 + 官方原文链接）→「地图与天梯」（只列文字，不做卡片、不放数值，末尾链官方原文），地图与天梯是页面最后一块。两者都是全局，按文明筛选时照常显示。
5. **样稿条目**：去掉 v1 的削弱占位卡（x → y）。加强用官方 185872 原文的两条：投石车攻击 50 → 55、长剑士对冲击步兵 +6 → +8；重型爆破船升级降价无数值，只写文字。德罗蒙 20% → 25% 按 185872.md 归到数据修正。新增新内容「骑马弩手：替换 12 个欧洲文明的骑射手」。185872 的真实削弱项等 data:update 生成，所以样稿里没有削弱分区（空分区不渲染）。
