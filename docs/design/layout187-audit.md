# #187 排版巡检

依据维护者提供的单位列表截图，巡检并一并提交可复现的排版修复。

## 发现与修复

- 单位、科技、建筑列表的版本图标位于正文流中，会随标题和费用的行数变化，出现上下不齐。图标统一放在卡片左下角，并为正文预留空间。
- 单位等资料卡片纵向居中排列，卡片增加统计内容后，图片落在正文中段。列表图片与标题顶部对齐，费用行移除旧版为图标保留的左缩进。
- 科技列表只有列数声明，缺少 `display: grid`，导致桌面卡片占满整行、手机两列规则不生效。补全网格，与其他资料列表保持一致。

## 巡检范围

浅色和深色，360 / 375 / 390 / 768 / 900 / 1024 / 1280 / 1920 八种宽度，共 24 类页面、384 个页面状态：

首页、文明列表、单位列表、科技列表、建筑列表、模拟器入口、单位普通详情与特殊射程单位、带文明配置的模拟器、文明评分、科技详情、建筑详情、科技树、加成列表与详情、DLC、文明对比、对局助手、单位 PK、开局列表与时间线、补丁、地图和数据说明。

检查页面横向溢出、超出可视区域的非滚动内容、意外截断与浏览器错误，并人工查看资料列表和工具页面截图。时间线条形图按时长缩放，短色块中的文字使用现有完整悬停说明和步骤列表，不拉长色块来迁就文字。

新增资料卡回归覆盖 360 / 375 / 390 / 1280 / 1920、浅深两主题：版本图标边距一致、位于卡片内且不遮挡正文；费用与名称不超出卡片；列表保持多列，无页面溢出与浏览器错误。既有受保护验收不修改。
