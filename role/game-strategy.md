# 文明阵容经验与分析方法

给接手项目、使用本站讨论玩法的人。这里保留 hongcun 分享或认可过的经验、形成这些判断的理由，以及何时需要调整；通过仓库维护，后续使用者不必依赖某位助手的私人记忆。入口与反馈职责见 [产品运营交接](product-operations.md)，产品范围和实现授权仍按 [CONTRIBUTING](../CONTRIBUTING.md)。

这些案例主要讨论陆地帝王中后期。帝王时代不等于缺金，基础配置也不等于每局必选。配比随对手、地图、已有兵力和经济改变。

## 怎样读与继续维护

- **机制事实**：附可打开的资料或工具链接，区分目录基础值、文明与科技后的有效值、工具理论预览。工具尚未覆盖或客户端未对账的部分照实保留。
- **用户经验**：明确是 hongcun 明确分享的实战经历，还是对讨论方案的认可；未说明实战状态时不推断。认可可行不等于助手打过，也不等于混编模拟的胜率结论。
- **待验证设想**：从机制推导的新组合说明成立条件、主要威胁和待验证部分；不因新奇就认定更强。若关键机制或接敌条件未核实就会改变取舍，保留条件候选并优先查来源或站内工具；PK 等理论结果可支持其设定范围内的判断，不能单独证明能接近、追上或在实战中获胜。

本文的经验来源为 [hongcun 与产品运营的讨论](https://app.devin.ai/sessions/0324fdbe099145518bae6f421b8925c4)。关键内容已写在本文，阅读不依赖会话权限。西西里、哥特、波西米亚资料及驻军机制在 2026-11-15 使用线上系统核对：站点 **v0.77.100**，数据 **DE 188329（2026-10-28）**，构建 **ea09def**。同日补入拜占庭、马里并修订高丽、土耳其时，重新核对了下文实际引用的线上机制与工具：**v0.77.102 · DE 188329（2026-10-28） · 构建 84988dd**。链接会随部署更新，复用机制和数字前须重核页脚三项；同日补入火矛驻塔跨文明对比、女真和越南并补充中国变体时，重新核对了所引用的线上机制与工具：**v0.77.105 · DE 188329（2026-10-28） · 构建 cd9382c**。这些版本不能倒填给早先未采集版本的观察。保留下来的旧外部来源若未标版本，仍不能当作当前数据证明。

同一文明的补充写进同一节，修改时保留来源和失效条件；发现错误就更正或撤回，数据变更后先标待复核。不在这里存单个 Issue 的流程状态、测试日志或发布档案。

## 阵容说明的三段格式

2026-11-15 与 hongcun 讨论后，阵容说明采用以下三段，每段一张表。先让读者看清组合、遇到什么对手要调整、其他候选为什么不默认加入；后文的分析方法用于形成判断，不必逐项展开成阵容说明。这是当前写法，可随案例积累改进，不预设每个文明都要采用相同兵种或作战方式。

### 一、最简组合

先用一句话概括基础组合，再按实际需要列出单位和支点建筑，说明职责与关键特点。若文明没有一套稳定的单一基础组合，可按需要列 2–3 条相互替代的条件路线，明确不是同时训练的兵种清单，并写出触发条件，如对手、地形、经济或玩家偏好；数量只是写法建议，不要求每个文明都列满，条件补队不必塞进基础组合。

| 组成           | 作用                     | 关键特点                           |
| -------------- | ------------------------ | ---------------------------------- |
| 单位或支点建筑 | 在这套组合中承担什么任务 | 支撑选择的机制、必要数据或使用边界 |

**进攻**：用一句话说明这套组合怎样接近、推进或拆除防御。

**防守**：另用一句话说明这套组合怎样站位、保护关键单位或拦截敌军。

进攻、防守说明这套组合的用法，与敌方兵力是不同维度，因此随组合分别写在表后。

常规科技与生产建筑可由单位、建筑推知，不再单独列一张清单或表格。独特科技、免费升级和影响配合的特殊文明机制，可按需写进“关键特点”；新增投入仍按后文方法核算。

### 二、按对手调整

这里只按敌方兵力写触发条件，说明增加、减少或替换什么，以及谁改变职责；不与进攻、防守状态混排。

| 对方兵力           | 调整                                         |
| ------------------ | -------------------------------------------- |
| 某类敌军或混编组合 | 调整哪些单位、比例或职责，以及需要避免的交战 |

### 三、为什么不出

解释讨论中被比较但未纳入默认组合的候选，理由要对应这套组合与适用条件。“不默认加入”不等于任何局面都不能出；已有兵力、科技等条件会改变选择时，简要写明。科技树缺口只列影响这套方案的部分。

| 不默认加入     | 原因                                     |
| -------------- | ---------------------------------------- |
| 候选单位或建筑 | 没有默认加入的理由，以及何时值得重新考虑 |

末尾一行注明实际使用的资料或工具链接与版本。数字继续区分目录基础值、有效值和理论预览，机制事实、用户经验与待验证推断仍按本文开头的口径标明。

## 先选择作战方式，再选择兵种

| 判断                   | 需要回答的问题                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------- |
| 明确局面与取胜任务     | 对手、地形、交战窗口和已有兵力如何？目标是袭扰、守住、推进，还是拆除防御？                                           |
| 核对经济供给与持续时间 | 食物、木材、黄金、石料各有多少库存和持续流入？哪些资源会成为瓶颈？不要假设市场或贸易能无限供给。                     |
| 分配职责并预判战损     | 谁输出、承受损失、处理射手、反骑、反攻城或拆建筑？各单位各自承担什么任务，可能损失多少昂贵主力？                     |
| 检查反制与接敌路径     | 对手有什么共同反制？射程、速度、地形、护卫和先手条件是否允许接战、追击或靠近目标？单挑或等资源 PK 不证明能接近目标。 |
| 核对文明机制与科技树   | 加成是否作用在实际任务上？缺失科技具体影响哪个职责？驻军时要查建筑实际获得什么效果，不从单位面板直接推断。           |
| 核算成型投入与产能     | 还缺哪些升级、生产建筑和准备时间？现有兵量能否先履行任务？资源够不等于能在交战窗口前形成兵力。                       |
| 预想对手回应与转换     | 对手换兵、绕路或转攻经济时如何调整？何时减兵、转线、守住或撤退？新增路线是否解决真实缺口？                           |
| 计入操作与个人偏好     | 多线、追击、僧侣或建筑微操能否稳定执行？操作省心、熟悉度和玩家兴趣也有价值，不只比较纸面上限。                       |

“接近不了”和“接触后打不过”是两种问题：新增主力线前，先评估侧翼、地形、分散或运输能否让现有单位履职。运输只是投送手段，不替代单位职责；核实装载兼容与容量，并计入卸载位置、护卫、成本、操作和撤退。

不预设“肉盾＋远程输出”。近战单位可以承担主输出，轻骑可以同时接战、追击、清攻城，建筑可以成为固定远程火力和前线生产核心。村民的进场、施工、维修与撤退，以及驻军分配、交战位置、补兵路线和产能都属于阵容设计。

寻找跨用途的机制配合：例如波西米亚强化村民的修道院科技，可以帮助前线施工；西西里卫兵可把占领的位置转化为城楼支点。比较的是这些配合能否在当时局面下产生收益，不能只比较一名单位的面板。

### 成型与持续补兵要分开算

1. 列出已有、免费和待研究科技，只核算新增投入；共享铁匠铺科技算一次，独立护甲、兵种线升级与特色科技分别算。
2. 加入待建生产建筑、扩产时间、研究顺序、补兵距离和人口占用。资源够不等于能在交战窗口前形成战力。
3. 用[总训练成本](https://linhongcun.github.io/aoe2-analyzer/#/production?mode=train-total)比较所选文明、时代、科技下的多兵种数量与训练资源；研究、升级、建筑和维修另算。
4. 用[连续生产](https://linhongcun.github.io/aoe2-analyzer/#/production)估算建筑产量、每分钟消耗和村民配置。它不是按实战损失自动补兵的混编战斗模拟。
5. 持续成本还包括实际战损、维修、采集停工、驻军占用人口和补兵瓶颈。食物等资源可能在主力与辅助之间重叠；分别列出库存和每分钟收入，不能把少量黄金库存当成稳定金流。

便宜不等于能持续：若单位无法接敌、很快损失或生产跟不上，低单价并不代表阵容可补。保护昂贵主力可能有价值，但不能假设后排垃圾兵会自动替它承受前排损失；不凭空填战损率或固定比例。

资源互补只是判断因素：步骑可能共用近战攻击却分别研究护甲；火枪与翼骑争食物，但及时成型仍可能优于从零转另一条路线。

### 从已有任务和实际消耗做取舍

| 判断                         | 用法与边界                                                                                                                                                                                                                                                                                                                                                                                      |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 资源与职责同时互补           | 两条主力既要分担任务，也要看资源是否重叠。一个金兵加一个免金兵可作常见检查起点，少量攻城器另算；不是配比规则。马里用死士强化的轻骑配飞刀补反步兵，拜占庭折扣长戟与掷矛分别反骑、反弓且用户认可共同撑线，说明两条垃圾兵线也可互补，但产能与升级仍要算。                                                                                                                                          |
| 按金流决定开几条路线         | 看黄金库存、持续收入和预留，不为“花完资源”同时开齐兵线。采金加速帮助供给但不等于黄金无限；马里额外存金与土耳其采金加速是不同机制。马扎尔研究科维尼安军队后，免金骠骑可释放黄金投入重装骑射手等互补兵种；马普切科那＋掷石绳骑兵可作双金条件配合，不因“一金一免金”的检查起点而排除，仍须核算金流与损耗。文明页的“骑兵单位击败敌军时生成的黄金 +3”仅文本，掷石绳骑兵是否适用未核实，不计固定金流。 |
| 检查共同反制                 | 轻骑＋重装骑士都可能怕长戟；增加一种骑兵未必补上缺口。同类护甲也不必一概排除，仍看加成、额外护甲、职责和局面。马里补骆驼针对骑兵压力，不把它当作清长戟的答案。                                                                                                                                                                                                                                  |
| 比较职责互补与重复           | 条顿游侠对普通骑兵已有优势，固定搭配长戟可能重复职责；火枪搭长戟则由长戟补反骑、火枪补反步兵。阿兹特克鹰勇士＋精锐掷矛手虽各有强化，hongcun 仍指出重骑兵或冠军剑士可能同时压制两线；资源分开或各有加成，不等于职责覆盖。是否重复仍依对手判断。                                                                                                                                                  |
| 按成形编队看职责，不只看标签 | 印加枪兵长普通与精锐页面均列射程 1；hongcun 认为成形并守住阵地时，其近战群体表现不应只按“反骑”标签判断。敌方有步兵也不自动加投石手，先看现有编队是否已履职；弩炮威胁可条件补精锐蔷琵战士反攻城，仍需安排接敌与护卫。                                                                                                                                                                            |
| 按实际作用看加成与缺科技     | 法兰克骑兵加成不自动让轻型骑兵成为最佳路线；缺血统或翼骑兵线要看任务影响。掷矛缺少部分射手科技也不自动失去职责；若其仍能完成需要的反弓或反长矛任务，就按局面比较。                                                                                                                                                                                                                              |
| 先用已有部队，再开新线       | 已能接近并清除弓手、攻城器的轻骑，不必自动再配投石车。若护卫、地形或射程使其无法接近，再讨论新增兵种；接触 PK 获胜不保证能追上风筝目标。                                                                                                                                                                                                                                                        |
| 分开核算野战、拆建筑和反攻城 | 推进方案要明确谁拆城堡、塔和中心；清野战兵不等于能拆防御。巨投、手推炮、冲车按可用性与现有基础选，不要求同时全出；反攻城还要说明接近或射击条件。                                                                                                                                                                                                                                                |
| 核对驻军与出击的不同职责     | 能进驻不等于能加箭，例如火矛驻塔有增箭而飞刀驻中心没有；建筑也不继承驻军单位的攻击、射程或克制加成。驻军与出击分开判断，例如扈从出击处理射手、火矛兵出击承担反骑。                                                                                                                                                                                                                              |
| 把操作量与偏好算进取舍       | hongcun 指出打法单一也是优势：操作量降下来，才能操作得更好、更省心。多线、追击和僧侣线可能提高操作要求；上限、熟悉度与个人兴趣都属于取舍，不是强弱定论，见[保加利亚](#保加利亚)。                                                                                                                                                                                                               |

已有部队、科技和地形会改变默认选择；补队与攻城器也会继续消耗资源。避免把“唯一金线”“垃圾兵只选一条”或某个阵容写成跨文明硬规则。

“人海”描述的是出兵方式，不是胜负结论；仍要核对持续资源、生产和部署能力，以及战损交换，不能只用兵量推断优势。

### 经济优势怎样转化为战力

区分采集速度、单位折扣、农田建造或重播费用、免费科技和每块农田可采集的食物总量：它们影响的分别是资源流入、单位成本、木材支出、研究投入和每块农田可采集的食物总量，不能互相代称。比如条顿农田费用减免是木材成本支持，法兰克免费磨坊科技是省下研究投入；除非机制明确如此，不写成提高采集速度或产量。

经济优势可以支持补兵、科技投入和转型灵活性，但不能单独证明“没有万金油”或某条路线必胜。四种资源都有来源，也不代表恰好满足这局的持续产能和时间窗口。

### 建筑阵容要说明怎样建成

| 阶段       | 要准备的配合                                                                                                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 选择支点   | 比较石料投入与其他用途；折扣不等于可以无限重复前推城堡，先确认这处位置值得承担成本和风险。                                                                                                 |
| 取得空间   | 主力争取交战位置，处理射手和远程攻城器；确认施工点不在敌军可自由输出的位置。                                                                                                               |
| 施工进场   | 保护建造者的路线与侧面，安排撤退通道；把行军、暴露施工时间和维修计入，同时确认主力能否维持掩护。建筑未完成前不能按成型防线估计保护能力。                                                   |
| 落成驻防   | 容量不等于箭数贡献，核对实际增箭阈值与上限，不默认驻满；计入驻军人口成本。建筑与移动部队要相互支援，留塔外兵力处理冲车等威胁。建筑若兼作前线生产，如保加利亚营垒，也要确认产能与生产安全。 |
| 维修与补兵 | 留出维修资源、工人安全空间和补兵通路；驻军仍占人口，也占用其训练资源。                                                                                                                     |
| 推进或撤退 | 计划敌方巨型投石机或手推炮等威胁、支点失守后的退路和经济保护；不要把一次建成的前线锚点当成永久安全。                                                                                       |

驻军贡献与塔自身火力要分清：增箭有阈值和上限，不是每进一名就固定多一箭，也不等于把驻军单位的直接攻击、射程及反步兵加成搬给塔。驻军与出击还要分别检查：单位进驻后对建筑的贡献，不等于出击时的反制能力。本站驻军预览注明：按固定数据和公开公式估算，尚未完成该版本客户端逐项对账；健康建筑有合法目标时的理论弹丸数不代表齐射伤害或胜负。

### 写案例前的快速自检

1. 这条路线要完成什么任务，谁会输出、接敌并承担损失？
2. 主力的职责和资源是否互补，是否有资源重叠或共同反制？
3. 它能否在地形、射程、速度和护卫条件下到达目标？
4. 能否及时成型并持续补兵，成本是否包含科技、产能、战损和维修？
5. 对手的简单应对是什么，何时换路、守住或撤退？
6. 操作要求是否适合玩家？结论是实战经验、用户认可，还是有条件的推断？

这是帮助发现遗漏的短检查，不要求每次讨论都补齐所有数据，也不要求每个文明有固定阵容；只展开会改变判断的维度，保留条件和证据边界。

### 中国

**用户经验（实战用过）**：hongcun 经常使用精锐诸葛弩＋轻骑兵＋少量巨型投石机进行阵地战，并分享过良好效果；2026-11-15 再次说明这套实战用过、经常取胜。诸葛弩作为需保存的主力输出，轻骑通常就在前方掩护，兼顾清理可接近的攻城器；巨投拆关键防御。绕侧不是轻骑发挥作用的必要前提，也不能假定任何受保护的攻城器都能被切掉。

**投入与边界**：诸葛弩训练耗木金，轻骑耗食物，主力训练资源分工有利于持续生产；巨投仍与诸葛弩争木金，农田补种也耗木。黄金充足且有骑士科技时可评估重装骑士替换部分轻骑，不能把缺金当成所有帝王局面的前提。诸葛弩＋长戟＋冲车的组合若无法处理受保护的攻城器，就不能仅凭正面输出判为完整方案。

**机制核对入口**：[本站中国资料与科技树](https://linhongcun.github.io/aoe2-analyzer/#/civ/Chinese)，以及上面的两项生产工具。本节保存用户经验，不固定单兵数值；原讨论的完整站点版本与构建未记录，不将后续版本补作原观察。

**火矛驻塔变体（2026-11-15，待实战验证）**：hongcun 认可中国可以像高丽一样把火矛驻塔做成主力阵容，四家对比见[火矛驻塔的跨文明复用](#火矛驻塔的跨文明复用)。这套是当天讨论中才发现的，hongcun 还没有实战用过；原来的诸葛弩路线是实战用过的打法，继续保留。

### 印度斯坦

**用户认可的经验**：需要节省黄金的帝王中后期，以火枪手＋翼骑兵＋少量手推炮为基础。火枪处理威胁主力的步兵，翼骑掩护、承担持续补充的损耗并抓机会清攻城，炮拆防御、威胁敌方攻城器。

**投入与扩展**：火枪和翼骑都耗食物，必须支持两条生产线的农田需求；火炮消耗木金，应少量保存。骑兵压力大、黄金和升级投入可承受时，评估帝王骆驼兵加入或替换一部分骑兵，不默认同时维持多条耗金主力。训练资源差额不能代替战力与成型时间比较。

**机制核对入口**：[本站印度斯坦资料与科技树](https://linhongcun.github.io/aoe2-analyzer/#/civ/Hindustanis)。本节属于用户认可的策略建议，不是混编模拟或助手实战记录；原讨论的完整站点版本与构建未记录。历史训练总价观察及其边界另见[运营案例](product-operations.md#印度斯坦混编要的是训练总价)。

### 马来

- **机制来源**：当次查看的 [AoE2Insights 马来科技树](https://www.aoe2insights.com/civilization/malay/tech-tree/) 与 [AoE Buddy 简体中文马来科技树](https://aoebuddy.com/zh-hans/tech-tree/malay) 列出劲弩手、双手剑士、长戟兵、手推炮和攻城技师。马来象兵从城堡时代起由马厩生产；城堡/帝王时代象兵费用分别折扣 25%/35%，以仓库固定生成的[文明](../data/game/civs.json)、[单位](../data/game/units.json)、[科技](../data/game/techs.json)和[科技树](../data/game/trees.json)数据为准（[DE Update 188329](../data/sources/data_sources.json)）。民兵系免金特色科技（Forced Levy）将民兵系黄金成本换为额外食物，但科技本身仍耗食物和黄金；研究后双手剑士耗食物，长戟兵耗食物与木材，劲弩手和手推炮耗木材与黄金。马来步兵护甲升级免费。外部页面未标游戏数据版本，本文不引用其数值。
- **用户判断与既有认可经验**：用户本轮明确判断“便宜强大的象兵才是前中期的主力”，据此记录为城堡时代起优先以折扣象兵作主力。弩手仅按枪兵压力作条件支援，“象兵＋弩手”不是固定阵容。僧侣密集或反骑护卫阻断接近时，不继续只堆象硬推，先处理反制并评估转线。这是战术建议，不是已验证的混编结果。来源：[本轮会话](https://app.devin.ai/sessions/96ed58fa60b84aa39c66ac6a213346ac)；未确认用户亲自实战过这套具体混编，本轮未做新模拟或实战验证。
- **投入与边界**：城堡时代象兵仍需食物与黄金；弩手按枪兵压力条件支援，不固定为“象兵＋弩手”阵容。帝王时代不因升时代自动转型；经济、金流和敌方反制允许时，象兵可继续升级为精锐象兵。马来可用畜牧与骑兵鳞甲，但缺血统、骑兵锁甲和骑兵钢甲，是否升级、继续扩军需结合现有科技、经济和敌方反制评估。帝王阶段按需投入长戟兵、劲弩和手推炮；手推炮需要攻城武器厂，攻城技师按拆防或反攻城需求投入。劲弩路线需独立兵种线升级和射手攻防科技；已有弩手基础及相关科技投入时可继续，不必无条件放弃。只有黄金不足且强征兵役已完成的帝王后期/消耗局，才考虑转双手剑士持续补兵；按骑兵压力补长戟兵，少量手推炮拆防或反攻城，劲弩按敌军与已有弩手基础选配。这条缺金转型不作开场默认主力。双手剑士和长戟兵由兵营生产，共用步兵攻击科技，但兵种线升级独立；步兵护甲免费，强征兵役仍须另行研究。人口、食物与木材供给、剩余研究时间、建筑扩产和补兵距离限制持续补兵；步兵需接近展开，敌方范围伤害可能限制堆量，双手剑士也不应无条件当作耐打肉盾。

### 西西里

**用户认可的基础配置**：精锐萨金特卫兵（军士）＋轻骑兵＋少量巨型投石机。卫兵凭高护甲承担正面接战与输出；轻骑提供机动，清理可接近的射手和攻城器；巨投拆城堡等关键防御。已有骑士基础时，也可先延续骑士路线，避免强转另一套主力。

| 条件                             | 扩展与取舍                                                               |
| -------------------------------- | ------------------------------------------------------------------------ |
| 黄金充足，骑士科技能及时完成     | 将轻骑换成锁子甲重装骑士，加强接战和对射手、攻城器的清理；持续耗金增加   |
| 石头充足，已有稳定战线           | 卫兵在前线建造、维修城楼，提供固定远程火力、驻扎保护与就地生产           |
| 敌方骑兵压力超出主力能力         | 按需增加长戟，不默认大量卫兵、长戟同时推进                               |
| 敌方攻城器保护严密、轻骑难以接近 | 先看路线与交战位置，再评估投石车等新增投入，不把第二条反攻城路线列为标配 |

**机制与来源**：[文明资料](https://linhongcun.github.io/aoe2-analyzer/#/civ/Sicilians)、[锁子甲](https://linhongcun.github.io/aoe2-analyzer/#/tech/757)和[帝王城楼空驻军预览](https://linhongcun.github.io/aoe2-analyzer/#/building/1665?civ=Sicilians&age=4&tab=garrison)。该预览显示空驻军基础每轮三箭；这说明建筑可提供多箭火力，不等于精确替代三名弩手的伤害。塔的箭系科技和位置仍要另行评估。

**教训与成本**：卫兵＋长戟可能一起受成群弩炮压制；减少所受额外伤害不等于减少所有基础伤害。轻骑已能完成清理任务时，优先用好已有兵种。卫兵与骑兵都争食物，步骑共享近战攻击但护甲和兵种升级分开；锁子甲、骑士线、城楼箭系各有新增投入。高护甲不代表卫兵必胜所有骑兵，城楼也受远程攻城和固定位置限制。

### 哥特

**用户认可的常见组合**：精锐近卫军＋长戟兵＋少量手推炮。近卫军凭高穿刺护甲接近弓箭兵，冲击经济区并清理可接近的攻城器；长戟按骑兵压力调比例；炮拆关键防御，威胁步兵难以接近的攻城器。已有巨投可先沿用。

**机制与来源**：[文明资料与无政府、井喷](https://linhongcun.github.io/aoe2-analyzer/#/civ/Goths)、[精锐近卫军](https://linhongcun.github.io/aoe2-analyzer/#/unit/761?civ=Goths)及[外部科技树](https://www.aoe2insights.com/civilization/goths/tech-tree/)。步兵折扣、无政府解锁兵营近卫军、井喷和团队兵营加成共同支持持续补兵。

**调整与成本**：对方转强力近战步兵时，评估以冠军剑士替换部分近卫军；面对条顿武士等强反步兵单位，可评估火枪支援，不为凑远程核心默认加入。共享步兵攻防不免除精锐、长戟、冠军和特色科技的独立投入。要支持农田、黄金和前线兵营产能；便宜且产得快，不等于资源可无限消耗。近卫军的高穿刺护甲不能代替近战能力，也不能抵消投石车打击。

### 高丽

**一、最简组合**

**阵地变体：前线箭塔＋驻扎精锐火矛兵＋少量攻城器。** 原来的弩手驻塔、火矛塔下清冲车是 hongcun 常用且认为战损比好的玩法；本轮用户进游戏观察到火矛驻塔确实会放箭，提出改为火矛驻塔、省掉弩手。只确认“会放箭”，没有逐箭计数，不能写成完整客户端对账或新组合胜率证明。

**用户判断**（hongcun，2026-11-15）：

- 女真、中国、越南的塔射程不如高丽，前塔容易被对方手推炮在射程外拆掉，所以要出轻骑兵去清炮。站内满科技条顿手推炮射程 13：高丽的塔可以还击，其余三家 11 射程的塔够不到。

- 越南没有建筑学，塔容易掉，只算凑合。
- 女真、中国各有箭塔加成，可以像高丽一样做成主力阵容。这套打法是当天讨论中才发现的，有待后面实战验证。
- 不为量产城堡特种兵多修城堡：城堡目录价 650 石，约等于 5 座大型箭塔的石料。第一座城堡仍然需要，强化堡垒、长城在城堡研究，巨投也由城堡生产。

- 女真不能研究步兵钢甲，精锐火矛兵 4/4 甲。火矛兵驻在塔里不挨打，这个缺口在驻塔时不起作用；出塔时仍在。翼骑兵吃到骑乘单位攻击速度 +25% 的文明加成，承担塔外机动。属机制推断，待实战验证，详见[女真](#女真)。

**边界**：塔的属性来自建筑页科技模拟器的“满科技”，箭数是驻军预览的理论值，未与客户端逐项对账（[#1062](https://github.com/linhongcun/aoe2-analyzer/issues/1062)）；只有高丽火矛驻塔“会放箭”由用户进游戏观察过。下文 PK 都是接触 1v1，不模拟射程、走位和混编。接触 PK 中四家的单个轻骑兵线单位都输给手推炮（女真、中国每击 5，越南、高丽每击 3），清炮要成队，还受护卫和地形限制。四家精锐火矛兵都输给冠军剑士。女真和中国的阵容是用户认可的方案加站内机制核对，hongcun 尚未实战使用，没有混编模拟或实战胜率证明。

**站内数据对照**：马扎尔翼骑兵满科技 95 血、11 攻、3/6 甲，68 食，马厩每个 30 秒；精锐马扎尔骠骑各项都高一档，并且对攻城武器有额外伤害。接触 PK 中骠骑[胜条顿手推炮](https://linhongcun.github.io/aoe2-analyzer/#/duel?a=871.Magyars.4.f.&b=36.Teutons.4.f.&m=1)（剩 36/110），翼骑兵落败；拆凯尔特重型冲车骠骑 27 秒，翼骑兵 58.9 秒。等资源 3000 的群战里，37 个骠骑[胜 22 个西班牙游侠](https://linhongcun.github.io/aoe2-analyzer/#/duel?a=871.Magyars.4.f.&b=569.Spanish.4.f.&m=r&bud=3000)（剩 19 个），但[对 50 个法兰克长戟兵全灭](https://linhongcun.github.io/aoe2-analyzer/#/duel?a=871.Magyars.4.f.&b=359.Franks.4.f.&m=r&bud=3000)（长戟兵剩 36 个），对 42 个日本冠军剑士也全灭（冠军剑士剩 21 个）。重装骑射手一侧，马扎尔是 12 攻、8 射程，匈奴、土耳其是 11 攻、7 射程；马扎尔劲弩手 40 血、10 攻、8 射程，对长戟兵每击 9，重装骑射手每击 14。重装骑射手目录训练时间 30 秒，按 +25% 折算约 24 秒，这个数是按站内规则换算的，页面没有直接给出。

群战是集火模型，不计包围空间和走位，人数多的一方结果偏好，不能当成实战胜率。PK 只算接触对打，不模拟射程和拉扯，重装骑射手对长戟兵、冠军剑士的接触结果都是落败，没有参考价值；“重装骑射手打长戟兵”来自 hongcun 的判断，站内工具验证不了。

机制推断（未经 hongcun 确认）：骠骑只花食物，重装骑射手花木材和黄金，两者费用不重叠；两者都是骑兵，目录移动速度 1.5 和 1.4，可以一起行动；这套比[保加利亚](#保加利亚)多一个兵种，骑射手还要拉扯，操作量更高。

### 波西米亚

本站名称为“波希米亚”。**用户认可的基础组合**是火枪手＋长戟兵＋少量手推炮，随后按经济和已有炮量升级榴弹炮。火枪处理步兵，长戟反骑并保护火枪、炮；炮拆防御、威胁敌方攻城器。延续城堡时代火枪基础可降低转型负担，不必一升帝王就同时开齐昂贵升级。

**机制与来源**：[文明资料](https://linhongcun.github.io/aoe2-analyzer/#/civ/Bohemians)、[胡斯派战车](https://linhongcun.github.io/aoe2-analyzer/#/unit/1704?civ=Bohemians)、[榴弹炮](https://linhongcun.github.io/aoe2-analyzer/#/unit/1709?civ=Bohemians)及[火枪驻塔预览](https://linhongcun.github.io/aoe2-analyzer/#/building/235?tab=garrison&gv=2&civ=Bohemians&age=4&gtechs=&army=5%3A5%3Ae)。采矿场科技免费；长矛系增加的是额外伤害，不是所有攻击。圣洁与狂热也影响村民，分别帮助生命与移动；胡斯派战车可为身后单位提供条件性的投射物掩护。

**用户补充的建筑扩展**：黄金采集支持火药单位，石头采集支持前线箭塔；部分火枪驻塔增箭，在面对射手时改变交战条件。免费采矿科技的优势在于及时取得采集提升并省下研究投入，相对已经完成同等科技的普通文明不会凭此额外加速。

| 使用阶段     | 配合方式                                                                       |
| ------------ | ------------------------------------------------------------------------------ |
| 巩固已有战线 | 在已控制空间建塔，部分火枪驻扎，长戟保护塔区与炮，炮处理远程攻城威胁           |
| 主动向前推进 | 先处理射手对工人的威胁；按需用胡斯派战车对射、掩护，取得施工空间后再让村民进场 |
| 新塔落成     | 调整驻军，把新位置作为补兵、维修与回撤支点；再判断下一次前移                   |

**进一步的机制联系与边界**：用户认可将圣洁、狂热对村民的加成用于前线施工、生存与撤退；必须实际研究才生效。战车的价值包含创造施工机会，但掩护受站位、来箭路径与侧面威胁约束，不能当作工人全向免伤。塔升级与箭系科技另有投入，不能照搬高丽免费塔升级、邑城；火枪驻塔也不会把其反步兵加成直接搬给塔。火枪、长戟和密集阵地仍怕范围伤害，炮兵要主动处理共同威胁。

**待验证的条件变招**：面对昂贵骑兵、战象或可招降的高价值目标，可评估长戟＋僧侣＋炮，火枪按步兵压力配置。已有僧侣体系且能操作保护时，再比较[胡斯革新](https://linhongcun.github.io/aoe2-analyzer/#/tech/785)把后续僧侣及修道院科技黄金成本转为食物的收益；特色科技本身、招降所需科技和农田负担仍须计算。这是机制推导，尚未取得本次讨论中的实战验证。

**防守**：翼骑、掷矛和长戟可按敌军压力作免金填线，保护征服者或火枪等金线主力；保留机动兵的拦截与侧袭空间，不把部队全压在正面。建筑工工作速度 +30% 可帮助施工，但石料、村民时间与施工保护仍是投入；本次页面核对未确认维修速度加成。

### 蜀

**用户讨论认可的配置（未说明实战使用）**：用火焰弓应对步兵、成群步弓时用精锐掷矛手；二者按敌军择用，不是固定双远程线。本路线不含剑士。

**一、最简组合**

| 火焰弓箭手                     | 对步兵施压       | 城堡单位，每名 45 木/45 金；站点描述其适合打步兵、攻城器和建筑，也明确怕骑兵、掷矛手。 |
| 精锐掷矛手（成群步弓时）       | 反制步弓         | 每名 25 食/35 木；只在敌方步弓成群时投入，不要求与火焰弓同时大量生产。                 |

| 牵引抛石机（推进时）           | 帝王攻城         | 按推进需要投入，不把赤壁战术当作城堡攻城的已验证替代品。                               |

**防守**：敌方骑兵能切到我方后排时才补长戟；敌方掷矛手压制火焰弓时减少暴露，只有安全侧袭才增加机动骑兵。

**二、按对手调整**

| 对方兵力           | 调整                                                                     |
| ------------------ | ------------------------------------------------------------------------ |

| 掷矛手             | 减少火焰弓暴露；只有侧袭路径安全时才加机动骑兵，不因此重新启用剑士路线。 |
