## 整合范围

三个模块分别提供一局与观赛入门、手填复盘和侦察情报辨析。各模块提交限定为领域、手工内容、组件、样式、使用说明、来源审计及两类专项测试共八个文件。整合者在各模块 PR 另加真实路由，使其 CI 可以直接验证页面；本次公共提交统一整理路由、首页学习入口、全局搜索别名、相关页面入口、静态元数据和生成索引，不扩展旧计算模型。

顶部主导航与首页原有六个工具入口保持既有结构，学习入口放在工具区。复盘的本机草稿不会进入 canonical、OG URL 或分享图片元信息。React Router 可接受多个尾斜线，pageKey 因而统一去除全部尾斜线，避免私密页被识别成首页后把查询带入 OG URL。
