# 区域单位侧栏卡片（#452）

维护者依据中国文明截图，要求区域单位使用与独特单位相同的紧凑模块，直接放在独特单位下方。本规格取代#450的正文大模块展示，领域数据与上下文链接继续沿用。

- 结构：使用相同 `SideBlock`、`uchips`、`UnitIcon`、`EliteBadge`；侧栏顺序为独特单位、区域单位、快速入口。有无独特单位均只渲染一次区域单位卡片；科技/数据等tab继续共用侧栏。
- 内容：仅标题和可点单位标签。移除正文区域模块及其说明、时代和训练建筑行。每文明可用形态经原领域查询筛选，再按原 `collapse` 合并普通/精锐；非Elite具名升级保持独立标签。标题提示普通/精锐完整名称，点击基础形态进入已有升级详情。
- 上下文：区域单位链接保持 `unitPath(id, civ, age, [], [])`，保留文明及基础形态最低时代。独特单位入口行为保持原样。
- 状态：未加载用一行 `role=status` 文本“正在加载区域单位…”；空态一行“本文明没有区域单位。”。切换文明不保留旧结果。
- 样式：直接复用侧栏底色、边框、圆角、字号、间距与主题令牌。仅局部 `.civ-regional-units .ulink` 保留44px最小宽高；删除原列表/路线/时代样式，不改共享样式。360/375/390下沿既有布局排到正文后，1280右侧位于独特单位正下方；四宽浅深主题无溢出、错误、重叠，axe WCAG AA与键盘链接通过。

验收更新现有 `civRegionalUnits450.spec.ts`：侧栏标题次序、正文无区域模块、区域无说明/时代/建筑；中国火矛兵仅一标签并带精锐，火箭推车与重型独立；穆伊斯卡蔷琵合为三标签；达罗毗荼象兵不带精锐；保留加载/空态、法兰克数据模拟/刷新与四宽双主题。主分支和线上短烟测同步使用侧栏定位器并检查顺序。
