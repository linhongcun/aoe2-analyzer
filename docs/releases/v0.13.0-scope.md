# v0.13.0 版本范围

维护者在本会话明确授权完成 #195、#196，并继续完成合并上线。本版范围限于科技首发版本核对，以及单位列表的文明与兵种联合筛选。游戏数据仍固定为 DE Update 185872。

## 范围与验收

- #195：逐项核对当前收录的 199 条科技，记录来源、证据和核对状态，以当前具名科技的首次引入作为口径。单纯效果调整不重置首发版本；改名或替换需保留判断依据。独立免费补丁新增的科技应单独说明，不强行归到某个文明或资料片；无法核实的项目保留未标注。科技列表、详情与版本筛选使用同一份核对结果，既有单位与建筑首发版本结果保持一致。
- #196：单位列表新增文明与兵种筛选，并与关键词、时代、资料片及类型条件联合使用。全部条件由同一个实际单位形态满足，卡片与详情链接对应命中形态；保留 #192 的系列折叠和计数规则。兵种采用结构化游戏分类，允许骑射等单位交叉归类，不以生产建筑推测类别。筛选数量、重置和空结果提示与实际结果一致。

每项由一个执行者负责，使用独立分支与 PR，以 `release/v0.13.0` 为目标。不修改 `tests/**/v0*-acceptance*` 的期望，不手改生成的游戏数据。核对清单与生成脚本需能重跑，缺少记录、身份不匹配或无依据的版本归属应被检查发现。

## 检查与集成

两项分别补充能覆盖原问题的回归用例。集成时逐项核对各自 PR 的 CI 与实际提交；发布前在整合后的代码运行 lint、类型检查、完整 Vitest、构建和完整 Playwright，并运行科技首发清单的一致性检查。

单位筛选和科技版本展示在浅色、深色两主题下检查 360 / 375 / 390 / 1280 四档宽度，确保没有横向滚动、页面报错或控制项遮挡，并保留截图供审查。沿用现有浅色编辑风、组件与设计令牌，不另作视觉改版。

本文件记录范围与待执行的验收清单，不代表已经取得任何具名审查人的签字，也不代表检查已经通过。实际检查结果、提交 SHA、PR 和部署状态由执行记录提供。

## 不在范围

- #197 开局模拟文明覆盖扩展，留待单独排期。
- #33 文明强度统计，继续等待可靠的新版本统计数据。
- 游戏数值、科技效果、文明可用单位数据或 DE 补丁版本的更新。
- 新的配兵推荐、胜率排行或全站视觉改版。
