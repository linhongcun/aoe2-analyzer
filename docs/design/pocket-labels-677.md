# #677 中路到场比较的标签与耐久边界

本项属于已授权开一局批次，承接已交付 #678，采用 [#677 冻结记录](https://github.com/linhongcun/aoe2-analyzer/issues/677#issuecomment-6618988486)中的标签口径限定方案。只调整中路卡片标签及直接说明，不新增生命权重，不改 Pareto、排序、公式、数据、科技包或来源 pins；边路 #678 文案和行为保持。

中路当前可比较且在原优先集合内的候选显示“到场数量 / 时间侧重”，其它可比较候选显示“到场对照候选”；预算不足或机制受阻继续显示原原因。卡片前的默认可见说明明确：仅比较期限前人数与首兵到达，未比较生命、攻击和完整战力；相同到达结果不代表相同耐久。

生命、攻击等属性继续默认折叠，避免把未参与比较的属性并排当作强弱结论。展开“查看计算输入”保留原始属性数值，并说明“速度用于到达计算；新训练部队还须完成首个训练周期，现成部队不等待训练。生命、攻击等未参与到场分组。”固定数据下法兰克与不列颠的新训练部队均为首兵50.202秒、期限前3兵；展开仍分别为生命120和100，不因到达相同而宣称耐久相同。切换现成部队后，法兰克首兵为行军时间20.202秒、期限前6兵。

验收先在1280真实旧构建复现旧“本场景指标优先”标签，再追加360/375/390/1280回归：核对匈奴限定标签、法兰克/不列颠到达相同与生命差异、默认输入隐藏、展开解释、现成部队到达及零预算原因；每宽保存两张展开卡片截图，截图时临时隐藏吸顶页眉以完整呈现卡片。四宽无横滚、console error或pageerror，原 #679/#678、明暗、axe、场景更换、数据失败和文明保留断言不变。
