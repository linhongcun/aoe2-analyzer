## 怎么看

用浏览器打开同目录的 `wire-*.html`（需要 `ladder.css`），或直接看 PNG。图标是占位方块，方块上的字是 Lucide 图标名。

表内三行和样本局数取自当前快照 `src/data/ladder-arabia-p162286.json` 的「全部」，只为看版式。对齐态线框上的日期、补丁号和「示意」不是界面文案，也不是新的 aoestats 摘录。

## 这一刀的界面决定

截止信息升进现有来源条的第一行，不新做组件，不写进标题说明。补丁与本站 DE 不一致时，这行以「非当前平衡」开头；黄条只留「胜率可能未反映最新平衡改动。」对齐时黄条不出现，来源条仍写统计截止日，并标「静态快照」。
