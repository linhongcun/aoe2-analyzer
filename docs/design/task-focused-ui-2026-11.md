本轮仅处理移动列表筛选、开一局层级、文明/单位详情扫描三项。基线 `483e513608a6a60150b54f4a70afaa0875b28a79`。不改生成数据、领域计算、持久化/URL协议、接口、科技树实现、全局令牌、发布配置。

## 可验收规格（实施前冻结）

- 列表：复用 CatalogFilters；≤600px 搜索、筛选按钮、结果数常驻，文明类型/位置/DLC与单位文明/兵种/类别/DLC/时代进入同一可展开区域；已选条件摘要常驻、清空仍清除原全部字段。文明必备组合沿用既有独立折叠及URL协议。桌面条件直接可见。筛选实时生效，不增加提交步骤。Escape关闭手机筛选并回焦点；关闭后隐藏内容不能Tab进入。重返列表保留原有sticky状态，面板收起但显示条件摘要。保留DLC和时代每个入口及≥44px触控区。
- 首页：当前步骤与选择保留；场景首段常驻提示保留“仅比较本场景指标，不是整局强度榜，也不覆盖全部文明”。当前科技方案/投入/距离用紧凑摘要紧邻调整入口。预先就绪前提、固定参考对手、未计入指标和来源以有明确标题的原生details渐进披露，原文完整保留。候选名称、理由、顺序、计算、方案切换、恢复和失败状态不变。本局摘要里打法结论先于工具跳转限制；限制放进可发现的details。首页功能菜单继续可达。
- 详情：仅作用于 #unit 与 #detail，沿用 DetailSection/StatTiles。主属性使用显著数字，次属性更紧凑；去掉主栏语义分区上不必要的阴影/外框，保留分区标题、来源与所有内容。单位空洞察保留section、18px标题和15px“暂无”，改无卡底的紧凑横排，≤56px；有内容洞察仍完整可见。文明原有无洞察不渲染行为不变，不新增空卡。不得修改其它详情/科技树。
- 令牌：仅用现有 --color-_、--space-_、--fs-*；正文≥15px、次要说明≥12px、操作≥44px、关键数字nowrap。四宽360/375/390/1280，浅深主题无页面溢出或错误；键盘、WCAG A/AA扫描通过。

## 可复用规则

1. 手机默认态先给任务和结果；搜索、数量、实际条件摘要常驻，高级条件通过有文字的入口披露。
2. 折叠仅改变呈现，不重置筛选、不新增提交步骤、不改URL。Escape尊重子控件已处理事件，断点变化避免焦点遗失。
3. 推荐按“当前操作—结论—理由—完整依据”分层；一句适用范围常驻，详细免责声明与来源原文保留且可达。
4. 用字号、对齐、间距和分隔线区分核心与次要信息；空值不单独产生大卡片。
5. 空、零、不适用与未知分别处理；优化面积不能篡改数据语义。核心数字不折行。
6. 借用信息架构原则，保留本站令牌与组件。三项完成即停止。
