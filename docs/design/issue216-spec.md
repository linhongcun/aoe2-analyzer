# #216 开局专注跟练与打印步骤单

实施规格，依据用户授权与 #216 验收条件；不代表人工设计签字。

## 内容与边界

复用现有全部开局的原始 `steps`，与相同参数的 `simulateBuild` 逐项对应，不使用会合并的时间线资源行或村民训练分组反推步骤。每一步完整显示全部结构化动作、原始说明、本站补充标记、村民数、模拟人口/分配及估算时点。匈奴沿用跳过造房与说明删除线；未支持文明必须持续显示“加成尚未计入，按通用计算”。不新增开局或修改模拟引擎。

`#/builds?bo=…&view=practice` 为专注跟练，`view=print` 为完整清单。保留 `bo/civ/dist/house/step` 等现有查询参数；返回时间线只删除 `view`。现有 `step` 只表示时间线选择，不作为跟练进度。专注页与完整清单互相切换仍使用相同配置。

跟练进度为当前页面内用户手动已跟完的步骤数（0 到全部步骤数），独立于时间线选择。点击“完成这一步”才前进；末步完成显示本轮完成状态。上一步可撤回，重新开始归零。刷新或切换开局/文明/走路距离/造房参数后归零。没有计时、自动跳步、游戏状态检测、评分、悬浮窗或全局快捷键。

## 布局、令牌和四档宽度

沿用站点导航与面包屑。页首标题说明“专注跟练 / 完整步骤单”，有返回时间线、完整清单/跟练和打印按钮。简洁参数行可切换开局与文明，显示走路距离、自动造房状态；其他设置从时间线调整。限制提示不折叠。

- 1280：内容最大 1040px；当前步骤和下一步骤以约 3:2 双列呈现，当前步骤强调；进度与手动控制横排；清单全宽。
- 390 / 375 / 360：全部单列，当前在前、下一在后；按钮自然换行且至少44px高，数字和单位不换行，无页面横向滚动。清单动作自然换行，不隐藏内容。
- 字号：标题28/22px，当前说明18px，动作15px，辅助说明13px，最小12px；正文行高1.65。
- 颜色：`--color-text` / `--color-muted` / `--color-link`；卡片 `--color-surface`，下一步 `--color-surface-2`，边框 `--color-border`；当前进度与主要按钮 `--color-accent` / `--color-on-accent`。限制使用 `--color-warn` / `--color-warn-soft`。浅深色均只使用现有令牌。
- 间距为12/16/24px，圆角12/18px。焦点沿用 `--focus-ring`。不以颜色单独传递状态。

## 所有交互状态

初始：第1步、已跟完0步，上一步/重新开始不可用。中间：当前与下一步、可前进/后退/重置。末步：明确“这是最后一步”，仍需用户确认完成。完成：显示手动跟完全部步骤，不宣称游戏完成；下一步不可用，可后退或重开。更改配置：组件按完整模拟配置重建，立即归零，不闪现旧进度。

跟练区域首次获得焦点，左右方向键后退/前进，且始终有可见按钮和文字说明。只在跟练区域内响应，不截获输入框、选择器、可编辑区、弹窗、组合框和带修饰键的按键，也不将长按重复事件当成连续完成。进度使用 polite 状态播报。文明选择器使用现有支持状态与键盘行为。

手动推进、撤回或重置后，将当前步骤滚动到导航下方并把焦点留在跟练区域，避免手机按钮位于双卡片下方时看不到新的当前动作。首次进入不自动跳过配置与限制说明。

数据载入、失败和重试沿用 TimelineLoader。没有开局参数时沿用开局列表；非法配置沿用现有 parseQuery 规则。专注页始终保留文明支持限制和来源，不受时间线的关闭提示记录影响。

## 打印与数据说明

任何专注/完整清单页面触发浏览器打印时只打印完整清单，不打印单步状态、导航、页脚和交互控件。A4纵向、12mm页边距，允许合理分页；条目尽量整块分页但不设置固定高度、裁切或强制一页。使用浅色打印令牌，即使网页为深色也打印清晰黑白/浅色内容。打印清单内保留全部步骤（含多动作与补充步骤）、完整来源URL/核对日期、许可、地图/推荐文明限制、所选文明、走路/造房参数、DE数据与模型版本、所有估算假设。

明确区分步骤标记村民数、模拟开始人口，以及估算时点；研究类估算时点可能晚于步骤开始，人口/分配是开始快照，不表示实时游戏结果。估算超时/等待说明不可隐藏。估算限制和来源均为清单实际内容，不依赖折叠控件展开。

## 验证

纯函数单测覆盖手动进度首尾/完成/撤回/重置、动作全部类型与跳过造房、所有真实开局逐步映射和多动作完整性。e2e覆盖参数保留、切换归零、键盘输入隔离、末步完成、时间线兼容、完整来源/限制、全部真实开局清单步骤数、四宽浅深截图、A4 PDF与打印样式核对。既有验收测试期望不修改。
