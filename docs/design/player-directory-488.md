## 数据与路由合同

一个手工目录为所有页面、成员查询、作者归属、搜索、路径、元信息、静态入口、sitemap 与后续赛事关联提供 ID。详情只接受实际目录成员；未知或损坏 ID 显示“未收录该选手”，保留原 URL 并可返回目录，不显示 Hera、文明 CTA 或首页元信息。无效目录显示可访问“资料暂不可用”；合法空目录显示“暂无已收录选手”，不把空与错误混为一谈。

新 JSON 使用显式 schema 登记及脚本生成的独立编译校验器；读取边界显式捕获结构、引用与语义错误，不在模块加载时抛出给 Suspense。纯 Node/浏览器共用校验检查真实日历、完整带时区时间戳、北京时间换算、成对 null、唯一 ID、来源/对手/文明引用和 HTTPS 来源。不得裸断言类型、默认 Hera、静默过滤坏记录。无运行时外部 API。

`pageRegistry` 只登记两个模板。目录为 `secondary/reference`；详情写目录入口原因，不给动态模板静态标题字段。真实三个人物元信息由同一验证目录枚举，禁止生成字面 `:id`、未知成员或第二份生产 ID 清单。每个已收录详情 title/description/canonical/OG URL 必须准确；现有默认 OG 图片可复用。中文目录与人物搜索标签经拼音脚本再生，不手改生成文件。

复制操作生成完整、稳定的同一选手静态 URL。成功有 live status；剪贴板失败显示完整可选、带标签的只读链接输入供手动复制。后退/前进/刷新/静态入口保持同一选手及正常文明路径，不改全局模式、Compare、计算器或参考评分。

## 视觉与无障碍

使用既有编辑风 pane、面包屑、链接与令牌；`--color-text/--color-muted/--color-link/--color-surface/--color-border`，字号至少 `--fs-xs`（12px），正文 `--fs-body`（15px），卡片标题 `--fs-h3`（18px）。页间距 `--space-4/--space-6`，圆角 `--radius-md`，不新增颜色。目录桌面最多三列，窄屏单列；资料详情单列清楚分节，不增标签页。

卡片名不截断；国际姓名、来源 URL 与长定位可换行。年份、日期及数字加单位用 `.num/.nw`，360 宽下不折开。按钮、主要链接、来源 summary 至少 44×44，可见键盘焦点，语义 H1/H2、来源 details 与 live status。只用已登记 users/trophy 图标与文字，不加人物肖像。

状态涵盖目录、三份简介、来源关闭/展开、有效空目录、损坏目录、未知 ID、复制成功/失败；若异步读取，加载壳不能误称完成。360 / 375 / 390 / 1280 各浅/深色，无横向滚动、console error 或 pageerror，WCAG AA 对比度及 axe 检查。

## 失败用例、保护与验收

先在旧产品上通过现存 `PAGES/PAGE_META` API 与真实 URL 证明缺目录登记、缺真实人物元信息、目录和 Hera 页面不存在，至少三条实际失败。不存在模块导致收集失败不算红例，已经绿色的未知-ID缺人物也不冒充缺功能红例。

随后验证三人精确事实与来源定位、跨日北京时间、真实读边界拒绝坏 ID/来源/文明/日期/HTTP、空与错误状态、分享后备、真实浏览器路径、未知成员不借首页元信息。Hera 作者链接从 #487 两条临时无-profile能力断言窄化迁移为已知成员准确 href 与真实落地页；保留所有无媒体/无评分/未知视频字段保护及未知作者无死链。

#335 只按原流程追加实际来源公开时间戳，保留旧日期和叶子快照。#338 给实际加载并展开来源后的四个真实页面 × 360/1280 录制八个明确伴随条目；所有历史 fixture 字节与断言保留。明确历史及全部伴随文件的所有权、拒绝缺/多/重叠键与未分配录制项；无表的 [] 只能来自真实页面捕获。
