# #631 单位页攻城入口支持范围

本轮维护者已授权修复 #631。沿用 #533 的位置、文案、样式和 URL，只收紧显示条件：单位必须被现有攻城工具的 `SIEGE_UNIT_IDS` 收录，且对缺省城堡的现有计算为 verified。单位页辅助函数 `unitSiegeHref` 同时负责判定与链接生成，避免显示条件和链接对象分离。复用已有支持名单，不维护第二份 ID 表；领域计算和原有 verified 判断保持。

民兵 74、骆驼投石机 1923 等工具尚未收录的单位不显示「算拆建筑」。攻城锤、中型冲车、重型冲车、巨型投石机的入口仍原样进入对应单位；未核实投石车和手推炮继续没有入口。加载时不提前显示。

1280 优先，360 / 375 / 390 基本可用。保持原触控尺寸、令牌、数字不换行和页面布局，无横向溢出与页面错误。四宽浏览器验收附截图；生成单位目录的每一个可见入口都必须能被解析器原样接受。

本规格补足 #533「谁显示」的工具支持前提，取代仅凭底层计算 verified 就显示的旧判定。不改伤害、结果数字、选择器支持范围、生成数据或受保护验收。
