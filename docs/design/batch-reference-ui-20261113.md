# 批量巡检第二批：科技目录/详情与地图手机布局

## 授权与边界

维护者已授权常规UI通过复核/测试直接合并部署。只改科技目录与详情的展示，以及地图窄屏筛选布局和返回焦点。数据、计算、搜索/筛选结果、URL协议、来源说明不改。基线为第一批已合入main的c89845a5c649fef241b56ae38e7ea2f16e41d535。

## 冻结设计

- 科技目录：搜索/类型/次筛选收进`--color-surface`卡片，边框`--color-border`，圆角`--radius-lg`，桌面20px/手机16px内边距。搜索、select、筛选触发为44px胶囊。现有数量和目录基础值说明保留，不增加新说明。结果整表单独同色卡片，表头浅底`--color-surface-2`；保留六列顺序/对齐、全行链接及mobile的名称→建筑/时代→费用→文明/首发顺序；行左右padding16px，手机12px，字体仍名称16px/说明13px。空结果原提示和清除入口保留；筛选展开/收起、选中态、默认/加载状态不改。
- 科技详情：顶部身份卡使用surface/border/radius-lg，桌面24px/手机16px内边距，图标80px/手机56px，名字26px/22px；复制与类型/时代/建筑标签为胶囊。研究卡当前所有宽度是费用/时间二列+地点整行；本批有意将桌面改为费用/时间/地点三列以减少空白，手机维持原二列+地点整行；目录基础值说明保留。作用对象/说明/文明/关联各为surface卡片，桌面20px/手机16px内边距，间距16px，h2仍18px；筛选sticky背景与卡一致。章节按钮仍滚动、不改路由、不新增scrollspy；更新历史保留details，增加Lucide箭头提示。经济科技、时代科技、拇指环等特殊内容完整保留。
- 地图手机：390px真实看到搜索和类型之间大块空白。源码`.map-search{flex:1 1 240px}`在父容器切column后错误作用于高度；<=899px将该flex重置为none，保留44px输入及12px组间距。搜索/筛选区用surface/border/radius-lg卡片，输入/select使用pill圆角。桌面双栏工作区与高度不动。
- 地图返回：手机选择地图进入详情后，返回目录保留map参数和当前过滤，焦点回已选行；已选行不存在时回搜索字段。只在用户按返回时触发，不抢自动筛选或直接进入页面的焦点。移动详情返回按钮语义/aria保留；桌面不受影响。

## 宽度、主题与状态

360/375/390：无水平溢出；科技字段可读、数值不拆行；手机次筛选和空结果保留；地图search不再有240px空壳，回目录焦点可继续键盘浏览。
1280：科技六列保持；详情研究三列；地图仍左右独立滚动。深浅色仅用语义令牌；hover/focus保留，动画不增加。
未计入、目录基础值、缺失数据、未知首发、空匹配、已选筛选摘要、历史loading/错误/无记录均复用现有文本与行为，不将未知当零。
