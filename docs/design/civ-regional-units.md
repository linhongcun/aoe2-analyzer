# 文明区域单位（#450）

展示结构已由[#452区域单位侧栏规格](civ-regional-sidebar.md)取代；本文件保留原版本的数据来源与设计记录。

无内容模块的空态规则现由[#465隐藏空模块规格](civ-empty-modules-465.md)取代：加载完成后空模块不渲染。

维护者要求文明说明展示区域单位，作为后续战术和数据分析可复用的组成模块。

## 数据与边界

- 固定 DE185872 / aoe2techtree `3bb43b1439eef88dfe7fe892d7f7dc41ac9dd76f`；`scripts/units_build.py` 直接保留上游 `node_type`，从科技树可用状态生成 `Unit.civs`。
- `src/domain/civUnits.ts` 提供纯函数 `regionalUnitLines(civ, units)`，先筛 `type === RegionalUnit` 和 `civs.includes(civ)`，再按 `from_` 组织有序路线，返回 `Unit[][]`。不硬编码名单，不读取 React，不计算评分或模拟属性。
- 所有 34 条区域形态的 `civs` 已与 `trees.json` 全文明可用状态核对一致，不增加树加载或数据生成。独特的帝王骆驼兵不进入区域模块。
- 按区域单位自身最低时代展示，并说明这是科技树资格，不代表当局完成前置或研究。基础值和加成使用既有单位详情、模拟器。

## 概览模块

概览中在“特色兵种”后、“文明加成”前加入 `DetailSection`，标题“区域单位”。说明“部分文明拥有的区域兵种，也是本文明的部队选择。点击单位可查看数据，并按本文明模拟科技与加成。”

- 加载中：模块显示 `role=status` 的“正在加载区域单位…”；不得短暂显示无单位。
- 有数据：按现有数据顺序每路线一行，所有可用形态各有图标、名称、最低时代和保留文明的链接；训练建筑来自 `bz`，相同建筑合并。时代使用 `.nw`，不把不可用高级版带入路线。
- 空态：“本文明没有区域单位。”，保留模块标题。
- 单位链接由 `unitPath(id, civ, unit.age, [], [])` 构造；刷新保留文明/时代，在既有详情可切模拟器。切换文明立即重新查询，不保留上一文明结果。
- 原独特单位区保留；不新增战术判断、推荐强度、胜率或满科技结论。

## 外观与可访问性

复用 `DetailSection`、`uchips`、`UnitIcon` 与既有令牌：标题 `--fs-h3`，正文继承页面字号，说明 `note` 不低于12px，底色 `--color-surface`，边框 `--color-border`，链接 `--color-link`/既有链接令牌。

新增局部样式仅约束 `.civ-regional-units`：列表去默认圆点、行间距16px，单位链接 flex wrap、最小44×44；长名称可折行，时代 nowrap。沿用卡片桌面24px与移动端既有padding，不新增固定列数。360/375/390/1280×浅深主题均无横向滚动、无页面错误；键盘可访问每个链接，axe WCAG AA通过。
