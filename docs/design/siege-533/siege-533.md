## 1. 单位详情「算拆建筑」

**位置（PC 优先）**：页头 `dhead` 之下、标签栏之上。与现有「回对局助手」同一条 `nav.ctx-bar`（`community-tool-entry`）。已有这条栏（文明链 / 回对局助手）时，把新链接追加进去，不另起一条。没有对阵上下文时，仍画出这一条，只放本入口，`aria-label="本页相关工具"`。

不放进侧栏、升级路线或概览正文。不进 `#/matchup`、`#/duel`。

| 项 | 规格 |
| --- | --- |
| 文案 | 算拆建筑 |
| 图标 | Lucide `hammer`（`Icon.tsx` 已登记，与工具页相同） |
| 控件 | `<Link class="community-tool-entry">`，真链接，可新标签打开 |

工具现有逻辑会把缺省补进地址（`n=4&bldg=82`）。那是 #308 的行为，本切片不改。入口本身只写 `unit`。

**谁显示**：`calculateSiege(该单位, 城堡 82, 缺省数量, 无文明, 无护甲)` 为 verified 才显示。用这一函数判断，不要另写一份 id 名单。按当前数据，会显示的是攻城锤 1258、中型冲车 422、重型冲车 548、巨型投石机 331。轻型/中型/重型投石车（280/550/588）和手推炮 36 对城堡即未核实，详情页不放此入口，避免从资料页承诺能算出数字。

建议 `data-testid="unit-siege-entry"`。

**建筑页（可选，可整段不做）**：若便宜，在建筑详情「造价与建造」里、现有「比较多人施工」旁，加同款链接。文案「算攻城拆这座」，地址 `#/siege?bldg=<id>`，不带 `unit` / `n`。只给对照表里、且默认攻城锤能出已核实结果的建筑（当前：城镇中心 109、城堡 82、瞭望箭塔 79）。石墙、城门不放。不改建筑页布局。

## 2. 「冲车」检索

官方中文名保持不动：攻城锤、中型冲车、重型冲车。不要把攻城锤改名为冲车。

- 单位俗称：`src/data/aliases.ts` 已有 `[1258, '冲车', …]`（写法同 [paladin-alias-468](../paladin-alias-468.md)）。本切片不改这一行、不改出处。搜索命中后主名仍是「攻城锤」，打开 `#/unit/1258`。
- 工具页：`pageRegistry.ts` 的 `siege` 增加 `searchAliases: ['冲车']`。导航名仍是「攻城拆建筑」，说明句不必改成冲车。搜索「冲车」时，工具页与攻城锤都应出现（页面 kind 可排在单位前，这是现有排序，不是缺陷）。中型冲车、重型冲车因官方名包含「冲车」可以同时出现。

未核实卡里删掉「可改选攻城锤或冲车」——冲车不是另一种单位。改单位仍用上方「攻城单位」。

## 3. 未核实面板

沿用 #308 的虚线灰卡（`.siege-unverified`）：`surface-2` 底、虚线 `#c7c7cc`、文字 muted `#636366`。**不用红色**，不用 `--color-bad`。未知不是错误。不渲染 `siege-result` / 击数 / 游戏秒 / 现实秒，对照表整块隐藏。选择器仍可用。模型口径句保持原样。

标题沿用现文案，Lucide `circle-alert`（muted，不着红）：

| 单位 | 标题 | 一句原因 |
| --- | --- | --- |
| 投石车系 280 / 550 / 588 | 规则未核实，暂不计算 | 主弹与副弹的伤害结算尚未对齐，不推算击数与用时。 |
| 手推炮 36（缺石质防御等） | 数据未核实，暂不计算 | 建筑的「石质防御」护甲数据尚未对齐，不推算击数与用时。 |

只此一句，放在标题下。口径来自现有 `result.reason`，写成上面两句，不要再堆第二段，也不要编数字。石墙/城门对照行的「暂不计算 · 数据待补」、数量越界、文明不可用，仍按 #308，本切片不改。

**反馈**：现有 `FeedbackLink`，`kind="data"`，`label="反馈数据缺口"`。图标即组件自带的 `message-square-warning`。新标签打开预填的 GitHub issue（带当前 `#/siege` 地址）。不要新做反馈页或表单。`entityOf` 尚未登记 `/siege`，预填标题可以仍是路径，本切片不为此改反馈模块。

卡片内这条链接单独保证 ≥ 44px 高（给 `.siege-unverified .fblink` 加 min-height / padding / 边框即可）。颜色用链接蓝 `#0066cc`，不要改全站页脚的 `.fblink`。

**可访问性**：结果区外层保持 `aria-live="polite"`。卡片 `role="status"`，标题是「为何未核实」的可见名（上表标题）。反馈链接的可访问名就是「反馈数据缺口」。焦点环沿用 accent 2px、offset 2px。数字若出现在选择器里仍用 `.num`；结果区没有用时数字。
