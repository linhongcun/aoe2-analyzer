## 怎么看

用浏览器打开同目录的 `wire-*.html`（需要 `maps.css` 和仓库里的 `public/img/`），或直接看 PNG。界面图标是占位方块，方块上的字是 Lucide 图标名。文明徽章和地图预览用仓库里的游戏图。

线框里的文明和一句理由只为看密度和语气。首批入库文案另写，不把线框样例抄进数据。

## 这一刀的界面决定

现有「推荐文明」留在开局下面。新的边路 / 中路放在它和「来源」之间，PC 两列等宽，窄屏上下排。没有稿的那一列画出待补，不藏轴，也不用天梯胜率或文明页的边位分去填。
