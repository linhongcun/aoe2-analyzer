## 状态与可访问性

- 三位正常选手均显示真实的对手选手、对手文明、本人该局文明开局及赛事公告入口，使用 React Router `Link`，支持复制地址、新标签和键盘 Enter。
- 直接打开、刷新和前后退保持真实地址，不依赖本地 sticky。不添加文明页比赛回链。
- 未知或大小写不符的选手、额外路径保留既有“未收录该选手”或全站 NotFound 与目录回退，不扩路由统一文案。
- 选手目录为空、损坏或缺少有效对手/文明引用时保留现有空态或 `role=status` 不可用提示，不生成新的对局/开局入口；不放宽原 schema/reader。
- 赛事目录为空或不可用时，`/events` 仍是有效目录入口，由赛事页显示既有状态，不生成假赛事卡。
- 复用 `.player-section p a`、`.player-link` 的链接颜色、字号、44×44 热区和 focus ring；必要布局仅用局部样式与现有令牌。四宽360/375/390/1280及明暗主题无溢出、控制台错误或页面错误，原数字 `.num/.nw` 保持。
