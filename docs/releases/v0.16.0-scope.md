# v0.16.0 发布范围

维护者于 2026-10-19 授权按 #204、#205、#206 顺序开发、验证和部署。本版只包含 #206；独立工作区可准备代码与自动验证，必须在 v0.15.0 正式站点和 Release 核验完成后才合并本版功能、发布到 main。

## 本版功能

- 文明列表可搜索、添加及删除必备单位与科技，按全部条件交集筛选。
- 条件依据具体单位形态、科技 ID 与固定科技树可用性，区分普通、精锐及文明替代单位，包含免费科技。
- 与现有文明名称、类型、DLC、位置筛选叠加，零结果保留条件，无效链接明确阻断而不放宽。
- 完整筛选分享链接、加载态、空态与复制失败回退；保留无参数入口的旧筛选记忆。

数据固定 DE 185872。不做 OR/NOT、胜率排序、自动推断满科技或最佳文明推荐。规格见 `docs/design/issue206-civ-requirements-spec.md`。
